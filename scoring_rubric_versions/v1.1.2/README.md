## 唯一问题与改动

本版本只减弱一项构图硬伤漏判：评分已经识别出主导前景、边缘元素、阴影或明暗块，却因为它没有直接遮住主体而只记为普通缺点。

构图干扰条款加入“移除测试”：若排除该元素只会让画面更整洁，仍按普通缺点；若会明显恢复预期主体、主路径、重复、分离或平衡，则触发原有构图／总体封顶。评分流程同步加入这项强制二选一。

封顶数值没有改变，仍为构图最高 5.5、总体最高 6.0。

## 边界保护

元素面积大、明亮、黑暗、贴边或属于自然延续，都不能单独触发封顶。满幅关系、自然边缘、负空间、有意前景、普通杂乱、雾气和正常风景只有在移除后会明确恢复主要阅读时才进入硬伤。

## 验证结果

18 张定向样本中，3/3 已确认构图漏判全部命中，6/6 既有构图硬伤继续命中，1/1 其他类别硬伤未新增构图封顶，8/8 正常／风格样本未新增构图封顶。15 张非目标样本总体分变化为 0；仅一张目标图总体分从 6.8 回到 6.0，全组总体分平均变化约 -0.04。
