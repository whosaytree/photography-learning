## 相对 v1.0.0 的规则变化

正文仍为 209 行，量表档位、五项评分结构和所有封顶数值均未改变。实际只替换七处既有行：

1. **全幅关系可以承担主体。** 没有离散主物体时，只要色块分区、重复、密度、节奏或空间关系在正常观看尺寸下立即可读，就不触发“主体存在但不清／弱”封顶；这只取消错误封顶，不自动建立强项。
2. **全幅关系不强制局部落点。** 道路、引导线等定向构图仍需清楚目的地；满幅图案、色块分区和整体节奏改看分区、节奏与视觉重量是否受控。
3. **可读但明显失焦的证据更明确。** 以预期焦区是否保留可用内部细节和可靠清晰锚点判断，避免仅凭轮廓可认就取消封顶。
4. **构图硬伤改用可见后果判断。** 区分无关可辨元素的事故式截边，以及同时造成竞争重量并破坏主体、路径、重复、分离或平衡的干扰；相关内容不自动豁免，单纯面积大或自然出框也不自动封顶。
5. **7.5以上需要两项真正独立的强维度。** 两项维度须在高分检查前已经达到7.5；技术只有达到8才计入。每项必须有不同的可见属性／关系和维度结果，同一证据不能换标签重复计数，也不能为了满足门槛临时补分或取整。

## 最终定向裁决

蓝天—树冠样本在本版本中按全幅关系判断：不再因没有局部落点扣分，合理总体分为6.0；平直光线、偏青灰色彩、树冠层次和视觉重量仍限制它，不具备7.5高分资格。草地—铁丝、满幅花叶等形式照片同样按自身关系完成度评分，不获得题材加分。
