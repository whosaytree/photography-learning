## 唯一问题与改动

本版本只修复一项失焦漏判：当照片有离散主体或预期焦区、该区域本应清楚，却没有可靠清晰细节时，必须触发“可读但明显失焦”封顶。轮廓可认、颜色分离或无关背景更清楚，不能再用来把它降级成普通偏软。

评分流程同步增加一次二选一检查：预期焦区“有可靠清晰锚点／无可靠清晰锚点”。封顶数值没有改变，仍为技术最高 4.5、总体最高 5.0。

## 边界保护

通过故意效果测试的模糊不受此条误罚；全幅视觉关系不因为没有局部清晰点而触发。正常浅景深、雾气、远距离低对比、满幅图案和色块分区均已纳入对照验证。

## 验证结果

18 张定向样本中，4/4 真实失焦正例命中正确类别，8/8 其他硬伤／明显缺陷样本与 6/6 正常／风格对照均未新增失焦封顶。14 张非目标样本总体分变化为 0；只有两张此前漏判的失焦图从 6.6、6.5 回到 5.0。
