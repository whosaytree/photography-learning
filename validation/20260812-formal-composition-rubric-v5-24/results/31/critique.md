# 一句话总评

蓝天、远丘和草地构成了安静的三层风景，但画面下部暗、乱、偏虚的近景植物占比过大，把视线从开阔的丘陵和天空上拉走了。

# 评分前检查

- **主体：**主体不是单一物件，而是近景野草、中景草原与远处丘陵共同呈现的开阔草原风貌；主阅读是清楚的。
- **题材：**自然风光，重点是草原的空间层次和宁静氛围，有初步视觉意图，不只是地点证明式记录。
- **基础问题等级：**基础问题。曝光与方向正常，但前景的占比、清晰度和边缘组织明显影响画面完成度。
- **逐项硬伤检查：**
  - 显示方向正常，无旋转硬伤。
  - 主体可读，不属于主体不可读、不清或小到无法裁剪挽回。
  - 丘陵轮廓和草地纹理仍可读，没有严重失焦、手抖或动态模糊封顶；但整体微软，下方近景植物比中远景更虚，又缺乏一个可靠的清晰花草锚点，是技术减分项。
  - 天空与草地保留层次，无主体大面积过曝或严重欠曝。
  - 地平走势自然，无明显意外倾斜。
  - 下方近景杂草偏暗、偏虚且从多个边缘零碎截断，占据约三分之一画面，其深色和繁杂线条会先于丘陵吸引注意，符合“主导性干扰／边缘与视觉失衡”硬伤。
  - 除上述构图硬伤外，没有多个跨维度重大失败同时出现。
- **高分资格：**不具备。画面有空间层次和平静氛围，但已触发构图硬伤封顶，且没有两个独立维度达到 7 分要求。
- **故意处理判断：**竖幅、大面积天空、三层景深和近景虚化可视为有意的风光组织；有稳定的丘陵锚点，也符合风光分层惯例。但近景的模糊、明暗和边缘并未形成清楚框景或引导，效果不足以豁免构图硬伤。

# 五项评分

- **技术：6.0/10**  
  明暗范围可用，天空与草地没有破坏观看的死白或死黑，丘陵走势也可辨。不足在于全图细节略软，前景花草又没有清晰主锚点，影像显得不够利落。
- **构图：5.5/10**  
  天空、远丘、草原的横向分层直观，丘陵轮廓也能带动视线横向移动。但下方杂乱、暗且模糊的植物区域太重，没有形成干净入口，反而让视线在底边滞留，因主导性干扰封顶。
- **光线：5.5/10**  
  光线足以区分草地、丘陵和天空，中景也有轻微明暗起伏；但光的方向性和戏剧性较弱，近景阴影又偏沉，没有有效塑造一个主视觉中心。
- **叙事：6.0/10**  
  证据等级为“场景／情绪”：广阔空间、很低的丘线与大片蓝天传达宁静、空旷的地方感，已超过单纯地点记录；但缺少天气、特征物、光影变化或明确关系来形成更强的记忆点。
- **总体：5.5/10**  
  这是一张有分层意识和安静氛围的风光尝试，比单纯记录多了空间感；但近景的视觉重量、清晰度和边缘控制未处理好，主要视觉效果被明显削弱。

# 色彩观察

画面的主色是偏冷的蓝天与偏暖的黄绿草地，蓝绿邻近色带来自然、安静的感受，而前景少量紫红花点提供了局部色彩对比。整体搭配基本和谐，蓝天与绿地的分区也帮助读取空间；但草地中间调稍灰黄，底部暗绿发脏，紫红花又因为虚化而难以成为有效的色彩落点。后期可略微减少黄色饱和度，将绿色色相轻微拉回更自然的绿，并局部提亮中景草坡；不要同时大幅加蓝、加绿，否则容易变成过饱和的旅游明信片色。

# 封顶规则

下方大面积暗、虚、杂的近景植物形成主导性干扰与视觉失衡，将构图分封顶于 5.5，总体分封顶于 6.0。

# 做得好的地方

- 没有把丘陵放在画面正中平分，而是给天空留出较多空间，开阔感是成立的。
- 草丛、草原、丘陵和天空构成了由近到远的景深，说明拍摄时已在考虑分层，而不是只对着远山平拍。
- 丘陵的缓慢曲线与薄云的走势相互呼应，整体气质安静。
- 蓝与黄绿的大色块清楚，没有杂乱人造色混入，地方感比较纯粹。

# 优先修改项

## 1. 缩减无效近景

- **问题：**下方近景植物占比大、偏暗、偏虚，边缘还有许多被截断的枝条。
- **为什么：**近景本应把视线带入远方，但现在它的暗部对比和复杂线条反而成了第一落点，丘陵的简洁曲线被压住。
- **下次怎么拍：**向前走几步或把机位抬高，让繁杂植物只占画面底部约 10%–15%；如果要保留花草，就只选一丛形态完整、与丘陵位置错开的植物做前景。
- **这张怎么修：**从底部裁掉约 20%–25%，优先移除最暗、最零碎的植物；保持丘陵线大致位于下三分之一附近，再视需要少量裁右边零碎枝条。

## 2. 给近景一个明确的清晰锚点

- **问题：**近景有彩色花点，却没有一朵或一丛足够清晰；相比之下，中远景丘陵更稳定，因而前景介于“想当主体”和“只是遮挡”之间。
- **为什么：**风光分层不只需要“前面有东西”，还需要清楚的视觉通道或锚点，否则容易变成平铺的草地与一团虚杂物的堆叠。
- **下次怎么拍：**先找一丛形态完整的花，让它落在左下或右下三分之一，用单点对焦锁在这丛花上；或反过来完全放弃花草前景，把丘陵曲线作为唯一视觉主题。
- **这张怎么修：**不要对虚焦花草强行全局锐化，那会放大杂乱边缘；局部降低底部纹理和清晰度，同时给丘陵轮廓增加少量对比与锐度，明确主次。

## 3. 用光给丘陵增加体积和记忆点

- **问题：**草坡上的光比较均匀，山体只有轻微明暗差，天空的薄云也较淡。
- **为什么：**没有强方向光或天气变化时，简单的大地形态容易只停留在“这里很开阔”，缺少让人再看一眼的光影事件。
- **下次怎么拍：**在日出或日落前后拍摄，让低角度侧光沿丘陵造成明暗分区；也可在有块状云影时等待一块光落在主丘陵上再按快门。
- **这张怎么修：**用很轻的局部加光提亮右侧主丘陵，再用渐变工具把天空压暗约 0.2–0.3 档；控制力度，不要造出不符合现场光线逻辑的“假聚光”。

# 建议设置

画面中没有可靠的拍摄参数信息，以下是估计：

- 风光优先使用 **ISO 100–200、f/8–f/11**，先保证中远景纹理与层次。
- 手持时快门尽量不低于 **1/250 秒**，有风吹动近景花草时提高到 **1/500 秒**；光线不足时先提 ISO，不要让近景因晴风变成无意义的软边。
- 如果要近景与远景都清楚，对焦在画面景深约三分之一处，并放大画面同时检查近景花草与丘陵；如果两者不能同时清晰，用三脚架拍两到三张不同对焦距离，后期景深合成。
- 可尝试偏振镜减少草叶反光、提高天空层次，但每次旋转都要看效果，避免蓝天过深或不均匀。

# 后期步骤

1. 先做裁剪：从底部裁掉约 20%–25%，必要时少量收紧右边，保留大天空与丘陵开阔感。
2. 进行镜头校正和轻微水平检查，但不要为追求绝对平直而破坏自然丘陵的起伏。
3. 全局降低高光约 10–20，轻提阴影约 10，尽量找回底部植物细节，避免 HDR 式过度提亮。
4. 给右侧主丘陵做少量局部加光和纹理提升，对底部杂草轻微降低纹理与饱和度，让视线落向中远景。
5. HSL 中轻降黄色饱和度，把黄绿色相微调至更自然；蓝色只少量增加明度或层次，不要重度加饱和。
6. 最后做遮罩锐化：主要作用在丘陵轮廓和中景草地，避免锐化天空与虚化近景。

# 下一次练习任务

在同一片开阔场景完成“前景有无”三联拍：第一张完全不要近景，只拍干净的丘陵与天空；第二张只保留画面底部 10%–15% 的近景；第三张选一丛完整花草作清晰主前景。三张保持相同曝光和大致相同丘线，回看时只比较哪种方案的第一落点最清楚、边缘最干净、空间感最强。
