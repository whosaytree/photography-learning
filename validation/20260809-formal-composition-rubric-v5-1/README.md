# V5.1 原版最小修订候选

## 相对正式原版的修改

V5.1每次都从正式 `SCORING_RUBRIC.md` 直接派生，不继承V2—V5正文。只修改原版三个章节，解决五个已由校准样本明确暴露的问题：

1. 硬伤表：加入唯一主体／落点窄例外，并明确任何其他硬伤生效时例外不可用。
2. 高分资格：实际使用例外时，同一形式关系产生的构图、颜色和氛围只能算一个强项。
3. 高分资格：未使用例外时，独立于构图且故事达到7分的状态／动作／空间关系可以成为第二强项。
4. 故意效果：柔焦必须有可靠的主体清晰锚点才能逃离失焦封顶。
5. 故意效果：稳定背景下、选择性作用于运动主体并强化动作的模糊可以不触发意外运动模糊封顶。

## 明确没有加入

- 没有A/B/C/D分类。
- 没有额外评分阶段或重写硬伤定义。
- 没有全局性的形式构图加分段落。
- 没有封顶上沿限制、高分保护或历史分数提示。

## 独立校准

- 使用同一批35张样本，每张全新上下文完整评分。
- 评分者只读取摄影框架、V5.1完整候选规则、该照片的 `metadata.json` 与 `original.*`。
- 禁止读取正式旧点评、旧分、历次结果、其他V5.1结果、其他照片、分组和验收目标。
- 不使用批量评分脚本，不压缩单张流程；全部完成后才比较。

## 验收条件

1. 不出现总体分降低。
2. 通用硬伤保护样本不提高。
3. 未使用窄例外的非目标照片相对旧分变化不超过0.2。
4. 原7.5分以上照片不降低。
5. 旧分低于6的目标照片不得仅凭同一形式证据进入7.5。
6. 例外只能在没有其他硬伤时使用。
7. 正式规则在用户确认前保持不变。
