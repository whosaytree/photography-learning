# 一句话总评

低机位与两组斜向木架把晾挂的花布组织成了有张力的图形画面，色彩和重复节奏很吸引人，但灰白天空、偏暗的布面以及底边闯入的人头削弱了完成度。

## 评分前检查

- **主体：** 两组木架上成排垂挂的彩色花布，重点在花布的重复、纹样与空间阵列，而不是某一块单独的布。
- **题材：** 民俗／手工艺场景中的环境与形式构成摄影；不是单纯物品登记，画面有明确的低机位、对角线和负空间设计。
- **基础问题等级：** 无。主体可辨，画面方向正常，曝光和清晰度足以支撑观看。
- **逐项硬伤检查：** 主体没有不可读或明显虚焦；未见手抖或运动模糊破坏主体；亮天空细节很少，但没有导致花布主体不可辨，未达到严重过曝封顶；布面偏暗但纹样仍可读，未达到严重欠曝封顶；木架倾斜主要来自低机位透视和主动的对角线构成，不按误倾斜处理；左右木架和花布自然延伸出画面，主体结构仍完整；底边中央的人头是明显的小干扰和不利落的边缘切入，但面积有限，没有覆盖主体或打断主要视觉路径，因此不触发硬伤封顶；主体大小足够；画面有形式设计，不属于无视觉故事的普通记录；没有跨维度的多项严重问题。
- **高分资格：** 主体明确、边缘与视觉重量大体受控，也有超出记录价值的构图意图；构图是清楚的强项，但技术、光线和叙事尚未形成第二个同等级强项，因此不进入 7.5 分以上档位。阻碍进一步提升的核心是天空与布面亮度失衡、底部干扰，以及缺少更明确的视觉落点或人物关系。
- **故意处理判断：** 低机位、大片天空、左右分组、斜线和花布重复至少同时具备受控构图、稳定视觉锚点和明确形式惯例，可判断为故意处理；布面偏暗、天空发白和底边人头没有强化主题，不视为有效的故意效果。

## 五项评分

- **技术：6.5/10** — 花布轮廓和大部分纹样清楚，没有明显抖动或误焦；但逆光下主体暗部偏沉，天空接近一片灰白，整体还有轻微偏冷、偏紫的感觉，层次不够干净。
- **构图：7.5/10** — 两组木架从左右向中部抬升，形成强烈对角线、重复节奏与开阔负空间，低机位让普通晾布场景有了结构感。中央天空把两组主体分开，也给画面呼吸；不足是视线沿斜线移动后没有一个特别明确的最终落点，底边人头又把注意力拉向画外。
- **光线：5.5/10** — 阴天逆光让花布局部有一点半透明感，也避免了硬阴影，但主体与天空反差处理不够好：天空缺少云层层次，花布暗部颜色和纹理被压住，光线更多是在保证可见，而不是主动塑造主体。
- **叙事：6.5/10** — 成排花布、木架和露天环境能够传达手工艺晾晒或展示现场的场景感，并通过规模与重复形成视觉想法；但缺少制作动作、人物关系或关键瞬间，故事仍停留在“场景／氛围”层级。
- **总体：7/10** — 这是有明确视觉组织、明显高于随手记录的初学者作品，最突出的价值是低机位和重复图案构成；若控制好天空、提亮布面并清理底边，画面会更完整。

## 色彩观察

画面的主色印象是冷灰蓝天空与偏蓝紫的暗部，花布提供红、黄、绿、蓝等多色点缀。多种花色本身复杂，但因为被纵向重复和深色木架统一，整体没有完全失序；其中蓝紫布面与冷天空较接近，主体分离度稍弱，红黄纹样则成为有效的小面积视觉跳点。冷调让场景显得安静、略带阴天湿润感，但偏紫暗部使木架和部分花布显脏，鲜艳纹样也没有充分展开。后期宜先校正偏冷偏紫的白平衡，略加暖并减少洋红；再对布面局部提亮、轻提自然饱和度，重点保护红色和黄色不过饱和，同时压低蓝紫暗部的饱和度，让花布丰富但不浑浊。

## 封顶规则

无。

## 做得好的地方

1. **机位选择有想法。** 从下向上拍让木架形成有力量的斜线，花布也获得比平视记录更强的尺度感。
2. **重复与变化结合得好。** 花布都是竖向长条，形成稳定节奏；不同纹样和颜色又避免了机械重复。
3. **左右视觉重量基本平衡。** 左侧布面密、位置较低，右侧架子高、线条更强，两边并非镜像，却能够互相制衡。
4. **负空间有效。** 大片天空让复杂花纹不至于挤满画面，并强化了木架向上延伸的感觉。

## 优先修改项

### 1. 控制底边的人头干扰

- **问题：** 底边中央露出一截人物头部，切得突然且与主体没有形成动作关系。
- **为什么：** 人脸和肤色天然抢注意力，观众会先尝试辨认人物，再发现其并不承担故事功能，视觉路径因此泄出画面。
- **下次怎么拍：** 按快门前快速扫一遍四条边；等人物完全走进画面形成“人在布间工作”的关系，或等其完全离开后再拍。若时间紧，可略抬高镜头或向前一步排除底边。
- **这张怎么修：** 从底部裁掉约 5%—8%，以刚好去除人头为准；裁后检查左右最下方花布是否仍保持稳定落点。若不想改变比例，可用修复工具移除人头并重建后方暗部，但要避免留下重复纹理。

### 2. 缩小天空与布面的亮度差

- **问题：** 天空接近纯白，花布和木架则偏暗，主体纹理没有充分显现。
- **为什么：** 画面面积最大的天空成为最亮区域，眼睛容易停在缺少信息的白色处；真正有内容的花纹反而显得沉闷。
- **下次怎么拍：** 对亮天空测光并保留高光，拍 RAW；有条件时使用包围曝光，或等天空云层更有纹理、光线稍侧一些再拍。手机拍摄可点按天空与花布交界处测光，再将曝光略向下拉。
- **这张怎么修：** 全局降低高光和白色色阶，天空用渐变蒙版轻压约 0.3—0.7 挡；对花布建立主体蒙版，提升阴影和中间调约 0.3—0.5 挡。不要把木架黑位全部抬灰，仍需保留深色线条作为结构骨架。

### 3. 给斜线一个更明确的视觉落点

- **问题：** 木架线条很强，但左右斜线主要把视线带向中央亮天空，那里没有关键对象。
- **为什么：** 引导线有方向却缺少终点，形式感强于观看结果，画面因此容易在第一眼惊喜后迅速结束。
- **下次怎么拍：** 轻微左右移动，让一块色彩最鲜明的布、一个晾布动作中的人物，或两组架子的交会关系落在斜线趋向的位置；也可以降低天空占比，让花布本身成为明确终点。
- **这张怎么修：** 可尝试从左上和上方少量裁切，减少无信息天空，但不要裁掉右上架子的上升趋势；同时对中央附近一块红黄或蓝色花布做轻微局部提亮，使其成为次级落点。

### 4. 清理偏冷偏紫的暗部颜色

- **问题：** 木架和部分阴影布面带紫蓝色偏色，丰富花纹被压成相近的冷色块。
- **为什么：** 色彩层次会变脏，木架与蓝色花布也更容易粘连，削弱主体分离。
- **下次怎么拍：** 使用日光或阴天白平衡并拍 RAW；现场先检查一块原本中性的木架或灰色布面是否明显发蓝发紫。
- **这张怎么修：** 白平衡略向暖色移动，色调轻微向绿色回拉；在 HSL 中降低蓝、紫饱和度并适度提高蓝色明度，再只对花纹使用少量自然饱和度，避免全局猛加饱和。

## 建议设置

原始拍摄参数无法从画面可靠判断，以下是类似阴天逆光场景的估计起点：

- 使用 RAW，光圈优先或手动模式。
- 广角端约 24—35mm 等效焦距，保留低机位的空间张力，但注意边缘人物和杂物。
- 光圈约 f/5.6—f/8，让前后两组花布和木架都有足够清晰度。
- 手持快门不低于 1/250 秒，若布被风吹动可提高到 1/500 秒。
- 自动 ISO 可设上限 800；静风且机身稳定时优先使用较低 ISO。
- 以天空高光不溢出为准，曝光补偿可从 -0.3EV 到 -0.7EV 试拍，再在 RAW 中提亮布面。
- 单点或小区域对焦放在前景花布的纹样边缘，不要对着无纹理天空对焦。

## 后期步骤

1. 先裁掉底边人头，微调画面比例，同时保留左右木架向上延伸的完整趋势。
2. 开启镜头校正和色差去除；不必强行把所有斜线拉直，低机位透视正是这张照片的动势来源。
3. 校正白平衡：略加暖、轻减洋红，以木架暗部不发紫为准。
4. 降低高光和白色色阶，使用天空渐变压回灰度；若原文件已无云层细节，不要制造过重的假天空。
5. 用主体蒙版提亮花布中间调和阴影，轻加纹理、清晰度，让纹样可读；避免暗部出现光晕和噪点。
6. 局部压低蓝紫饱和度，对红黄纹样少量提升自然饱和度，建立更明确的色彩层级。
7. 对画面四角与边缘做最后清理，移除残留小枝叶或突兀碎片；输出前只做边缘遮罩锐化，不要锐化天空噪点。

## 下一次练习任务

回到类似成排物件或晾晒场景，完成一组 **“引导线必须有落点”** 的 9 张练习：固定低机位和相近焦段，分别拍 3 张以最鲜艳花布为落点、3 张以人物动作或手部为落点、3 张以两组结构交会处为落点。每次按快门前检查四条边，保证没有半截人物；回看时只保留视线能沿木架或花布自然走到明确终点的一张。
