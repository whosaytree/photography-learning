# V5.13 原版单一窄例外候选

V5.13 从正式原版直接生成，不继承 V5.12。与原版相比只改一处：在硬伤封顶总则中加入严格的结构场窄例外，使重复单元或两至三个大区域组成的画面不会仅因缺少孤立主体／局部落点而被封顶；原版其他分数定义、硬伤、逃逸、高分和故意处理规则全部保留。

## 独立校准

- 同一批 35 张，先进行 A、B 两组盲态独立完整评分。
- 每一次评分使用全新上下文，只读取摄影框架、V5.13 完整候选规则和当前照片原图／方向信息。
- 禁止旧点评、旧分、同图另一次结果、其他照片、分组与验收目标。
- A、B 全部完成后才比较；只有两次总体分差大于 0.2 时，才以同样隔离条件进行第三次评分并取中位数。
- 不做分布校正，也不依据旧分选择结果。

原始归档的 `metadata.json` 含历史评分。首次执行因此被整体判为盲态无效并删除；正式校准改用 `blind-inputs/` 中去除评分与评价字段的元数据副本和原图副本，从头重新执行 A、B 两组。

## 验收条件

沿用七项严格条件：不得降分；硬伤保护不提高；未用例外的非目标变化不超过 0.2；原高分不降低；旧分低于 6 的目标不因同源证据进入 7.5；例外不得绕过其他硬伤；正式规则保持不变。
