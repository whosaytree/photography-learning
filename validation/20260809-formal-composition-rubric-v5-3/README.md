# V5.3 原版最小修订候选

## 修改范围

V5.3 直接从正式原版派生，不继承 V5.2 正文：

1. 窄例外门禁只处理主体等价物及其关系之外的干扰；同一连续重复场内部的正常疏密、明暗和重量变化不自动禁用例外。
2. 使用例外时，同源的形式、色彩和情绪只算一个强项。
3. 未使用例外时，可见关系只有在故事至少 7、技术至少 6.5、无封顶且不重复构图证据时，才能成为第二强项。
4. 静态主体必须有可靠清晰锚点才能避开失焦封顶；重要彩色主体大面积失去内部层次时不能用高调解释避开曝光封顶。
5. 稳定背景下、选择性作用于运动主体且强化动作的模糊可不触发意外运动模糊封顶。

没有分类、额外评分阶段、全局形式加分、历史分数提示或封顶上沿限制。

## 独立校准

- 同一批 35 张，每张全新上下文完整评分。
- 只读取摄影框架、V5.3 完整候选规则、当前照片 metadata 与 original。
- 禁止旧点评、旧分、历次／其他 V5.3 结果、其他照片、分组与验收目标。
- 全部完成后才统一比较。

## 验收条件

1. 不出现总体分降低。
2. 通用硬伤保护样本不提高。
3. 未使用窄例外的非目标照片相对旧分变化不超过 0.2。
4. 原 7.5 分以上照片不降低。
5. 旧分低于 6 的目标照片不得仅凭同源形式证据进入 7.5。
6. 窄例外不得用于有其他硬伤、关系外大面积中断带或竞争性边缘碎片的照片。
7. 正式规则在用户确认前保持不变。
