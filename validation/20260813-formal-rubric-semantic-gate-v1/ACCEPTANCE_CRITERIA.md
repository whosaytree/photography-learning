# 语义边界候选 V1：预注册验收条件

零改动基线已证明：同一正式规则可以稳定维持整批均值，却不能稳定复现每张历史分数。因此本轮不再用逐张分差或分数极差验收，而只检验用户关心的语义边界、硬伤安全性和高分证据。

## 一、分档定义

- 历史高分：历史总体分达到7.5的11张（08、09、12、16、17、18、25、26、27、34、35）。
- 低分边界：低于6.5。6.5—7属于“可分享的初学者照片”，不视为低分。
- 高分边界：7.5及以上。
- 新增目标类校准样本：23、24、28、32。它们只代表需要被新规则公平识别的整幅排列、重复、区域或大块关系，不获得预设加分。
- 非目标旧低分：除上述4张目标样本外，历史分低于7.5的全部20张。

## 二、盲态有效性

以下任一失败，本轮即无效：

1. 候选从正式原版直接生成；只改预先列明的四个边界，不继承失败稿，不加入照片编号、历史分或题材特判。
2. 每张照片使用全新的独立评分上下文，只可读取摄影技能、唯一候选规则、本张盲态`metadata.json`和`original.*`。
3. 评分者不得读取正式规则、旧点评、历史分、样本分组、验收条件、事实审计、其他照片、其他轮结果或对话；不得使用批量评分脚本。
4. 35张全部完成前不读取本轮点评或分数，不得按分布、配额或验收结果回填。
5. 正式`SCORING_RUBRIC.md`保持原哈希，通过且获得用户确认前不得覆盖。

## 三、单轮探索门槛

以下条件全部满足，候选才值得进入三轮复验：

1. **旧高分不变低分**：11张历史高分全部达到6.5或以上；其中零改动三轮均稳定为高分的17、18、34、35仍须达到7.5或以上。
2. **非目标旧低分不变高分**：20张非目标旧低分全部低于7.5。
3. **目标类自由分层**：23、24、28、32不设最低分、目标分或机械增幅；是否上升只由本图完成度决定。若任何一张达到7.5或以上，必须通过与所有照片相同的高分证据审计。
4. **硬伤安全性**：10张事实硬伤（02、03、11、15、19、20、21、22、30、31）至少8/10命中正确硬伤大类并执行封顶；15的失焦与20的构图干扰必须命中；10张均不得达到6.5。
5. **无硬伤保护**：6张事实无硬伤（01、04、05、10、14、29）至少5/6不被误封顶。
6. **高分证据**：本轮每一次7.5或以上都必须同时满足无硬伤、至少两项真正强的维度、两项由不同可见事实支持；普通清晰、曝光可用或拍摄稳定不得冒充第二强项。8分还必须满足正式原版的8分条件，目标类别身份本身不算证据。

任一条件失败，下一候选仍从正式原版重新生成，不在本候选上追加规则。

## 四、三轮稳定复验门槛

探索轮通过后，另做三轮共105次全新独立评分。只检验分档是否稳定，不要求复现具体小数：

1. 11张历史高分的三轮中位数均不低于6.5；每张至少2/3轮达到6.5，且任何一次不得低于6.0。17、18、34、35的三轮中位数均不低于7.5，且各自至少2/3轮达到7.5。
2. 20张非目标旧低分的60次评分中至少58次低于7.5；任何一张不得在2/3轮或3/3轮成为高分。
3. 4张目标类不设分数分布要求；任何一次达到7.5或以上都必须通过统一证据审计，不因类别身份加分。
4. 真实硬伤30次判断中至少24次命中正确大类；每张至少2/3轮正确；15和20必须3/3正确。每一次事实硬伤照片的总体分都不得达到6.5。
5. 无硬伤18次判断中至少15次不误封顶；每张至少2/3轮不误封顶。
6. 所有实际7.5或以上的结果，事后证据审计通过率必须为100%；任何一张不得只靠一次偶发的资格判断进入高分。

三轮全部通过后仍只提交用户确认；未经明确确认，不覆盖正式规则。
