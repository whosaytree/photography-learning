# 一句话总评

这是一张有海边独处气氛、人物位置也有意识的环境人像，但人物偏软、画面污点和栏杆对身体的横向切割，让它停在“有想法但执行还不够干净”的阶段。

# 评分前检查

- **主体：**画面右侧、背对镜头望向海面并举起蓝色物件的人物；海面、远山与大面积天空共同交代环境。
- **题材：**海边环境人像／旅行氛围照，重点不是身份辨认，而是人物面对海面的动作和空间关系。
- **基础问题等级：**基础问题。人物轮廓和动作可以正常辨认，但主体细节偏软，天空右侧有明显污点，整体通透度不足。
- **逐项硬伤检查：**
  - 主体不可读：不触发，人物、朝向和动作均清楚。
  - 主体存在但不清楚或弱：不触发，人物在海天背景上有足够的明暗分离，并落在右侧视觉重心。
  - 严重失焦：不触发，人物没有糊到失去轮廓或动作信息。
  - 主体细节比次要细节更软且无稳定锚点：不触发硬封顶。人物确实偏软，但栏杆、海平线提供稳定参照，构图关系仍可读；这仍会明显扣技术分。
  - 严重或明显手抖／运动模糊：不触发，没有整幅同方向拖影；人物头发和手部的轻微软更像对焦、隔着介质拍摄或轻微运动共同造成。
  - 重要高光大面积丢失：不触发，天空和衣服亮部仍有基本层次。
  - 重要阴影大面积丢失：不触发，黑裙虽暗，但外形和褶皱仍能辨认。
  - 地平线／垂直线意外倾斜：不触发，海平线基本稳定。
  - 干扰、裁切、边缘切割或失衡：不触发硬封顶，但天空右侧污点会反复抢注意力，栏杆又横穿人物腰背和手臂，属于明显的构图减分项。
  - 主体过小且无法裁切恢复：不触发，人物尺寸足够，仍是明确落点。
  - 普通记录、缺乏可见摄影叙事：不触发。背身、海面、举手动作和空旷天气共同形成了可读的场景情绪，已超过纯地点记录。
  - 光线平淡且故事弱：不触发组合封顶。光线偏平，但人物与海的空间关系和动作提供了基本叙事。
  - 多个不同维度重大问题叠加：不触发，现有问题会削弱完成度，但没有阻断正常观看。
- **高分资格：**不具备 7.5 分以上资格。主体关系明确，也有负空间和动作，但技术清洁度、人物锐度、栏杆切割及光线塑形都没有达到两个维度清晰的 7 级证据。
- **故意处理判断：**背身、人物右置和大面积天空应是有意营造空间感；至少有清楚主体、稳定的海平线／栏杆锚点和可读的空间组织。人物偏软、天空污点及低通透感没有形成选择性表达，也不强化动作或情绪，因此按执行问题处理，而不当作故意的柔焦风格。
- **窄结构场例外：**未使用。画面不是由重复单元覆盖全幅，也不是两三个大色块依共享边界构成“整体场域主体”；它有清楚、具体的单一人物落点，本来就不触发“主体存在但不清楚或弱”。
- **故事证据等级：**场景／情绪。人物背向镜头望海、举起物件的动作和空旷海天建立了轻松又略带独处感的氛围，但还没有更强的表情、关系或决定性瞬间。

# 五项评分

- **技术：5.0/10。**曝光可读、方向正常、海平线稳定，但人物细节偏软，整体略雾，天空右侧污点清晰可见；技术表现基本够用，尚不干净。
- **构图：6.5/10。**人物放在右侧、面向左侧海面，视线和动作都获得空间，海平线与栏杆形成横向秩序；不足是栏杆穿过人物躯干和手臂，大面积天空缺少有效细节，污点也破坏了负空间的纯净。
- **光线：5.5/10。**阴天光避免了强烈高光和死黑，蓝色环境有一定气氛，但光线较平，人物缺少轮廓光和面部／服装的立体塑形，远景也显得灰蒙。
- **叙事：6.5/10。**背身人物、风吹头发、举起物件与海景形成“面对海面玩耍或停留”的可读情境，比纯风景记录多了一层动作和情绪；由于看不到表情，物件含义也不够明确，故事还停留在简单氛围层。
- **总体：6.0/10。**它有清楚的人物—海面关系、可读情绪和一定构图意图，已超过普通记录照；但人物锐度、画面洁净度和栏杆分割明显降低完成度。

# 色彩观察

画面以低饱和的青蓝色为主，黑白服装形成中性色落点，蓝色物件与海水有呼应，整体搭配协调，传达阴天海边的清凉、安静感。问题是青蓝几乎覆盖天空、远山和海面，层次容易黏在一起，人物白衣也略偏冷；天空灰蓝区域中的污点因负空间单纯而更显眼。后期可先校正白平衡，略加暖中间调但保留海水冷感，再适度去雾、压低青色饱和度并提高蓝色明度差；人物区域单独提亮约 0.2—0.4 档，避免全局猛加饱和度。

# 封顶规则

无。人物偏软、污点和栏杆切割均造成扣分，但当前可见程度尚未达到候选规则中的硬伤封顶条件。

# 做得好的地方

- 人物不在正中央，右侧落点与左侧海面形成较自然的呼吸空间，背身朝向也与留白方向一致。
- 海平线、栏杆和地面形成清楚的横向层次，人物作为竖向元素打破水平线，画面骨架容易读。
- 人物举起蓝色物件、头发被风吹动，给静态海景增加了一点动作和现场感。
- 青蓝环境与黑白服装关系简洁，没有杂乱的多色竞争，情绪方向统一。

# 优先修改项

## 1. 先保证人物成为最清楚的落点

- **问题：**人物轮廓和衣服细节偏软，清晰度没有明显胜过栏杆等次要元素。
- **为什么：**人物是叙事中心，若主体不够清楚，观众会先看到栏杆和污点，动作的感染力也会减弱。
- **下次怎么拍：**在人物眼睛或上半身使用单点对焦／连续对焦；快门至少提高到约 1/250 秒，风大或人物持续动作时提高到 1/500 秒；尽量不要隔着有污渍的玻璃拍，拍前清洁镜片或拍摄介质。
- **这张怎么修：**对人物做局部纹理与锐化，幅度要小，并配合降噪；避免全图重锐化，否则栏杆和污点会更突出。若原片本身已经失焦，后期只能改善观感，不能真正恢复细节。

## 2. 调整机位，避免栏杆切过人物核心部位

- **问题：**最粗的栏杆横穿人物腰背，另一条结构又靠近手臂，人物被背景线条分割。
- **为什么：**强水平线会把人物拆成几段，削弱轮廓完整性，也让栏杆比人物更有存在感。
- **下次怎么拍：**尝试稍微抬高机位，让粗横杆落到人物腰部以下；或降低机位，让横杆明确成为前景框架但不要穿过头、肩、手等关键动作部位。拍前沿人物轮廓快速检查一圈背景交叠。
- **这张怎么修：**可从底部裁掉一部分空地、从顶部适量裁去空天空，形成更紧凑的横幅；栏杆本身不建议大面积修除，以免产生明显伪影，但可轻微压暗和降低清晰度，让它退后。

## 3. 清理负空间并增强海天层次

- **问题：**天空右侧污点明显，天空、远山和海面之间的反差偏低，大面积留白不够纯净。
- **为什么：**负空间越简单，任何污点越容易成为竞争落点；层次过灰也会使本应安静的留白变成松散空白。
- **下次怎么拍：**检查镜头、保护镜和拍摄玻璃是否干净；阴天可等待云层出现明暗变化，或换到侧光更明显的时段；拍摄时保留高光并记录 RAW，方便后期拉开层次。
- **这张怎么修：**用修复工具清掉天空污点；对远山与海面分别做轻微去雾和局部对比，天空只做温和渐变压暗，避免把噪点、色带和灰尘一起强化。

# 建议设置

以下为根据画面估计的起点，并非原片参数：手持拍摄可用快门优先或手动模式，快门约 **1/250—1/500 秒**，光圈约 **f/4—f/5.6**，自动 ISO 并尽量控制在画质可接受范围；使用单点 AF-C／连续对焦锁定人物上半身，连拍 2—3 张捕捉手势和头发状态。若隔着玻璃拍摄，让镜头尽量贴近玻璃、避开反光和污渍，并关闭会在玻璃上产生反光的闪光灯。

# 后期步骤

1. 先用修复工具清除天空右侧的污点和小斑痕。
2. 轻微校正白平衡，让人物白衣回到较中性，同时保留海景的冷色基调。
3. 对远山和海面少量增加去雾、对比和黑色色阶，分开天空—山—海三个层次。
4. 给人物建立局部蒙版，提亮约 0.2—0.4 档，略加纹理和锐度；检查黑裙不要压成一片死黑。
5. 降低栏杆的局部清晰度或亮度，使其退后，但保留真实结构。
6. 尝试裁成更紧凑的横幅：减少顶部空天空和底部空地，同时保留人物面向一侧的空间。
7. 最后检查青色是否过量；若海水显得发荧光，适度降低青色饱和度，并用蓝色明度而不是饱和度来拉开层次。
