# V4 语义分组确认轮：预注册验收条件

## 分组

- 历史高分11张（历史≥7.5）：08、09、12、16、17、18、25、26、27、34、35。
- 真正旧低分且非目标16张（历史≤6.0）：01、02、03、04、05、10、11、14、15、19、20、21、22、29、30、31。
- 中间档4张（历史6.1—7.0，非目标）：06、07、13、33。它们不预设维持或升降，只受统一高分证据约束。
- 目标类4张：23、24、28、32，自由分层。
- 事实硬伤10张：02、03、11、15、19、20、21、22、30、31。

## 有效性

每张用全新独立上下文，只读取摄影技能、确认轮唯一候选、本张盲态元数据与原图；不得读正式规则、验收、历史资料、其他照片、候选、结果或对话；不得用批量评分脚本。35张全部完成前不读取结果。正式规则哈希不变。

## 单轮门槛

1. 历史高分至少10/11达到6.5，任何一张不得低于6.0。
2. 真正旧低分至少15/16低于7.5；事实硬伤10/10不得达到7.5。
3. 中间档与目标类不设分数分布；任何高分都执行统一证据审计。
4. 所有实际7.5以上必须100%满足：无生效硬伤；至少两项明显强维度；每项各有独立可见事实和结果；普通技术7不算第二强项；8/8.5符合原版定义。
5. 硬伤正确大类和无硬伤误封只作诊断；只有事实硬伤进入高分才构成边界失败。

## 三轮复验门槛

确认轮通过后，以同一V4候选再做三轮105次评分：历史高分每张中位数不低于6.5且无单次低于6.0；真正旧低分每张中位数低于7.5；事实硬伤无一次达到7.5；中间档和目标类不设分布；所有实际高分证据审计100%通过，任何一张不得只在1/3轮偶发高分；硬伤若某张3/3系统误判则不放行。

三轮全部通过后仍须用户确认才可覆盖正式规则。
