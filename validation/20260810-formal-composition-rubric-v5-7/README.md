# V5.7 重复独立校准

V5.7 的规则正文与 V5.6 相同，仍为正式原版加 7 行严格结构场窄例外；不再增加任何评分条款。

## 校准协议

- 同一批 35 张；每张先做两次完整、相互隔离的独立评分。
- 每次只读取摄影框架、V5.7 完整规则和当前照片原图／方向信息。
- 禁止旧点评、旧分、同图其他评分、其他照片、分组与验收目标。
- 两次总体分差异超过 0.2 时，再追加第三次全新上下文独立评分。
- 每次都生成完整点评，不压缩；全部结束后才逐图取五项中位数并验收。

## 验收条件

沿用七项严格条件：不得降分；硬伤保护不提高；未用例外的非目标变化不超过 0.2；原高分不降低；旧分低于 6 的目标不因同源证据进入 7.5；例外不得绕过其他硬伤；正式规则保持不变。
