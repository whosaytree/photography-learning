# 摄影点评

**一句话总评：** 这是一张有安静海港感的环境风景：海面、橙色浮标线、防波堤与两座灯塔建立了观看顺序，但过大的空白天空和偏平的光线让画面的力度还没有完全集中到灯塔与堤岸关系上。

## 评分前检查

- **主体：** 右侧近处的条纹灯塔与横向延伸的防波堤；左侧小岛灯塔是呼应元素。
- **题材：** 海港环境风景，具有明确的画面组织意图，不只是地点记录。
- **基础问题等级：** 无。画面可正常观看，主体、海平线和空间关系都清楚；主要问题是取景取舍与光线表现力，而非基础失败。
- **硬伤封顶检查：** 主体可读；没有明显意外虚焦、抖动、重要细节过曝/欠曝、方向错误或严重倾斜。边缘没有会抢走主体的硬性切割，灯塔虽偏小但仍可通过适度裁切强化，且当前广阔空间有环境叙事作用。未触发封顶。
- **高分资格：** 不满足 7.5 分门槛。主体与空间关系成立，但光线没有成为强项，天空留白也没有提供足够强的形状或气氛来支撑其占比。
- **故意处理判断：** 大面积留白与小主体有两项有效证据：海面和天空形成稳定的尺度感，左右两座灯塔与堤岸线构成可读的视觉关系；因此按有意的环境式构图评价，而非把小主体直接视为失误。不过留白的表现仍可更凝练。
- **窄结构场例外：** 未使用。画面有明确的灯塔、堤岸和视觉落点，不属于无主体的均质场或简单区域场。

## 色彩观察

主色是偏青蓝的海与天空，白色灯塔和橙色浮标线形成冷暖对比。橙色是很有效的次要引导色，让视线从水面进入堤岸；但整体偏青、天空又较淡，画面略显漂白，右侧灯塔与背景的分离度不够。后期可略微降低青色饱和度、把蓝色明度压低一点，并只小幅提升橙色浮标的饱和度和明度；不要整体猛加对比，以免海面变脏、天空出现断层。

## 做得好的地方

- 横向防波堤把左右两处灯塔联系起来，空间不是散的。
- 浮标线在前景提供了一个不生硬的进入点，冷海水中的橙色也增加了节奏。
- 人物虽小，但让堤岸的尺度和海港的日常感变得可感。

## 优先修改项

1. **问题：天空留得太多，但云层和明暗没有足够内容承接。**  
   **为什么：** 视线会在大面积浅色区域停留，削弱灯塔作为落点的力量。  
   **下次怎么拍：** 向下压低取景，保留约三分之一天空；或等待有云纹、斜射光时再使用大留白。  
   **这张怎么修：** 从上方裁去约 15%–20%，同时少裁一点左侧，让浮标线的入口和左岛仍在。

2. **问题：主灯塔与堤岸的明暗分离不够。**  
   **为什么：** 主体虽在右侧，却没有立即从浅色背景中跳出来。  
   **下次怎么拍：** 尝试清晨、傍晚或侧逆光，让塔身、堤石和海面出现不同亮度层次。  
   **这张怎么修：** 对右侧灯塔和堤岸做局部微加对比、微降背景高光；幅度要小，保留海边雾感。

3. **问题：画面有“人走在堤上”的潜在线索，但人物太分散。**  
   **为什么：** 叙事停留在风景氛围，尚未形成一个明确的观看瞬间。  
   **下次怎么拍：** 等一两个人走到主灯塔附近、姿态清楚时再按快门，或用更长焦把人物与灯塔压近。  
   **这张怎么修：** 不建议强行放大人物；保留其作为尺度细节即可。

## 建议设置

画面无法可靠判断实际参数，以下为海港日景的**估计建议**：若手持拍摄，优先使用 ISO 100–200、f/5.6–f/8、1/500 秒或更快；若用较长焦或风大，提升到 1/1000 秒。对亮天空测光后可尝试 -0.3 EV，保护浅色天空，再在后期轻提堤岸阴影。

## 后期步骤

1. 开启镜头校正，并确认海平线保持水平。
2. 上方裁切约 15%–20%，再检查左岛、主灯塔和浮标入口是否仍均衡。
3. 全局轻微降低高光，增加少量去朦胧和中间调对比；不要让远景变硬。
4. 用局部蒙版加强右侧灯塔、堤岸的纹理与对比，再轻压其背后的亮背景。
5. 在 HSL 中略降青色饱和度，微压蓝色明度；只选择性提亮橙色浮标线。
