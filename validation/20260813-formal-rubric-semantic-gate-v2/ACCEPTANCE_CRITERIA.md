# 语义边界候选 V2：预注册验收条件

本轮沿用V1的语义分档定义，但删除超出用户要求的“稳定锚点必须继续达到7.5”附加条件。历史高分只需守住6.5，不要求复现原高分小数或继续具备高分资格。

## 一、分组与边界

- 历史高分11张：08、09、12、16、17、18、25、26、27、34、35。
- 低分边界：低于6.5；6.5—7不算低分。
- 高分边界：7.5及以上。
- 目标类4张：23、24、28、32。
- 非目标旧低分20张：除目标4张外，历史分低于7.5的全部照片。
- 事实硬伤10张：02、03、11、15、19、20、21、22、30、31。
- 事实无硬伤6张：01、04、05、10、14、29。

## 二、盲态有效性

1. 候选从正式原版直接生成，只改整幅排列主体例外、失焦硬伤、构图硬伤和两项独立强项四处，不继承V1文字。
2. 每张照片使用全新的独立评分上下文，只读取摄影技能、唯一候选规则、本张盲态元数据与原图。
3. 评分者不得读取正式规则、验收条件、旧分、旧点评、事实审计、其他照片、其他候选或结果、分组与对话；不得使用批量评分脚本。
4. 35张全部完成前不读取任何结果，不得按分布、配额或预期回填。
5. 正式规则保持原哈希，用户确认前不得覆盖。

## 三、单轮探索门槛

1. 历史高分11/11总体均不低于6.5。
2. 非目标旧低分20/20总体均低于7.5。
3. 目标类不设最低分、目标分、增幅或分布；若达到7.5，执行同一高分证据审计。
4. 事实硬伤至少8/10命中正确大类并实际执行封顶；15失焦与20构图必须命中；10张总体均低于6.5。
5. 事实无硬伤至少5/6不被误封顶。
6. 每一次总体7.5或以上都须100%满足：无硬伤；至少两项真正强的维度；两项各有不被另一项独占的可见事实和不同可观察结果；普通技术7不算第二强项。8分另须满足正式原版8分条件。

任一失败则不进入复验；下一候选仍从正式原版生成。

## 四、三轮复验门槛

探索轮通过后再进行105次全新独立评分：

1. 历史高分11张三轮中位数均不低于6.5；每张至少2/3轮达到6.5，任何一次不得低于6.0。
2. 非目标旧低分60次中至少58次低于7.5；任何一张不得在2/3轮成为高分。
3. 目标类不设分布；每次达到7.5均须通过统一证据审计。
4. 事实硬伤30次至少24次命中正确大类，每张至少2/3轮正确，15与20必须3/3；每次总体均低于6.5。
5. 无硬伤18次至少15次不误封顶，每张至少2/3轮不误封顶。
6. 所有7.5及以上结果的证据审计通过率100%，且任何一张不得只在1/3轮偶发进入高分。

三轮全部通过后仍须用户确认，才可覆盖正式规则。
