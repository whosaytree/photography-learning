# V5.18 验收条件

1. 原分不低于 7.5 的照片，下降不得超过 0.2，提升不得超过 0.2。
2. 未使用结构场例外的非目标照片，总体变化绝对值不得超过 0.2。
3. 硬伤保护样本不得明显提高，总体提升不得超过 0.2。
4. 四张目标照片只允许有限提升：提升不超过 1.0，且不得因结构场资格事实本身进入 7.5 档。
5. 结构场例外只可把“主体存在但弱／含糊”一项的 5.0 上限放宽到 6.0；不得绕过其他硬伤，不得建立高分资格。
6. 不使用旧分、分组、分布、其他照片或其他结果影响任何一次单图评分。
7. 正式 `SCORING_RUBRIC.md` 保持不变；候选通过后仍须等待用户确认才可覆盖。
