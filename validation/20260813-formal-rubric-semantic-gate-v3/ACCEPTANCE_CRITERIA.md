# 语义边界候选 V3：预注册验收条件

## 分档和分组

- 历史高分11张：08、09、12、16、17、18、25、26、27、34、35；低分边界为6.5以下。
- 非目标旧低分20张：除23、24、28、32外，历史分低于7.5的全部照片；高分边界为7.5。
- 目标类4张：23、24、28、32，不设最低分、目标分或增幅。
- 事实硬伤10张：02、03、11、15、19、20、21、22、30、31。
- 事实无硬伤6张：01、04、05、10、14、29。

## 盲态有效性

每张必须使用全新独立上下文，只读取摄影技能、V3唯一候选、本张盲态元数据与原图；不得读取正式规则、验收条件、历史资料、其他照片、结果或对话；不得用批量评分脚本。35张全部完成前不读取结果。正式规则保持原哈希。

## 探索门槛

1. 历史高分11/11不低于6.5。
2. 非目标旧低分20/20低于7.5。
3. 目标类自由分层；任何7.5以上执行统一证据审计。
4. 事实硬伤至少8/10命中正确大类并执行；15失焦与20构图必须命中；10张总体均低于6.5。
5. 事实无硬伤至少5/6不误封顶。
6. 每次7.5以上均须100%满足：无硬伤；至少两项各有独立事实和结果的真强维度；普通技术7不算；不存在两项或以上分别削弱主体呈现、路径、边缘、光线或故事的明显限制。8分另须满足原版8分条件。

## 三轮复验门槛

探索通过后才做105次复验：历史高分每张中位数不低于6.5、至少2/3轮达到6.5且无一次低于6.0；非目标旧低分至少58/60低于7.5且无一张2/3轮成为高分；目标类不设分布；硬伤至少24/30正确、每张至少2/3、15与20为3/3且每次总体低于6.5；无硬伤至少15/18且每张至少2/3不误封；所有7.5以上证据审计100%通过且不得仅1/3轮偶发高分。

全部通过后仍须用户确认才可覆盖正式规则。
