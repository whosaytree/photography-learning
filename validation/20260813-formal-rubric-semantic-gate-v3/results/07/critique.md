# 一句话总评

孩子奔跑的姿态、地面影子和弯曲小路构成了清楚的夏日动感，但主体的运动模糊明显削弱了人物细节与观看落点，画面目前更像抓到了瞬间却没有把瞬间拍稳。

# 评分前检查

- **主体：** 画面中央偏左、沿小路向前奔跑的孩子；人物轮廓、抬起的腿和帽子使主体可以立即辨认。
- **题材：** 户外生活纪实／儿童动态抓拍。它不只是地点记录，奔跑动作与影子提供了明确的瞬间证据。
- **基础问题等级：** 基础问题。主体仍然可读，但人物从帽沿、上衣到腿脚都出现方向一致的明显运动模糊，关键细节没有稳定下来。
- **逐项硬伤检查：**
  - 主体不可读：否。
  - 主体存在但不清楚或过弱：否；人物具有足够的尺寸、位置和动作辨识度。
  - 主体严重意外虚焦：否；并未模糊到难以辨认。
  - 主体明显意外虚焦但仍可读：不按失焦处理；可见弱点更符合人物运动造成的方向性模糊。
  - 严重手抖或运动模糊使主体难读：否。
  - 明显手抖或运动模糊削弱主体：是；主体的脸部、衣服图案、手脚边缘均缺少稳定细节，因此技术分最高 5.0、总体分最高 5.5。
  - 严重过曝或欠曝遮蔽主体细节：否；日照很强，白色衣帽偏亮，但仍可辨认主要形状与部分纹理。
  - 方向、地平线或垂直线意外倾斜：否；观看方向正常，主要垂直物没有形成阻碍观看的明显倾斜。
  - 主导干扰、尴尬裁切、边缘切入或视觉失衡：未达到硬伤。右侧被截断的灯杆和远处行人会分散注意，但没有遮挡主体，也没有大面积破坏道路的引导关系。
  - 主体过小且无法通过裁切恢复：否。
  - 普通记录且无可见摄影叙事：否；奔跑姿态与影子构成了一个可读的动态瞬间。
  - 光线平淡且叙事弱：否；光线虽普通且偏硬，但瞬间叙事并不弱到只剩记录信息。
  - 多个不同维度的重大问题：否；主要硬伤集中在动态清晰度。
- **故事证据等级：** 关系／瞬间／视觉想法。动作本身、抬起的右腿与同步延伸的影子让人直接感到“正在奔跑”，不仅是在说明公园里有一个孩子。
- **高分资格：** 不具备。主体清楚、道路引导和动态瞬间都有意图，但技术硬伤已经触发总体封顶；同时右侧边缘灯杆、偏空的右下路面和正午硬光也没有控制到强作品水平。
- **故意处理判断：** 奔跑动作显然是画面的表达核心，但模糊不像成功的故意动感：虽然背景比人物稳定、动作方向可读，画面却没有形成清楚的锐利锚点，也没有流畅、选择性的拖影效果，主体重要细节只是变软。满足的意图证据不足，按意外运动模糊处理。较大的道路空间有一定现场感和运动方向感，但不是足以抵消主体模糊的成熟负空间设计。

# 五项评分

- **技术：5.0/10** —— 曝光整体可读，背景环境也有基本分辨率，但主体存在明显运动模糊，人物面部、衣服和四肢的关键边缘都不够稳定；依规则技术分封顶 5.0。
- **构图：6.0/10** —— 道路边缘和两侧绿篱形成自然引导，视线能落到奔跑者并继续向远处延伸；但人物接近画面中部，右下路面占比偏大，右缘灯杆与远处零散人物让边缘控制不够简洁，视觉重量略向右侧空地散开。
- **光线：5.5/10** —— 强烈日光让人物和影子分离，也强化了动作感；不过光质偏硬，衣帽亮部较刺眼，脸部被帽檐和背向光线压暗，光线主要负责照亮场景，未能很好塑造人物。
- **叙事：6.5/10** —— 抬腿奔跑的姿态、前方道路和地面影子共同给出明确瞬间，能让人联想到孩子向前冲去的活力；但人物背对镜头，缺少表情、互动对象或明确目的地，故事停留在简单动作层面。
- **总体：5.5/10** —— 这是有瞬间意识、有引导结构的动态抓拍，但主体恰好是最需要清楚的部分，却被明显运动模糊削弱；叙事强项让它高于纯记录照，但总体受硬伤限制在 5.5。

# 色彩观察

画面的主色是高饱和的黄绿色植被，辅以大面积偏粉红的道路和清亮蓝天，整体感觉明快、炎热、带有夏日公园气息。绿与粉红形成较明显的色相分区，白色上衣和蓝色裤子也帮助人物从背景中分离；不过植被的绿色偏艳、部分暗部略脏，粉红路面面积很大且饱和度不低，容易与人物争夺注意。白平衡没有明显失控，但整体暖意与强光感略重。后期可轻降绿色和黄色饱和度约 5—15，并略压绿色明度；同时将路面的红／洋红饱和度轻降，人物蓝色与白色只做局部提亮和微量对比，让颜色层级从“环境很艳”转为“人物先被看见”。

# 封顶规则

明显手抖或运动模糊削弱主体：技术分最高 5.0，总体分最高 5.5。本图按人物运动造成的明显模糊执行该封顶。

# 做得好的地方

1. **动作时机可读。** 一脚着地、一脚后抬的姿态处在完整的跑步步态中，不需要文字说明也能看出速度和方向。
2. **影子增加了动态信息。** 地面影子轮廓独立、方向明确，既交代强烈日照，也把孩子的动作在画面下方重复了一次。
3. **环境线条能带动视线。** 道路与绿篱向远处收拢，使主体不是孤立地贴在背景上，而是处于一条可继续前进的空间路径中。
4. **人物具有基础色彩分离。** 白色上衣和蓝色裤子在绿色背景、粉红路面之间容易被发现，主体识别没有被复杂植被吞没。

# 优先修改项

## 1. 先把奔跑中的主体拍清楚

- **问题：** 人物全身出现明显的方向性运动模糊，尤其是脸部、上衣图案和腿脚。
- **为什么：** 这张照片的价值依赖奔跑瞬间；主体一软，观看者看到的是“孩子在跑”，却看不到这个孩子和这个瞬间的具体细节，视觉落点会松掉。
- **下次怎么拍：** 使用连续自动对焦和人物／眼部追踪，提前对准孩子将经过的位置，采用高速连拍；把最低快门设为 1/800 秒，跑动较快时提高到 1/1000—1/1600 秒，宁可提高 ISO，也不要让快门降下来。
- **这张怎么修：** 后期无法真正恢复丢失的运动细节。可用主体蒙版少量增加纹理与锐化，并配合降噪，但不要把锐化推到出现白边；最终适度缩小输出尺寸，会比强行放大更自然。

## 2. 收紧右侧与下方的空量，强化“向前跑”的方向

- **问题：** 右下方粉红路面占据较大面积，右缘被截断的灯杆较抢眼，主体周围的视觉重量没有完全服务于运动方向。
- **为什么：** 道路本应把眼睛带向孩子和前方，但大块空路面及高反差灯杆会把注意拉回边缘，减弱瞬间的集中度。
- **下次怎么拍：** 在孩子进入画面前先确定路线，稍向右移动机位或把镜头朝左前方多留空间，让孩子位于右侧三分之一附近、运动方向前方保留空间；拍摄前快速扫一遍四边，避开灯杆贴边切入。
- **这张怎么修：** 建议从右侧裁去约 8%—12%，从下方裁去约 8%—10%，尽量移除灯杆并减少空路面，同时保留孩子前方弯曲道路和完整影子。裁切后检查人物不要被重新压到正中央。

## 3. 控制正午硬光与高饱和环境色

- **问题：** 白色衣帽偏亮，脸部受帽檐与背光影响偏暗；黄绿色植被和粉红路面都较艳。
- **为什么：** 亮部和高饱和背景容易先抓住视线，人物面部却缺少光线信息，主体层级因此不够稳定。
- **下次怎么拍：** 若时间可选，改在早晚斜射光或明亮阴影处拍；若只能在正午，改变站位让孩子获得侧前光，并对高光做约 -0.3EV 的保护，拍 RAW 以保留衣帽亮部。
- **这张怎么修：** 全局高光降低约 20—35，白色色阶降低约 5—15；人物蒙版提阴影约 10—20、曝光最多增加约 0.2EV。再分别降低绿色、黄色和路面洋红饱和度，避免全局增加对比导致阴影更脏。

# 建议设置

无法从画面可靠判断原始拍摄参数，以下是针对同类白天儿童奔跑场景的估计起点：

- 模式：快门优先，或 M 档配自动 ISO。
- 快门：先用 **1/1000 秒**；动作更快或焦距更长时用 1/1250—1/1600 秒。
- 光圈：**f/4—f/5.6**，在主体分离与追焦容错之间取平衡。
- ISO：自动 ISO，晴天通常可从 ISO 100 起，允许相机按快门需要升高。
- 对焦：AF-C／连续自动对焦，人物或眼部追踪；若追踪不稳定，使用区域对焦覆盖孩子上半身。
- 连拍：高速连拍，提前半按或使用后键启动追焦，在完整步态出现前开始拍一小串。
- 测光与曝光：评价测光，先尝试 **-0.3EV** 保护白衣和白帽，并观察高光警示。

# 后期步骤

1. 先裁切右侧与下方，移除或尽量弱化右缘灯杆，保留孩子前方的道路延伸和完整影子。
2. 开启镜头校正与色差去除，再做基本曝光调整；先压高光与白色色阶，避免白衣进一步发亮。
3. 建立人物蒙版，轻提阴影与中间调；纹理约 +5—10、清晰度约 +3—8，少量锐化即可，不强行制造不存在的细节。
4. 建立背景反向蒙版，轻降纹理或清晰度，使繁密植被不再和人物竞争；不要使用明显的假虚化。
5. 在 HSL 中轻降绿色、黄色以及路面红／洋红的饱和度，必要时略降绿色明度，让人物白蓝配色成为第一色彩落点。
6. 对右侧亮路面和远处零散行人做轻微压暗；若修复工具处理自然，可移除小型边缘杂物，但不改动主要场景关系。
7. 最后按输出尺寸做蒙版锐化，并在 100% 视图检查帽沿、手脚周围是否出现锐化白边。

# 下一次练习任务

做一次“奔跑定格”练习：选择一条安全、背景简单的小路，让拍摄对象沿同一路线跑 5 次。固定使用 1/1000 秒、AF-C 和高速连拍，每次只改变一个变量——第一次练追焦，第二次练把人物放在三分线，第三次练给运动方向留空间，第四次练避开边缘杂物，第五次尝试侧前光。每次选出一张，在 100% 视图检查眼睛、衣服图案和鞋底是否都有稳定边缘；最终目标是得到一张“动作姿态完整、主体清楚、前进方向有空间”的照片。
