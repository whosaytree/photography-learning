# V3最小增量规则独立校准

## 目的

验证一个严格以正式规则为母本的最小补充：只解除C全幅秩序型和D形面分区型受到的错误主体／落点限制，不改变技术硬伤、高分尺度或A/B型照片的评价。

## 独立性要求

- 使用与V2相同的35张照片。
- 每张照片由全新上下文完整评分一次。
- 评分者只能读取摄影基础框架、正式评分规则、V3候选补充、该照片的 `metadata.json` 与 `original.*`。
- 禁止读取旧 `critique.md`、V2结果、其他照片、样本清单、比较表、旧分、新分或验收分组。
- 不使用批量评分脚本，不压缩点评过程，不做分布归一化。
- 全部35张完成后，主任务才读取旧分与V2分数进行验收。

## 预先确定的验收原则

1. 完全独立评分是不可变条件，不以旧分或高低分锚点影响任何一次评分。
2. 35张中不得出现总体分低于正式旧分的照片；若出现，说明候选补充没有做到单向兼容。
3. 旧评已经触发失焦、抖动、曝光、方向、边缘、裁切、主导干扰、失衡、普通记录或多重问题等通用硬伤的照片，不得因为新增形式解释而提高总体分。
4. 允许提高的主要对象，是旧评仅因缺少唯一主体／落点而受限、同时没有其他通用硬伤，或原评已经看见形式意图但主体中心化语言明显压低构图／故事的照片。
5. 原7.5分以上照片不得降低；新增组织方式不能成为额外高分门槛。
6. 不允许把原低于6分的照片仅凭风格类别抬到7.5以上。
7. 不以平均分稳定代替逐张方向正确；任何错误上调或错误下调都必须单独报告。

## 文件结构

- `SCORING_RUBRIC_V3_CANDIDATE.md`：候选补充规则。
- `results/<archive-id>/critique.md`：35份完全独立的新评分。
- `comparison.md`：全部评分结束后生成的逐张旧分／V2／V3对照。
- `acceptance-report.md`：按上述原则作出的验收结论。
