# V5.2 原版最小修订候选

## 修改范围

V5.2 每次从正式 `SCORING_RUBRIC.md` 直接派生，不继承 V2—V5.1 正文。只改原版两个章节：

1. 在硬伤表前为原有失焦、曝光、主导干扰／边缘／失衡封顶补充可观察触发条件。
2. 加入唯一主体／落点窄例外，并要求例外使用前先通过清晰结构、局部第一落点、大面积中断带、边缘碎片和其他硬伤门禁。
3. 在高分资格中允许合格的主体等价物，同时规定同一形式关系产生的形式、色彩与情绪只能合并算一个强项。

## 已删除的 V5.1 内容

- 未使用例外时的空间／动作第二强项条款。
- 柔焦清晰锚点补充条款。
- 选择性运动模糊补充条款。
- 其他历次候选中的分类、额外阶段、全局形式加分或封顶上沿限制。

## 独立校准

- 使用同一批 35 张样本，每张全新上下文完整评分。
- 评分者只读取摄影框架、V5.2 完整候选规则、该照片的 `metadata.json` 与 `original.*`。
- 禁止读取正式旧点评、旧分、历次结果、其他 V5.2 结果、其他照片、分组和验收目标。
- 不使用批量评分脚本，不压缩单张流程；全部完成后才比较。

## 验收条件

1. 不出现总体分降低。
2. 通用硬伤保护样本不提高。
3. 未使用窄例外的非目标照片相对旧分变化不超过 0.2。
4. 原 7.5 分以上照片不降低。
5. 旧分低于 6 的目标照片不得仅凭同一形式证据进入 7.5。
6. 窄例外不得用于任何有其他硬伤、结构不清、大面积中断带或竞争性边缘碎片的照片。
7. 正式规则在用户确认前保持不变。
