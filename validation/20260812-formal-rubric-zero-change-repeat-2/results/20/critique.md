# 一句话总评

这张俯拍荷叶用大小圆形、深浅绿色和少量黄花做出了自然纹理感，但斑驳直射光与过多碎细节分散了中央大叶片的视觉统治力。

# 评分前检查

- **主体：**中央偏上的深绿大荷叶是主要视觉落点，周围的大小荷叶与黄色小花共同构成环境。
- **题材：**自然植物细节、俯拍图案化构图；画面不只是辨认植物，有用圆形重复、大小对比和色彩节奏组织画面的意图。
- **基础问题等级：**无。主体可读，对焦与曝光足以支撑正常观看，显示方向正常。
- **逐项硬伤检查：**主体并非不可读或严重偏小；没有明显失焦、手抖或严重运动模糊；重要叶片细节没有被严重过曝或欠曝破坏；俯拍纹理题材没有需要校正的地平线；边缘叶片的截断符合铺满画面的图案化方式，未到破坏主体的程度；虽然枯痕、碎叶和阴影较多，但尚未形成压过主体的单一主导干扰；没有多项重大缺陷同时成立。
- **高分资格：**主体清楚，边缘与视觉重量基本受控，且有超过普通记录的构图意图；但只有构图组织较明确，光线、技术质感和故事层次尚未形成第二个清晰强项，不符合 7.5 及以上条件。
- **故意处理判断：**俯拍、满画面和边缘截断与重复圆形的图案化意图一致，可视为故意处理；但横跨叶片的亮暗阴影缺少稳定规律，对主体与氛围的帮助不足，更像拍摄时没有完全控制的斑驳光。

# 五项评分

- **技术：6.5/10**
  
  叶片轮廓、叶脉和水面碎细节基本清楚，没有明显抖动或对焦失误。不足是高亮区绿色偏淡、阴影区偏青，局部明暗与色温差异让整体显得不够统一。
- **构图：7/10**
  
  中央深绿荷叶提供了落点，右上、左下和右下的大叶片建立了稳定的重量关系，黄花又形成小节点。但主叶周围的病斑叶、细碎浮叶和不规则阴影密度较高，视线会在四处游移，落点还不够强。
- **光线：5.5/10**
  
  光线让荷叶的颜色和叶脉可见，但明暗斑块横跨多片大叶，部分亮区平、淡，部分暗区偏冷，既没有集中地塑造中央主叶，也未形成明确的节奏。
- **叙事：6/10**
  
  故事证据属于“场景/情绪”：密集荷叶、少量小黄花与新旧叶片带来了池塘生长状态和夏日气息。但画面没有更强的生物瞬间、光影关系或反差线索，还没有达到清晰的“关系/瞬间/视觉想法”层级。
- **总体：6.5/10**
  
  这是一张有意识将植物场景转化为平面图案的入门作品，主体和构图秩序都已超过单纯记录。斑驳光和偏满的细节使画面缺少更强的统一性与记忆点。

# 色彩观察

画面以中、高饱和度的黄绿和深绿为主，黄色小花是最醒目的点状色彩。绿色家族本身和谐，深浅变化也有助于分开叶片；黄花增加了活泼的夏日感。问题在于阳光下的黄绿偏亮、偏淡，阴影里的深绿又偏青，加上褐色枯痕和浑暗水面，造成局部色彩脏乱。后期建议压低黄色和黄绿色的明度及饱和度，适度降低青色在阴影中的饱和度，再局部提升中央深绿叶片的明暗对比和叶脉细节，让色彩层级更明确。

# 做得好的地方

- 选择垂直俯拍，成功弱化了池塘的空间深度，把荷叶变成圆形和色块的平面练习，拍摄意图比普通“看到荷叶就记录”更清楚。
- 中央大叶片的深绿与周围黄绿色形成明度对比，提供了基本可靠的主视觉落点。
- 大叶、小叶与黄花的尺寸差异形成了节奏，画面不是单调的同尺寸重复。
- 全画面清晰度足够，多片荷叶的边缘、叶脉和表面痕迹都能被读到。

# 优先修改项

## 1. 先解决无规律的斑驳光

- **问题：**大块阴影从叶片上横跨，亮区又显得偏淡，不同荷叶的明暗关系缺乏统一方向。
- **为什么：**俯拍图案需要清晰的形状和色块秩序，不规则阴影会在圆形之上又叠加一层杂乱图形。
- **下次怎么拍：**选择薄云、早晚柔光或整体处在开放阴影里的区域；按快门前先查看取景框四角，确认自己和周围物体的影子没有落在主叶上。
- **这张怎么修：**用局部蒙版轻微压低过亮的黄绿叶，同时抬起最深的阴影；处理幅度保持轻微，避免每片叶子都一样亮而失去层次。

## 2. 减少中央主叶周围的碎信息

- **问题：**主叶周边同时出现小浮叶、枯痕、水面反光和多朵黄花，主体与环境的信息密度差不够大。
- **为什么：**中央大叶虽然尺寸最大，但观者的视线容易被黄花和浅色病斑拉走，弱化了主从层级。
- **下次怎么拍：**围绕同一组荷叶左右移动半步，比较哪个角度能让主叶周围留出更整洁的水面或小叶背景；也可再靠近一些，只保留 3–5 片关键大叶和少量黄花。
- **这张怎么修：**从左边和底部少量裁切，将中央深绿叶片放在更明确的主位；对外围病斑和黄花适度降低饱和度或纹理，不必把自然痕迹全部消除。

## 3. 把“圆形节奏”做得更精确

- **问题：**现在多片大叶的边缘同时被画框截断，有些截断帮助了铺满感，但右下与底边的局部叠压偏重。
- **为什么：**图案化构图对边缘和负空间很敏感，局部图形太重会让画面重心下沉，削弱中央主叶的作用。
- **下次怎么拍：**打开网格线，在按快门前沿四边逐一巡视，让每个被截断的大叶要么明确地进入画面，要么完全排除，避免只留下狭小碎角。
- **这张怎么修：**先试验 4:3 或轻微收紧的横幅裁切，目标是保留中央、右上和左下三个主要圆形，同时减少右下叠压的大叶重量。

# 建议设置

画面无法提供实际拍摄参数，以下是下次拍摄同类俯拍植物纹理时的**估计起点**：

- 光圈优先或手动模式，光圈约 **f/5.6–f/8**，让多片荷叶同时保持清楚。
- 手持快门不低于 **1/250 秒**；如果有风吹动叶片，提高到 **1/500 秒**或更快。
- **ISO 100–400**，以能保证上述快门为准，不必为了低 ISO 牺牲稳定性。
- 使用单点对焦或小区域对焦，对在中央主叶的叶脉上；有微风时可用连续对焦。
- 在强光下可从 **-0.3 EV** 曝光补偿开始试拍，查看高亮预警，以保留亮绿叶片的色彩和纹理。
- 若有偏振镜，可小心旋转以减少水面和湿叶反光，但不要把所有反光完全消除，避免画面变得沉闷。

# 后期步骤

1. 先做镜头校正，再试验小幅裁切，优先减少底部和右下过重的叶片，保留中央深绿主叶。
2. 轻压全局高光和白色阶，使明亮的黄绿叶片恢复纹理；阴影只少量抬起，保留深浅层次。
3. 调整白平衡至中性偏暖，再在 HSL 中稍降黄色、黄绿色的明度和饱和度，同时减少阴影里的青色感。
4. 给中央主叶建立柔和局部蒙版，微增纹理、清晰度和中间调对比；外围叶片则少量降低纹理，建立主次。
5. 对最亮的病斑、水面小反光和边缘碎角做有选择的压暗或修复，保留部分自然痕迹，不要修成完全无瑕的塑料感。
6. 最后在 100% 视图下进行适度边缘锐化，输出前再检查黄绿色是否过饱和、阴影是否出现脏青。

# 下一次练习任务

找一组类似的荷叶或其他圆叶植物，只练习“一个主圆＋三个辅助圆”的组织：分别在直射光、整片阴影和薄云柔光下各拍 5 张，每张按快门前都检查四边截断、主叶周围是否干净、黄花是否抢眼。拍完只选 1 张，选择标准是：第一眼落在主叶，三个辅助圆保持平衡，画面中没有一块无规律阴影比主叶更醒目。
