# 色彩观察

主色调是天空的浅蓝、植被的绿色和岩石的中性灰褐，中间的红、黄、蓝、绿彩旗形成高饱和多色核心。背景整体偏冷、低饱和，与彩旗的暖色和高饱和区域搭配和谐，彩色层级对主体分离和注意力聚集起到了明显作用。色彩带来明快、开放和旅行感，没有无序冲突。当前远山和蓝天略带灰感，后期宜小幅去霞、提升蓝色与绿色的层次，同时轻微降低彩旗中红色和青蓝色的饱和度，避免把本来和谐的多色推成刺眼。白平衡整体自然，不需要大幅改变色温。

# 做得好的地方

1. **前中后景层次完整。**脚下岩面提供空间起点，彩旗占据中景核心，山脊和亭子负责把景深延伸到远处。
2. **线条不是摆设，而是真正在引导视线。**彩旗的斜线收束到顶点，右侧小路再引向亭子，浏览顺序清楚。
3. **主体分离有效。**多色彩旗处在低饱和山体与蓝天之间，即使不依赖浅景深，也能立即被看到。
4. **边缘与大尺度视觉重量稳定。**左侧远处谷地、右侧植被与下方岩面都作为支撑，画面没有明显向某一边倾倒。

# 优先修改项

## 1. 让主落点与次落点更有主次

- **问题：**彩旗顶点、背后岩峰与右上亭子都有较强存在感，彩旗顶点还与岩峰部分重叠。
- **为什么：**线条已经很强，如果终点与背景轮廓粘连，视线到达核心后会短暂犹豫；亭子的第二落点也会分散主题强度。
- **下次怎么拍：**横向移动几步或略微降低机位，尝试让彩旗顶点落在干净的天空或单纯山体区域；拍一张以彩旗为绝对主体的版本，再拍一张让小路更明确通向亭子的版本，分别比较。
- **这张怎么修：**对彩旗中心和顶点做轻微局部提亮及纹理加强，同时将亭子周围亮度或清晰度轻微降低，建立更清楚的第一、第二注意层级；调整要很小，避免局部痕迹。

## 2. 把“可见”的日间光提升为“能塑形”的光

- **问题：**山体、岩石和植被整体亮度比较均匀，局部立体感和天气氛围偏弱。
- **为什么：**彩旗形状足够强，但偏平的光让山体纹理和路径缺少明暗节奏，图像的空间感更多依赖构图而不是光。
- **下次怎么拍：**如果条件允许，选太阳较低的早晨或傍晚，等侧光在山脊和岩石上形成明暗转折；现场以彩旗最亮部为保护对象，必要时做负曝光补偿。
- **这张怎么修：**轻微压高光，用小幅 S 曲线提升中间调对比；对山脊和右侧小路局部增加质感或清晰度，远山只做小幅去霞，不要把天空和远景压成生硬边缘。

## 3. 精简最下方前景的空白岩面

- **问题：**画面底部的亮色岩面占据一定面积，具有空间起点作用，但纹理与主题联系略弱。
- **为什么：**大片偏亮、低色彩的区域会拉低彩旗在画面中的占比，也稍微分散了对彩旗放射线的注意。
- **下次怎么拍：**机位再向前一些，或镜头略向上抬，在保留少量前景作为地理依托的同时，让彩旗占比更大。
- **这张怎么修：**从底部小幅裁去约 5% 至 8%，保留彩旗底边与植被的完整性；裁切后检查亭子与右边缘仍有足够呼吸空间。

# 建议设置

画面中看不出实际拍摄参数，以下只是针对同类白天山地风光的估计起点：

- 光圈优先或手动模式，光圈约 **f/8–f/11**，以兼顾彩旗、山脊与亭子的景深。
- **ISO 100–200**，在快门充足时优先保持低感光度。
- 手持时快门建议不低于 **1/250 秒**；如彩旗在风中快速抖动，可提高到 **1/500 秒**左右。
- 使用广角至标准广角视角，先以约 **24–35mm 等效焦段**作为构图起点，避免过广导致亭子过小。
- 单点对焦在中景彩旗顶点附近或画面纵深约三分之一处，拍后放大确认近中景纹理。
- 使用评价测光，观察高光警告；白色彩旗或岩石接近过曝时，尝试 **-0.3EV 至 -0.7EV**。
- 有三脚架时可使用 ISO 100、f/8–f/11，并用 2 秒延时或遥控减少触发震动；若使用偏振镜，应边旋转边观察彩旗和天空，避免宽画面蓝天明暗不均。

# 后期步骤

1. 开启镜头校正和色差移除，先确认画面边缘与山脊线条自然。
2. 轻微压低高光，小幅提升阴影，保留彩旗中白色布片和岩石表面细节。
3. 加一条轻微 S 曲线，主要增强中间调对比，不要把暗部压死。
4. 对远山和天空轻微去霞，再用渐变工具小幅压低天空亮度，保持云层柔和，避免出现光晕或过重灰阶。
5. 在 HSL 中小幅增加蓝色明度层次，适度整理绿色的饱和度；如彩旗显得过艳，单独将红色和青蓝色饱和度回收少许。
6. 对彩旗中心做小范围局部提亮和质感加强，将右上亭子附近的对比稍微收住，明确主次。
7. 试做一个从底部裁去约 5% 至 8% 的版本，与原构图对照，选择彩旗更有重量且前景仍自然的版本。
8. 输出前使用边缘遮罩做适度销化，不对天空和远山的细小噪点过度销化。
