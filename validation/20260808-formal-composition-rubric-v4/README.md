# V4条件式最小补充独立校准

## 状态

**验收未通过，不得覆盖正式评分规则。** 35张已全部独立完成；详见 `comparison.md` 与 `acceptance-report.md`。

## 方法

- 复用前两轮同一批35张照片。
- 每张由全新上下文完整评分一次。
- 评分者只读取摄影框架、正式规则、V4补充、该照片的 `metadata.json` 与 `original.*`。
- 禁止读取旧点评、旧分、V2/V3结果、V4其他结果、其他照片、样本清单、比较表和验收目标。
- 不使用批量评分脚本，不压缩点评过程，不做分布归一化。
- 全部35张完成后才进行任何分数比较。

## 预先验收条件

1. 35张中不得出现总体分低于正式旧分的照片。
2. 16张通用硬伤保护样本不得因V4形式补充提高总体分。
3. A/B及其他非目标控制照片相对旧分的变化不得超过0.2；超过说明补充仍外溢。
4. 原7.5分以上照片不得降低。
5. 目标形式照片可以提高，但原低于6分的照片不得仅凭形式组织进入7.5以上。
6. 同一形式证据不得同时充当两个高分强项；若因此进入7.5以上，判为失败。
7. 不以平均分稳定代替逐张验收；平均值只用于检查整体膨胀或压缩。
