# 一句话总评

大面积蓝天压住底部树冠，冷色和负空间带来安静、开阔的观看感，但天空里的点状元素太小且分散，缺少一个能让视线明确停住的记忆点，普通的正午光也让画面显得偏平。

# 评分前检查

- **主体**：主体不是某一棵树或某一个小黑点，而是“连续树冠作为下方基底、大片蓝天作为负空间”的整幅场景关系；天空中的飞鸟或点状元素只起轻微的尺度提示作用。
- **题材**：偏极简的自然风景／空间气氛照片。它有明确的负空间选择，不只是用于说明“这里有树和蓝天”的普通记录，但视觉想法还比较简单。
- **基础问题等级**：无。画面可正常观看，方向、曝光、清晰度和整体结构均未失效；落点偏弱属于表现力限制，不构成基本失败。
- **逐项硬伤检查**：
  - 主体不可读：否，天空与树冠的整体关系一眼可辨。
  - 主体存在但含混或弱：否；本图使用窄结构场例外，见下文。
  - 主体严重意外虚焦：否。
  - 主体明显意外虚焦但仍可读：否；树冠细节略柔、略有空气感，但没有明确错焦证据。
  - 严重手抖或运动模糊：否。
  - 明显手抖或运动模糊：否。
  - 严重过曝并损失重要主体细节：否；亮部偏亮，但没有重要主体被大面积冲白。
  - 严重欠曝并隐藏重要主体细节：否。
  - 地平线／垂直线意外倾斜：否；画面方向自然，树冠基线没有造成明显失衡。
  - 主导干扰、别扭裁切、边缘切割或视觉失衡：否；树冠从底边自然延伸，边缘没有足以改变主阅读的干扰。零散黑点有些含混，但尚未成为主导干扰。
  - 主体过小且无法靠裁切恢复：否；主体是整幅天空—树冠结构，不以单个点状物的大小成立。
  - 普通记录且没有可见摄影叙事：否；大片负空间和蓝绿冷色至少建立了开阔、安静的场景情绪与尺度关系。
  - 光线平淡且故事弱：未触发。光线确实普通偏平，但画面仍有可读的空间情绪和负空间想法，因此不同时满足两项条件。
  - 多个不同维度重大问题并存：否。
- **高分资格**：不具备 7.5 分以上资格。主体和边缘控制合格，也有视觉意图，但技术、光线、叙事均未达到“明确强项”；尤其天空没有清晰落点，光线也没有为树冠提供足够层次，尚不足两项明显强维度。
- **故意处理判断**：大面积高亮蓝天、小比例树冠和负空间可视为故意处理。依据是：负空间支持安静与尺度感；树冠形成稳定的视觉锚点；上下边缘与横向结构较受控；并且符合极简风景的常见表达。至少满足两项故意效果测试，因此不按误裁或主体过小处理。效果基本成立，但点状元素太弱，尚未形成更有力的视觉事件。
- **窄结构场例外**：使用。可见理由是画面的主体是横贯全幅的天空—树冠排列，正常观看尺寸下立即可读，整体秩序没有被竞争元素或结构断裂破坏；缺少局部落点本身不触发“主体存在但含混或弱”的封顶。不过，这项例外只证明整体可读，不自动构成构图强项、故事强项或高分资格。

# 五项评分

- **技术：6/10**。曝光与清晰度足以支撑观看，没有明显手抖或错焦；但树冠细节偏柔，亮部略显发白，天空中的小黑点形态不够明确，整体质感仍像未经精细控制的直出。
- **构图：6/10**。树冠压在画面下部，蓝天形成大面积负空间，结构简洁且视觉重量基本稳定；不足是天空过于均质，点状元素散而小，视线进入天空后没有明确落点，所以更接近“有组织但落点偏弱”，尚未达到 7 分的完整引导。
- **光线：5/10**。光线保证了可见度，但方向感弱，树冠明暗层次和立体感不足，天空也没有云层、渐变或特殊光色提供气氛加成。
- **叙事：6/10**。证据等级为“场景／情绪”：画面能传递晴朗、开阔、安静和人与自然距离感，但没有明确关系、瞬间或更强的视觉冲突，天空中的点状物也不足以形成事件。
- **总体：6/10**。它已经超出随手记录：负空间、色彩和横向树冠关系体现了选择；但核心效果尚未被一个清晰落点或有方向的光线推到“可分享的成熟构图”层级。

# 色彩观察

主色调是高明度的青蓝天空与偏冷的蓝绿色树冠，属于相邻冷色搭配，整体和谐、清爽，能强化晴朗、开阔和安静的情绪。蓝色的大面积占比也把树冠从背景中分离出来，色彩层级是清楚的。问题在于天空略偏青、树叶略偏蓝绿且亮部发灰，冷色统一得有些单薄；色彩没有冲突，却也缺少层次。后期可轻微向暖、向洋红校正综合色偏，适度压低青色饱和度和蓝色明度，同时给树冠增加少量局部对比与自然饱和度，保持清爽而避免把绿色推成荧光色。

# 封顶规则

无。

# 做得好的地方

- 把树冠压在下方、把天空留成主体空间，画面意图比居中拍一片树林更明确。
- 树冠横向连贯，左右边缘没有明显突兀截断，底部视觉重量足以稳定大片天空。
- 蓝与绿的冷色关系统一，天然形成宁静、清凉的氛围，没有杂色抢视线。
- 曝光、方向和基本清晰度都可靠，没有会阻断观看的技术硬伤。

# 优先修改项

## 1. 给负空间设置一个真正的落点

- **问题**：天空占比很大，但飞鸟或黑点太小、太散，观者的视线扫过天空后不知道应停在哪里。
- **为什么**：负空间不是“空得越多越好”；它需要与一个形态清楚、位置明确的元素产生比例或方向关系，才能把开阔感转成完整构图。
- **下次怎么拍**：先固定树冠基线，再等待一只更近的鸟、一簇更集中的鸟群或一朵形态明确的云进入三分线附近；若鸟是核心，换更长焦段并保证至少 1/500 秒，让轮廓可辨。
- **这张怎么修**：从上方裁掉约 8%—12% 的纯空区域，再小幅裁掉点状元素最零散的一侧，尝试 2:1 左右的横幅，让现有较集中的点状区域更靠近三分交点；不要裁到树冠失去横向基底作用。

## 2. 增加树冠的光影层次

- **问题**：树叶整体受光较平均，亮部偏白，树冠像一条颜色相近的平面带。
- **为什么**：树冠是画面唯一稳定锚点；当它缺少明暗起伏时，大片天空也会显得只是空白，而不是被有力承托的负空间。
- **下次怎么拍**：改在日出后或日落前的侧光时段拍摄，让不同树冠产生明暗分层；曝光补偿可先试 -0.3 EV，并看直方图保护亮叶细节。
- **这张怎么修**：对树冠单独建蒙版，降低高光约 15—25、增加少量纹理和清晰度；用很轻的局部加深／提亮塑造两三组树冠，不要全局猛加去雾导致天空变脏。

## 3. 处理点状元素的含混感

- **问题**：天空中的若干黑点既可能被读成远鸟，也可能被误认成画面污点，形态和组织都不够确定。
- **为什么**：小元素一旦缺少轮廓和规律，就难以承担叙事，反而会分散注意力并降低画面的完成感。
- **下次怎么拍**：若想表现鸟群，使用连续对焦与高速连拍，等鸟群形成更集中或有方向的队形；拍摄前也检查镜头表面，避免真实飞鸟与污点混在一起难以判断。
- **这张怎么修**：保留位置有关系、像飞行队形的点；对孤立、边缘模糊且不参与结构的点逐一放大确认，确属杂点时再修除，避免把真实鸟群全部抹掉。

# 建议设置

以下为根据画面估计，并非原始拍摄参数：

- 风景优先可用光圈优先或手动模式，ISO 100，f/8 左右。
- 若要同时保留飞鸟形态，快门至少 1/500 秒；鸟飞得快时提高到 1/1000 秒，并允许 ISO 自动升高。
- 对树冠拍摄可先试 -0.3 EV，优先保护亮叶与天空色阶。
- 只拍天空—树冠结构时可用约 50—100mm 等效焦段压缩画面；若要让鸟成为真正落点，可尝试 100—200mm 等效焦段。
- 树冠静止时单点对焦即可；等待飞鸟进入时切到连续对焦和小区域追踪。

# 后期步骤

1. 先做镜头校正和轻微色差去除，保持树冠边缘干净。
2. 尝试从上方裁去约 8%—12%，微调左右边界，比较原比例与约 2:1 横幅，选择点状元素关系最集中的版本。
3. 全局轻压高光和白色色阶，避免亮叶发白；阴影只少量抬起，保留树冠的深浅差。
4. 白平衡略向暖、色调略向洋红移动，消除过强青绿色倾向；幅度以天空仍自然为准。
5. 在 HSL 中轻降青色饱和度，略压蓝色明度；树冠只增加少量自然饱和度，不追求浓艳绿。
6. 单独蒙版处理树冠，加入少量纹理、清晰度和局部明暗；天空保持平滑，不做重度清晰度与去雾。
7. 放大检查天空中的点状元素，只清理确认不参与鸟群／画面关系的杂点。
8. 最后做遮罩锐化，主要锐化树冠边缘，避免把平滑天空锐化出颗粒。

# 下一次练习任务

在同一片树冠前完成一组“负空间与落点”练习：固定横向机位，分别拍天空占画面约 1/2、2/3、3/4 的三张；每个比例都等一个明确元素进入画面——单鸟、鸟群或一朵形态清楚的云。回看时只检查三件事：主体关系是否一眼可读、视线最终停在哪里、空白是否在加强情绪而不是单纯占面积。最终选出一张，并写一句话说明“为什么这个落点必须在这里”。
