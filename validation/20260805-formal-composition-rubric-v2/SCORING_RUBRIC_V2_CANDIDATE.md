# 摄影点评评分 Rubric V2（候选校准版）

状态：候选标准，仅用于独立校准。不得覆盖正式 `SCORING_RUBRIC.md`，不得据此回写既有单张存档。

目标：在保留 5/10 记录照基线、技术硬伤封顶和高分纪律的同时，避免将“无唯一主体”误判成“主体失败”。评分不奖励个人偏好，只针对照片选择的视觉组织方式检查其完成度。

## 一、核心尺度

5/10 是普通记录照基线：内容可辨认、可观看，但摄影意图、组织控制或表达较弱。清楚、可读、具有信息价值，本身不足以超过记录层。

| 分数 | 含义 |
|---|---|
| 1—2 | 失败图像。严重技术问题或结构混乱使视觉信息几乎不可用。 |
| 3—3.5 | 严重基础失败。失焦、抖动、曝光、方向或关键关系明显破坏观看。 |
| 4—4.5 | 清楚的硬伤。画面可理解，但基础问题使它在技术或结构上明显失败。 |
| 5 | 普通记录照或被基础问题封顶的照片。 |
| 5.5—6 | 有价值的初学尝试。至少有一项可见摄影优势，但控制仍有明显限制。 |
| 6.5—7 | 可分享的初学者照片。视觉组织明确，技术基本成立，边缘和画面重量大体受控。 |
| 7.5 | 强初学者照片。至少两项明显较强，但仍有一项有意义的限制。 |
| 8—8.5 | 明显强照片。至少两项很强，弱点为次要问题；8.5需要鲜明记忆点或高度形式控制。 |
| 9 | 作品集级别。意图、执行和画面一致性都很强，无明显初学者问题。极少使用。 |
| 10 | 参考级。近乎无可挑剔，正常学习点评中几乎不用。 |

低端和高端必须都可用。严重基础失败通常为 3—4.5；普通记录通常在 4.5—5.5。不要把 6.5 当成安全默认分，也不要因为形式照片看起来“有设计感”就自动给 7 分。

## 二、评分前先确定视觉组织契约

每张照片必须先选择一个主要契约；必要时可记录一个辅助契约。契约选择本身不加分，只决定用什么证据判断构图是否完成。

### A. 主体层级型

画面依靠一个主要人物、物体、动作或局部作为观看中心，其他元素负责支持、交代或平衡。

主要检查：主体可读性、主体分离、主次关系、背景、边缘、位置和动作时机。

### B. 路径关系型

画面依靠道路、栏杆、桥、透视、重复、视线、动作方向、尺度或两个以上对象之间的对应关系成立。

主要检查：路径是否有效、方向是否清楚、终点或对象关系是否成立、各元素是否真正互相定义。

### C. 全幅秩序型

画面有意不设唯一主体，各区域相对同权，依靠重复、网格、密度、节奏、纹理、连续线条或类型学结构成立。

主要检查：间距、密度、节奏、正对程度、透视一致性、色调统一、边缘连续性，以及异常点是否有意。

### D. 分区形面型

画面依靠两三个大面积、色域、明暗区、轮廓、边界或剪影关系成立，具体对象可能仍可辨认，但不是主要观看入口。

主要检查：面积比例、边界形状、区域分离度、色彩/明暗张力、轮廓清晰度和四边裁切。

### 契约判断原则

- 先从画面证据判断，不根据作者喜欢哪种风格预设。
- 作者声明只能帮助理解，不能替代画面证据。
- 如果所谓“抽象、极简、平面”在画面里没有形成可读秩序，仍按普通记录或结构未完成评分。
- 无唯一主体不等于主体失败；但非主体型画面必须以贯穿全画面的形式秩序证明其意图。

## 三、视觉命题检查

总体评分的第一问不是一律询问“主体是否清楚”，而是：

> 这张照片的主要视觉组织原则是否清楚——主体、路径、关系、重复秩序或形面分区，是否至少有一种从画面本身明确成立？

对应要求：

- A型：主体必须清楚且能承担画面中心。
- B型：路径必须通向有效终点，或对象之间的关系必须可读。
- C型：不要求唯一落点，但秩序必须遍及画面，而不是随机杂乱。
- D型：不要求人物或物体落点，但面积、边界或轮廓关系必须明确。

“落点”只在照片承诺通向某处、依赖小主体或建立主次层级时作为硬要求。全幅图案、非中心秩序、形面分区和纯镜像不因没有唯一落点而扣分。

## 四、五项维度

### 技术

评价曝光、对焦、运动模糊、锐度、噪点、白平衡和基础画质。标准与正式版保持一致。

- 1—2：严重模糊或曝光失败，图像不可用。
- 3—4：主要技术问题支配画面。
- 5：可读但明显有瑕疵，或仅满足记录用途。
- 6：基本可用，但存在一个有意义的限制。
- 7：曝光和清晰度稳定，仅有轻微问题。
- 8：干净、可控、有技术把握。
- 9—10：卓越技术控制，极少使用。

形式照片不因“抽象”免除技术要求。如果画面依赖清晰边界、重复纹理或精确线条，失焦、抖动、脏点和色彩断层会更加明显。

### 构图

先按主要契约评价，再检查简化、边缘、裁切、重量、层次和故意性。

- 1—2：主要视觉组织不可读，或画面彻底混乱。
- 3—4：视觉命题存在但被严重遮挡、失衡、随机裁切或强干扰破坏。
- 5：记录层取景，或所选契约只有题材表象，没有形成稳定组织。
- 6：契约可读，有一定组织，但边缘、比例、节奏、路径、关系或视觉重量存在明显弱点。
- 7：所选契约被有意、稳定地执行；背景与边缘基本受控，画面具有清楚组织逻辑。
- 8：全画面组织强，观看路径、关系、节奏或形面控制成为主要优势。
- 9—10：高度精炼，每个主要元素与边缘都像经过决定。极少使用。

#### C型达到7分至少需要

- 重复、密度或节奏关系明显；
- 四边裁切具有一致逻辑；
- 没有偶然亮点、断线、杂物或局部密度突变破坏秩序；
- 透视、间距、形状变化或色调变化具有可读规律；
- 简化不是因为内容贫乏，而是让秩序更清楚。

#### D型达到7分至少需要

- 面积比例看起来是明确选择；
- 分界线或轮廓具有构图作用；
- 各区域存在足够的色彩、明暗、质感或方向张力；
- 四边裁切坚定；
- 简单但不空洞，观看理由从画面本身成立。

### 光线

评价光线质量、方向、反差、动态范围、色温、气氛，以及光线是否支持所选契约。

- 1—2：光线破坏关键视觉信息。
- 3—4：硬、平或错误方向的光明显削弱照片。
- 5：可用但普通或仅供记录。
- 6：存在有用光线、色域或气氛，但限制明显。
- 7：光线支持主体、关系、节奏、边界或形面分区。
- 8：光线是主要优势。
- 9—10：卓越光线，极少使用。

普通光不自动等于低分：如果均匀光正好服务类型学、纹理或色面控制，可以成立；但必须确实帮助形式统一，而不是仅仅“没有出错”。

### 叙事／视觉想法

评价画面是否提供超越信息记录的观看理由，包括瞬间、关系、姿态、尺度、气氛、对照、场所、重复、形面转换、视觉错觉或形式命题。

- 1—2：没有可读对象，也没有有意义的观看理由。
- 3—4：内容存在，但几乎没有关系、情绪或视觉想法。
- 5：只记录人物、物体、纹理、墙面、地点、产品、损坏或事件。
- 6：出现可读气氛、节奏、尺度、形面关系或简单对象关系。
- 7：有清楚的形式命题、关系、对照、姿态、空间尺度或瞬间。
- 8：形成强烈情绪、关系、时机、视觉转换、错觉或有记忆点的形式想法。
- 9—10：具有作品集级别的叙事或视觉概念，极少使用。

没有人物不等于没有叙事；有重复和色块也不自动等于有视觉想法。必须看到现实被怎样组织、转换或赋予关系。

### 总体

总体不是五项平均值。依次判断：

1. 主要视觉契约和视觉命题是否清楚；
2. 是否具有超越记录价值的观看理由；
3. 是否存在阻碍正常观看的通用硬伤；
4. 光线、构图和技术是否支持所选契约；
5. 形式选择是否真正落实到全画面，而不是只在标题或作者说明中成立。

## 五、色彩观察

色彩不是第六项分数，但必须观察：主色倾向、和谐或冲突、色彩层级、情绪作用、主体/区域分离、白平衡、偏色、过饱和、灰闷、脏暗部和可执行后期方向。

鲜艳本身不加分。异常色彩在有意且协调时不扣分。C型和D型中，色彩一致性、区域分离和局部脏色会直接影响构图、光线、视觉想法与总体判断。

## 六、通用硬伤封顶

硬伤是阻碍正常观看或直接破坏所选视觉契约的基础问题。技术硬伤对所有契约同样生效。

### 方向检查

归档图必须先读 `metadata.json`，再使用能够识别方向信息的来源检查 `original.*`。只按正确显示方向评分，不能因原始像素矩阵横置而误判。只有正确显示后，人、建筑、水线、文字或重力依赖对象仍明显横置/倒置并阻碍观看，才应用方向封顶。

| 条件 | 必须封顶 |
|---|---|
| A型主要主体不可读 | 总体最高4.0；构图最高4.0；叙事／视觉想法最高4.0 |
| A型主要主体存在但明显不清楚或无力 | 总体最高5.0；构图最高5.0；叙事／视觉想法最高5.0 |
| B型核心路径或对象关系不可读 | 总体最高4.5；构图最高4.5；叙事／视觉想法最高4.5 |
| C型声称全幅秩序，但画面主要呈现随机杂乱、无可读节奏 | 总体最高5.0；构图最高5.0；叙事／视觉想法最高5.0 |
| D型声称形面分区，但面积与边界关系不可读或近乎偶然 | 总体最高5.0；构图最高5.0；叙事／视觉想法最高5.0 |
| 关键视觉信息严重意外失焦 | 技术最高3.5；总体最高4.0 |
| 关键视觉信息明显意外失焦但仍可读 | 技术最高4.5；总体最高5.0 |
| 严重抖动或意外动态模糊使关键视觉信息难以阅读 | 技术最高4.0；总体最高4.5 |
| 明显抖动或意外动态模糊削弱关键视觉信息 | 技术最高5.0；总体最高5.5 |
| 严重过曝剪切关键视觉信息 | 技术最高4.5；光线最高4.5；总体最高5.0 |
| 严重欠曝隐藏关键视觉信息 | 技术最高4.5；光线最高4.5；总体最高5.0 |
| 可见水平线／垂直线无意倾斜 | 构图最高6.0；总体最高6.5 |
| 主导干扰、尴尬裁切、边缘截断或视觉失衡破坏主要契约 | 构图最高5.5；总体最高6.0 |
| A/B型关键对象过小且不能通过裁切恢复 | 构图最高5.5；叙事／视觉想法最高5.5；总体最高6.0 |
| 主要为普通记录、证据、产品/标识、损坏/用途或事件说明，没有可见摄影想法 | 叙事／视觉想法最高5.0；总体最高5.5 |
| 光线普通，且主体、关系、秩序和形面均弱 | 光线最高5.5；叙事／视觉想法最高5.5；总体最高5.5 |
| 不同维度同时出现多个重大问题 | 总体最高4.5 |

注意：

- “主体不清”封顶只适用于照片确实依赖主体层级的情况。
- C型和D型不能仅因没有唯一主体、人物或落点而触发主体封顶。
- 取消错误主体封顶不等于取消边缘、失衡、随机裁切、曝光、失焦和杂乱封顶。
- 如果C型或D型的形式契约本身不成立，应使用对应的契约失败封顶，而不是给风格豁免。

## 七、基础问题逃逸

通用硬伤或契约失败存在时，从相应封顶开始。只有画面同时具有真正强的补偿项，才允许总体进入5—5.5，清楚可见时才可接近6：

- 强光线或气氛；
- 虽有局部问题但主要契约仍明显强；
- 强瞬间、关系、表达或视觉转换；
- 清楚而有效的故意处理；
- 稀有或有视觉兴趣的对象，并得到一定控制。

有基础问题或主要为记录的照片，不得超过6；除非问题只是轻微，并且至少两项优势清楚可见。

## 八、故意形式与偶然杂乱

将模糊、暗调、高调、高反差、异常取景、小主体、负空间、剪影、粗糙纪实、全幅秩序、非中心结构或大面积分区视为故意处理，至少需要以下两项成立：

- 处理支持清楚的主体、关系、情绪、节奏、面积关系或视觉想法；
- 画面存在锐利、稳定或结构明确的锚点；
- 四边、裁切、透视和视觉重量受到控制；
- 效果具有选择性或一致性，而不是全画面随机失控；
- 能识别出成熟类型语言，如摇拍、长曝光、剪影、高调极简、低调、重复图案、类型学、色域分区或镜像；
- 用户明确说明意图，并且结果支持该说明。

少于两项时，按意外问题保守评分。意图只能改变问题的解释，不能替代执行质量。

## 九、高分资格

先应用所有通用硬伤和契约失败封顶。真正的封顶不能因气氛、线条或作者偏好绕过。

7.5、8或8.5必须全部满足：

- 主要视觉契约和视觉命题立即可读；
- 无严重技术硬伤；
- 至少两个维度明确强，而非只是合格；
- 背景、边缘、裁切和视觉重量受到足够控制；
- A型主体层级清楚；B型路径或关系清楚；C型秩序贯穿全画面；D型面积、边界和区域张力明确；
- 具有超越记录价值的视觉意图。

7.5用于强照片仍有一个有意义的限制；8用于至少两项强、剩余问题轻微可修；8.5需要强瞬间、情绪、关系、光线、构图、视觉转换或高度形式控制形成鲜明记忆点。

C型和D型进入7.5以上时，至少还需满足：

- 不规则与断裂像主动决定，而不是完成度不足；
- 形式选择在四边和整个画面持续成立；
- 除构图外，光线、技术、色彩体验或视觉想法至少还有一项明显强。

不能因为照片属于抽象、极简、全幅或色域分区，就降低高分门槛。

## 十、评分纪律

- 每张照片必须独立评分，不参考同批或前后照片、旧分数、作者进步趋势或期望分布。
- 不做批次归一化、强制曲线或事后分数重映射。
- 完整执行：视觉契约、视觉命题、基础问题、方向、逐项硬伤、故意处理、色彩、高分资格、五项分数。
- 分数可以使用一位小数，但只用于表达具体差异，不制造伪精度。
- 形式类别只改变评价路径，不提供风格加分。
- 严重技术问题在任何视觉契约下都必须正常扣分和封顶。
- 若无法确定契约或意图，说明不确定性并保守评分。

## 十一、校准点评输出

每次校准必须完整包含：

- 一句话总评；
- 评分前检查：主要契约、辅助契约、视觉命题、基础问题等级、逐项硬伤检查、故意处理判断、高分资格；
- 五项评分：技术、构图、光线、叙事／视觉想法、总体；
- 色彩观察；
- 封顶规则；
- 做得好的地方；
- 优先修改项：问题、为什么、下次怎么拍、这张怎么修；
- 建议设置；看不出来时明确说明是估计；
- 后期步骤；
- 下一次练习任务。
