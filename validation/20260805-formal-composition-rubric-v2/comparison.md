## 关键变化

### 符合修订目标的上调

- 蓝天与树线：5.0 → 6.0。取消错误的“主体偏弱”封顶，但仍因边界、天空层次和洁净度停在6分。
- 俯拍荷叶与黄色小花：4.8 → 5.9。不再因没有唯一落点封顶，同时仍明确指出四边、密度和光线一致性不足。
- 粉色荷花与满幅荷叶：5.4 → 6.2。形式命题得到承认，失焦、裁切和光线问题仍阻止进入6.5—7。
- 草与横向铁丝：5.8 → 6.5。没有被强迫增加主体，但下缘复杂度、间距和普通光线仍限制高分。
- 沙丘与天空：6.1 → 7.0。形面比例与山脊边界能够独立构成可分享照片，但没有因极简风格进入7.5以上。

### 仍然受到约束的低完成度照片

- 杂乱紫色野花：5.3 → 5.5，仍按主体与背景竞争处理，没有被误认成全幅秩序。
- 悬挂花布：5.5 → 5.9，形式想法被看见，但底边人头和边缘切割继续触发6分封顶。
- 蓝天草地：5.5 → 6.0，形面意图成立，但右侧枝叶和下沿杂物继续触发6分封顶。
- 浅色沙丘：5.6 → 5.8，天空污点在极简画面里仍作为主导干扰处理。

### 需要进一步校准的分歧

- 黄色花朵绿散景：5.0 → 6.0。旧评把花瓣高光认定为严重剪切，新评认为仍有纹理、不触发封顶。这不是形式契约造成的上调，而是“重要高光何时达到严重过曝”的可操作定义不够稳定。
- 鸟与电线：7.5 → 6.8；红砖山墙：7.5 → 6.9。候选规则的高分资格被独立评分者执行得偏严，只承认构图一项明显强，说明“第二个明显强项”仍需更清楚的证据例子。
- 经幡山亭、紫色灯廊：8.0 → 7.5。仍属于强照片，没有被压回中低分，但候选规则更强调前景重量、色彩层次和终点精度。
