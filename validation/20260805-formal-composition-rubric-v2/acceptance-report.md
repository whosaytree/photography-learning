# 候选 Rubric V2 校准验收报告

## 结论

> **方向通过，候选文本暂不直接覆盖正式规则。**

新标准成功修正了“没有唯一主体就低分”的结构性偏差，同时没有造成整体分数膨胀，也没有让低完成度形式照片进入高分区。它已经证明核心方案有效。

但在正式替换前，建议制作一个小幅修订的V2.1版本，解决两类一致性问题：技术硬伤严重程度的可操作界线，以及高分资格中“第二个明显强项”的证据门槛。

正式 `SCORING_RUBRIC.md` 保持不变。

## 执行完整性

- 完成35张，位于要求的30—40张范围内。
- 每张评分都只接触候选规则、摄影基础框架、该照片的方向信息和原图。
- 评分阶段禁止读取旧点评、旧分、其他照片、样本分组和批次背景。
- 一次任务只评价一张照片；没有多图提示、批量生成或脚本评分。
- 每张均生成完整的评分前检查、五项分数、色彩、封顶、优点、修改项、设置、后期和练习任务。
- 机械核验显示35份结果均包含全部10个规定部分。
- 旧分只在35张全部评分结束后读取。
- 有一个任务异常长时间未输出，被中断后只在同一张照片、同一独立上下文中继续；没有接触其他照片。
- 第36张预留样本因独立任务总数上限未启动。没有用受其他照片影响的上下文补评，最终保留35张。

## 为什么没有出现“给偏好放水”

候选规则把“类别成立”和“分数增加”分成两道门：

1. 先确认主体、路径、全幅秩序或形面分区中，是否有一种从画面本身可读；
2. 再检查该契约是否落实到清晰度、四边、节奏、比例、光线和全画面控制。

因此，取消主体封顶只移除了错误判罚。形式照片仍然会因以下问题被扣分或封顶：

- 关键纹理失焦；
- 间距和密度随机；
- 画面边缘截断不一致；
- 极简空白中的污点；
- 面积分区比例犹豫；
- 边界弱、区域分离不足；
- 前景杂乱破坏色面；
- 只有形式表象，没有第二项强度支撑高分。

## V2.1建议修改

### 1. 收紧技术硬伤的证据描述

在“严重过曝剪切关键视觉信息”后增加：

> 只有当关键区域出现连续、无纹理的纯白/单色块，并且该丢失覆盖主体识别、材质或形状的重要部分时，才应用严重过曝封顶。小面积镜面高光、灯芯或仍保留可读纹理的亮部不触发该封顶，只作程度扣分。

对失焦也增加同类面积与功能判断，减少不同评分者对“明显偏软”和“关键视觉信息失焦”的漂移。

### 2. 澄清高分资格的第二强项

增加：

> “第二个明显强项”可以来自技术、光线、色彩体验、叙事／视觉想法或时机；不要求第二项与构图同样突出，但必须对照片成立产生不可替代的作用。一个可修的小边缘问题不能单独把已经满足两项强度的照片从7.5压回6.5—7。

同时加入正反例：鸟与电线、红砖山墙用于判断7与7.5的边界；经幡山亭和紫色灯廊用于判断7.5与8的边界。

### 3. 防止B型吸收所有混合构图

在契约选择处增加反事实检查：

> 不要因为画面里存在斜线、重复或一个可辨对象就默认选择B。先问：如果忽略终点或对象关系，照片是否仍主要依靠全幅节奏或面积边界成立？若是，C或D应为主要契约，B只能作为辅助契约。

### 4. 保留现有防膨胀机制

以下内容不应放松：

- 5分普通记录基线；
- 全部技术硬伤封顶；
- C/D型契约失败封顶；
- 7.5以上至少两项强度；
- C/D型必须把形式控制贯彻到四边；
- 风格声明不能替代照片证据。
