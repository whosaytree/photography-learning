# v1.1.2 构图干扰“移除测试”定向验证计划

## 目标

验证候选改动能减少主导前景、边缘内容和阴影的漏判，同时不恢复 v1.0 对自然边缘、满幅图案、有意前景和一般杂乱的误封。

## 方法

- 只测试候选修改的构图干扰条款；其余视觉判断与分数冻结，以隔离规则效果。
- 每张判断：是否存在候选元素、是否形成竞争重量、移除后是仅更整洁还是会明显恢复主要阅读、是否触发本条封顶。
- 若候选条款不改变判定，五项分数保持 v1.1.1 结果；若从漏判变为命中，只允许构图分和总体分向原封顶收敛。

## 预设通过条件

1. 3 张已确认漏判的主导前景／边缘／阴影样本全部命中。
2. 6 张原本正确命中的构图硬伤继续命中。
3. 1 张其他类别硬伤不新增构图封顶。
4. 8 张正常／风格对照不新增构图封顶，其中满幅关系、自然边缘、有意前景、雾气和正常风景均须保住。
5. 非目标样本总体分变化为 0；目标样本只因构图封顶变化。
