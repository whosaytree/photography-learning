# 语义边界候选 V4：预注册验收条件

## 语义定义

- 历史高分11张：08、09、12、16、17、18、25、26、27、34、35。低分边界为6.5以下。
- 非目标旧低分20张：除目标类23、24、28、32外，历史分低于7.5的全部照片。高分边界为7.5。
- 目标类4张：23、24、28、32，按自身完成度自由分层。
- 事实硬伤10张：02、03、11、15、19、20、21、22、30、31。

## 盲态有效性

每张使用全新独立上下文，只读取摄影技能、V4唯一候选、本张盲态元数据与原图；不得读取正式规则、验收条件、历史资料、其他照片、候选、结果或对话；不得使用批量评分脚本。35张全部完成前不读取结果。正式规则保持原哈希。

## 单轮探索门槛

1. 历史高分至少10/11达到6.5，任何一张不得低于6.0。
2. 非目标旧低分至少19/20低于7.5；事实硬伤10/10不得达到7.5。
3. 目标类不设最低分、目标分、增幅或分布。
4. 每一次实际7.5以上都须100%满足：无生效硬伤；至少两项明显强维度；每项各有独立的可见事实和结果；普通技术7不算第二强项。8分另须符合原版8分定义。
5. 另行报告事实硬伤正确大类命中率和无硬伤误封情况，但不以单轮命中率否决候选；只有事实硬伤进入7.5才构成边界失败。

## 三轮复验门槛

探索通过后做105次全新独立评分：

1. 历史高分11张三轮中位数均不低于6.5，任何单次不得低于6.0。
2. 非目标旧低分20张三轮中位数均低于7.5；事实硬伤任何一次不得达到7.5。
3. 目标类不设分布；任何高分执行统一证据审计。
4. 所有实际7.5以上的证据审计通过率100%；任何一张不得只在1/3轮偶发高分。
5. 硬伤正确大类和无硬伤误封按三轮逐张报告；如果某张3/3系统性误判，则候选不放行。除此之外，不再用具体分差、极差或硬伤命中总数要求单次评分复现历史判断。

三轮全部通过后仍须用户确认，才可覆盖正式规则。
