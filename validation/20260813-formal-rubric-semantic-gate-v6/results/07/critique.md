# 一句话总评

这张照片抓到了孩子向前奔跑的活力，弯曲小路、抬起的脚和地面影子共同形成了清楚的动势，但主体细节偏糊、正午光线生硬以及下方空路面过多，让它停留在“有明确瞬间、完成度仍需加强”的阶段。

# 评分前检查

- **主体**：画面中近处正在奔跑的孩子，主体能够被立即识别；地上的人物影子是有效的辅助视觉元素。
- **题材**：公园环境中的儿童纪实／生活抓拍，不是单纯的地点或人物到此一游记录，画面有可见的动作瞬间和空间关系。
- **基础问题等级**：基础问题。主体虽清楚可读，但跑动造成的整体虚化偏重，没有留下足够清晰的人物细节；问题影响观看质量，但没有让主体难以辨认。
- **逐项硬伤检查**：
  - 主体不可读：否，孩子的轮廓、衣着、跑动方向和姿态都清楚。
  - 主体存在但不清楚或过弱：否，主体在画面中的面积、明度和位置足以形成落点。
  - 严重失焦：否，没有达到主体难以辨认的程度。
  - 明显意外失焦：不单独按失焦封顶；画面更接近移动主体产生的选择性运动虚化，而不是焦点完全落到错误景深平面。
  - 严重手抖或运动模糊：否，环境仍相对稳定，主体也可读。
  - 普通明显运动模糊：不作为硬伤封顶。虚化集中在跑动人物，稳定的道路和绿篱提供锚点，且模糊与奔跑动作相符，具备故意效果的多项证据；但效果只部分成功，仍会降低技术分。
  - 严重过曝／欠曝：否，亮部和暗部总体仍有层次，重要主体细节没有因曝光直接消失。
  - 地平线或垂直线意外倾斜：否，观看方向正常，路灯和树木没有形成阻碍观看的明显歪斜。
  - 主导干扰、尴尬裁切、边缘切断或失衡：否。右边缘路灯和远处人物属于次要环境信息，并未大面积遮挡主体或破坏主要路径；但右侧路灯贴边、下方空路面偏多是普通构图瑕疵。
  - 主体过小且无法裁切挽救：否，孩子已有足够画面占比。
  - 普通记录照封顶：否，跑动姿态、影子与道路纵深提供了超出信息记录的瞬间感。
  - 光线平淡且叙事弱：否。光线本身较普通，但叙事并不弱，因此不触发组合封顶。
  - 多个不同维度的重大问题：否。
- **高分资格**：不满足 7.5 分以上资格。叙事中的跑动瞬间是明确强项，但技术控制未达到强项标准，构图在空路面、右边缘和背景简化上也仍有明显限制；扣除这些限制后，没有两项彼此独立且仍然清楚成立的强维度。
- **故意处理判断**：人物虚化与跑动主题一致，背景相对稳定、模糊具有选择性，构图中的道路也继续把视线引向人物，符合至少两项故意效果证据，所以不把它当作纯粹误操作硬伤。不过人物头部、衣服纹理和四肢边缘都软得较明显，虚化尚未形成漂亮的方向性拖影，因此只能算部分成功。

# 五项评分

- **技术：5.5/10**  
  整体曝光可用，亮部没有明显毁掉主体，环境也有基本层次；但孩子从帽子到衣服、裤脚和鞋都缺少清晰锚点，运动虚化带来的细节损失明显。画面还略显柔软，锐度和微反差不足。
- **构图：6.5/10**  
  红色道路从前景进入画面并向左后方转折，绿篱形成两侧边界，能把视线先送到孩子、再带向远处，孩子与影子也形成了有趣的双重形状。限制在于下方和右侧空路面占比偏大，视觉重量有些松散，右边缘路灯又略显突兀，远处落点也比较杂。
- **光线：5.5/10**  
  正午硬光让色彩明快，并留下清楚的跑动影子，给动作增加了一层信息；但人物顶部和道路亮部较硬，绿植暗部偏沉，光线对人物形体和面部信息的塑造有限，更多是提供可见度和夏日感。
- **叙事：7/10**  
  抬起的脚、前倾身体、向远处延伸的道路和同行方向上的小人物，共同给出“孩子向前跑去”的明确瞬间。影子加强了动作感，公园纵深也让画面具有去往某处的空间关系，不只是识别人物和地点。
- **总体：6.5/10**  
  照片有清楚的拍摄意图和有效瞬间，已经超过普通记录照；但主体清晰度、硬光控制和画面收束都不够稳，还没有达到两项强维度同时成立的高分门槛。

# 色彩观察

画面以高饱和的黄绿色植被、偏粉红的道路和蓝天为主，冷暖对比鲜明，整体传达出明亮、炎热、活泼的夏日感觉。白色上衣和浅蓝裤子能从深绿色背景中分离出来，红色道路也自然承担了引导视线的作用，因此色彩确实在帮助主体和空间组织。

不足是绿色与黄色略显浓重，粉红路面面积又很大，两块高饱和色域会争夺注意力；部分深绿阴影略脏，亮处则稍显发白。后期可先把黄色和绿色饱和度各降低约 8%—15%，绿色明度略降但提一点阴影洁净度；再把洋红／红色饱和度降低约 5%—10%，避免道路压过人物。白平衡保持中性或只轻微降温，不必把夏日暖感完全去掉。对孩子做局部提亮和微反差增强，比继续增加全局饱和度更有效。

# 做得好的地方

- 抓拍时机有效：孩子抬腿、身体前倾，动作处在容易识别的阶段，奔跑感不依赖文字解释。
- 道路和绿篱形成自然引导线，视线能够从前景进入、经过孩子，再向远处移动。
- 人物影子轮廓清楚，不只是附属黑块，而是在画面下方重复并强化了奔跑姿态。
- 孩子的浅色服装与深绿背景有亮度分离，主体即使细节偏软，仍能迅速被找到。
- 近处人物、弯曲道路和远处行人构成前中后三层，公园空间感成立。

# 优先修改项

## 1. 先保证移动主体有一个清晰锚点

- **问题**：孩子全身都有明显运动虚化，帽沿、衣服图案和四肢边缘都不够利落。
- **为什么**：动作姿态本身已经足够传递速度，不需要让整个主体都失去细节；目前的模糊虽能表达运动，却也削弱了人物作为主角的观看停留点。
- **下次怎么拍**：使用连续对焦，把焦点区域放在孩子上半身，快门提高到至少 1/500 秒；如果跑动速度快或距离较近，优先尝试 1/800—1/1000 秒。开启高速连拍，连续拍三到五张，从中选头部或躯干最清楚、腿部姿态最好的一张。
- **这张怎么修**：后期无法真正恢复丢失的运动细节。只对帽沿、肩部、衣服图案和裤脚做轻量局部纹理／清晰度与锐化，控制光晕；适当缩小输出尺寸能改善观感，但不要用过强锐化制造白边。

## 2. 收紧下方与右侧，让画面更集中

- **问题**：下方和右侧大面积红色路面没有新的信息，右边缘路灯又形成一条深色竖线。
- **为什么**：多余空地把视觉重量拉向右下角，使孩子和道路转弯处之间的关系变松；路灯虽然不是硬伤，却会在边缘持续吸引余光。
- **下次怎么拍**：在孩子进入理想位置前先决定画面边界，机位略向左转并稍微抬高，保留孩子前进方向上的道路，减少身后和右下方空地。按下快门前快速扫一遍四边，确认是否有贴边竖杆。
- **这张怎么修**：尝试从底部裁掉约 8%—12%，从右侧裁掉约 10%—15%，尽量去除贴边路灯，同时保留孩子左前方的行进空间和道路转弯。裁切后让孩子靠近右侧三分线、影子仍完整，会比把孩子裁到正中央更有方向感。

## 3. 控制正午硬光和高饱和绿植

- **问题**：人物和道路受光偏硬，植被明暗反差大，绿色与黄色略显过饱和。
- **为什么**：硬光没有很好地塑造背向镜头的人物，反而让环境色块比人物细节更抢眼；暗绿背景也容易显得厚重、脏。
- **下次怎么拍**：条件允许时在上午较早、下午较晚或薄云天气拍摄；如果只能正午拍，寻找树荫边缘的均匀光，或让人物处在逆光／侧逆光位置并按人物曝光，避免头顶直射光。
- **这张怎么修**：全局高光降低约 20—35，阴影提升约 10—20；黄色和绿色适度降饱和，必要时用蒙版单独提亮孩子约 0.2—0.4EV，并给人物增加少量纹理和局部对比。不要全局大幅提阴影，以免绿植变灰和噪点变重。

# 建议设置

以下为根据画面运动状态作出的估计，不是对原始拍摄参数的读取：

- 模式：快门优先或手动模式。
- 快门：先从 **1/640 秒**开始；孩子快速奔跑时提高到 **1/800—1/1000 秒**。
- 光圈：约 **f/4—f/5.6**，兼顾人物清晰和一定环境信息。
- ISO：自动 ISO，晴天可把上限设在 **ISO 800** 左右，让相机优先守住快门。
- 对焦：AF-C／连续对焦，人物追踪或中等大小区域对焦，持续锁定孩子上半身。
- 连拍：高速连拍，每次短按三到五张，避免长时间无选择扫射。
- 测光／补偿：评价测光；若白色衣服在直射光下过亮，可尝试 **-0.3EV** 曝光补偿并检查高光提示。

# 后期步骤

1. 启用镜头校正和色差去除，先确认整体曝光不过度抬亮。
2. 从底部和右侧收紧画面，去掉右边缘路灯，并保留孩子前进方向的空间。
3. 高光降低 20—35，阴影提升 10—20，黑色色阶只轻微调整，保持树木层次。
4. 调整 HSL：黄、绿饱和度降低 8%—15%，洋红／红色饱和度降低 5%—10%，避免道路和植被抢主体。
5. 给孩子建立局部蒙版，曝光提高约 0.2—0.4EV，纹理和清晰度各少量增加；蒙版边缘要柔和。
6. 仅对人物轮廓和衣服纹理做遮罩锐化，背景不要一起加锐；若出现白边立即回退。
7. 最后以较小尺寸预览，确认视线先到孩子而不是路面、右边缘或高饱和绿植，再导出 sRGB。

# 下一次练习任务

在同一类公园小路上完成一次“跑动人物清晰锚点”练习：固定一个取景范围，让人物沿道路跑过三次，分别用 1/250、1/500、1/1000 秒拍摄，每档至少拍十张，并保持连续对焦。回看时只比较三件事：头部／躯干是否有清晰锚点、腿部姿态是否有力量、道路是否仍把视线带向人物。最后每档各选一张，记录哪一个快门速度能在保留动作感的同时让主体最容易停留观看。
