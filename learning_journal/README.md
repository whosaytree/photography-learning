# 个人摄影学习阶段日记

这个目录记录的是“整批照片与个人风格的阶段性变化”，不替代 `data/archive/` 中的单张照片点评。

## 两类记录

- `entries/`：正式阶段复盘。只有在一批新增照片已经完成单张点评，并做过总体评价、与前一阶段比较后才新增。它会推进学习路径。
- `notes/`：专题补记。用于记录某一种偏好、构图方法或学习方向，但不代表一次完整批次，也不会改变“最近一次阶段复盘”。

## 下次如何使用

当用户要求“总体评价今天新增的照片”“和以前比较”“更新我的风格描述”时：

1. 先读 [LATEST.md](./LATEST.md)，再读其中指向的最近一篇正式阶段复盘。
2. 确认本次新增照片的日期范围和数量；单张评分仍按各自画面独立完成，不因过去分数而调整。
3. 在批次层面比较：稳定优势、重复问题、新出现的视觉偏好、旧问题是否改善，以及下一阶段练习重点。
4. 按 [TEMPLATE.md](./TEMPLATE.md) 新建一篇 `entries/YYYY-MM-DD-stage-review.md`。
5. 更新 [INDEX.md](./INDEX.md) 和 [LATEST.md](./LATEST.md)。

如果只是讨论某一种风格、摄影师或构图偏好，应写入 `notes/`，不要把它误标成完整批次复盘。

## 来源标注

每篇记录都要注明：

- 日期和照片范围；
- 记录性质；
- 原始材料来自本地文档、历史任务原文，还是根据存档回溯重建；
- 是否属于正式比较链；
- 上一篇正式阶段复盘。
