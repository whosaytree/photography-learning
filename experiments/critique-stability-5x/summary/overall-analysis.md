# 摄影点评稳定性实验总体报告

## 实验设置

- 测试集：从只读归档图片中复制出的 20 张隔离图片。
- 重复次数：每张图片 5 次，共 100 次独立点评。
- 独立性控制：每次点评由隔离子 agent 生成，只允许读取原图和规则文件，只写入自己的 `run-N.md`。
- 文字一致性：先按 codebook 编码为 `tags.json`，再用公式计算，不直接凭主观印象下结论。

## 总体结果

- 总体分平均极差：0.61。
- 总体分平均标准差：0.248。
- 问题标签平均 Jaccard：0.706。
- 前三优先问题平均重合率：0.695。
- 建议动作平均 Jaccard：0.676。
- 总体分最不稳定图片：photo-10，极差 1.5。
- 问题标签一致性最低图片：photo-18，Jaccard 0.399。

## 主要发现

1. 分数稳定性仍强于文字细节稳定性。20 张图中有 13 张总体分极差不超过 0.5。
2. 高稳定样本：`photo-02`、`photo-07`、`photo-11`、`photo-12`、`photo-13`、`photo-14`。这些图的分数和问题标签都较集中。
3. 明显漂移样本：`photo-09`、`photo-10`、`photo-15`、`photo-16`、`photo-18`。这些图应优先回看 run 文本。
4. 总体分最不稳定的是 `photo-10`，总体分为 5.5/4.5/5.5/5/4，极差 1.5。
5. 文字问题标签最不一致的是 `photo-18`，问题标签 Jaccard 为 0.399。
6. 需要重点复查的边界/规则漂移样本：`photo-09`、`photo-10`、`photo-15`、`photo-16`、`photo-18`。

## 方法限制

- `subject` 和 `genre` 是自由文本，精确字符串一致率会低估语义一致性。后续应在 codebook 中增加 `subjectTag` 和 `genreTag`。
- 标签编码仍由模型完成，虽然最终指标由公式计算，但编码本身可能有少量主观差异。严谨版本可以让两名编码员独立编码后再仲裁。
- 当前测试集有 20 张图，已经能暴露主要漂移类型，但仍不足以代表所有题材和所有硬伤组合。

## 改进建议

1. 在正式点评模板中强化“封顶规则先行”的输出约束，尤其是普通基础问题和逃逸规则。
2. 把 `基础问题等级`、`封顶规则`、`高分资格` 改成更标准化的短标签，减少自由文本漂移。
3. 对边界图增加专门判定句：先列出故意处理测试满足几条，再决定是否按硬伤处理。
4. 扩充测试集到 20-30 张，并按题材和硬伤类型分层抽样。
