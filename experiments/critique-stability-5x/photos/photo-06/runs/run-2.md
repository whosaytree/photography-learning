# photo-06 run-2 摄影点评

## 一句话总评

这是一张完成度较好的夜间旅行街景：彩色灯笼和街道纵深很吸引人，但顶部黑天空偏多、边缘元素略乱，让画面从“有气氛”差一点到“更精炼”。

## 评分前检查

- 主体：悬挂在街道上方的一组彩色灯笼，尤其是上方的大黄灯笼和右上粉色灯笼。
- 题材：夜间旅行街景 / 城市街拍 / 灯饰氛围照。
- 基础问题等级：无。主体清楚，曝光和对焦基本成立，没有影响观看的严重基础失败。
- 硬伤封顶检查：
  - 主体不可读：否。
  - 主体存在但不清楚或很弱：否，灯笼主体明确。
  - 主体严重虚焦：否。
  - 主体明显虚焦但仍可读：否。
  - 严重手抖或运动模糊：否。
  - 明显手抖或运动模糊削弱主体：否。
  - 重要主体严重过曝：否。灯笼有局部高光溢出趋势，但主体纹理和轮廓仍可读。
  - 重要主体严重欠曝：否。黑天空很暗，但不是重要主体。
  - 地平线 / 垂直线无意倾斜：不作为硬伤。画面是仰拍街景，右侧建筑倾斜主要来自透视。
  - 主导背景干扰竞争主体：否。边缘截断灯笼和招牌有干扰，但没有压过主体。
  - 主体太小且无法裁切恢复：否。
  - 主要是普通记录、无明确摄影意图：否。灯笼重复、色彩对比和街道引导线有明确意图。
  - 光线平淡且故事弱：否。灯笼光色是画面主要优点。
  - 多个维度重大缺陷叠加：否。
- 高分资格：具备 7.5 分附近资格。主体立即清楚，无严重硬伤，光线氛围和构图纵深两项较强；但边缘控制、顶部留白和人物时刻还不够精炼，所以不到 8。
- 故意处理判断：
  - 黑天空：基本是夜景环境造成，也帮助突出灯笼，属于可接受的低调背景。
  - 高反差：符合夜间灯笼街景的题材，主体轮廓仍清楚，算有效处理。
  - 不规则仰拍透视：有意用来表现灯笼悬挂和街道延伸，不算倾斜硬伤。
  - 局部高亮和饱和：灯笼自身发光导致，效果有氛围，但后期可以再压一点高光。

## 做得好的地方

- 灯笼颜色非常抓眼，红、黄、粉、蓝形成了清楚的冷暖对比，第一眼有节庆和夜游气氛。
- 街道两侧建筑和灯笼排列形成纵深，视线会自然从上方大灯笼走向远处街道。
- 夜景曝光总体可用，暗部没有强行提得很灰，黑天空反而把灯笼衬得更亮。
- 画面里有人和店铺，保留了真实街区的生活感，不只是拍一排灯。

## 优先修改项

### 1. 顶部黑天空占比偏大

- 问题：画面上半部大面积黑天空，尤其右上和中上区域信息较少。
- 为什么：黑色背景能突出灯笼，但占比过大时，会让下方街道和人间烟火感被压缩。
- 下次怎么拍：机位稍微低一点但镜头下压一点，保留大灯笼，同时让远处街道和人群多进入画面；或者横向多试一张，把灯笼串和街道压成更完整的斜线。
- 这张怎么修：从顶部裁掉约 10%-15%，右侧也可少量裁切，保留上方大黄灯笼的线和右上粉灯笼，但减少纯黑空白。

### 2. 边缘截断元素有点抢眼

- 问题：左下红灯笼、右侧半个红灯笼、右下角露出的人脸都在画面边缘被切断。
- 为什么：边缘的高饱和红色和人脸会吸引视线，把注意力从主灯笼和街道纵深拉走。
- 下次怎么拍：拍摄前扫一遍四个边角，向左或向右挪半步，等边缘人物离开，或者干脆更大胆裁掉边缘杂物。
- 这张怎么修：右侧裁掉一点，让右边半个红灯笼和右下人脸减少存在感；左下如果不想大裁，可以用暗角或局部降低饱和度处理。

### 3. 灯笼高光和饱和度略满

- 问题：部分红色、黄色灯笼亮度和饱和度较高，细节有被压扁的感觉。
- 为什么：夜景发光体很容易过曝，一旦高光顶住，灯笼表面的材质和层次会变少。
- 下次怎么拍：拍灯饰时优先保护高光，可以尝试曝光补偿 -0.3 到 -0.7EV；拍完回看最亮的黄色和红色灯笼，确认没有大面积纯白或纯色块。
- 这张怎么修：后期降低高光和白色色阶，红色、黄色饱和度各降一点点；如果软件支持，用蒙版只压灯笼，不要把整张街景压暗。

### 4. 街道里的“人”还不是故事核心

- 问题：画面有人，但没有特别明确的动作、表情或关系，叙事更多停留在“漂亮街景”。
- 为什么：旅行街景如果只有好看的灯，容易偏记录；如果能等到一个清楚的人物动作，照片会更有故事。
- 下次怎么拍：找好这个机位后等 1-3 分钟，等一个人走到灯笼串下方、抬头看灯、经过光亮区域，或者等一组人形成前中后层次再按快门。
- 这张怎么修：可以轻微提亮画面下方中间的人物和地面反光，让街道生活感更明显；不要提太多，否则会破坏夜景氛围。

## 建议设置

看不出真实 EXIF，以下是估计和下次可尝试的方向：

- 如果用相机手持拍：光圈 f/4-f/5.6，快门不低于 1/60s；如果街上人走动明显，尽量到 1/125s；ISO 用 Auto ISO，上限可设 3200 或 6400。
- 如果想让整条街更清楚：用 f/5.6-f/8，但需要更高 ISO 或更稳的手持。
- 曝光补偿：拍发光灯笼建议 -0.3 到 -0.7EV，优先保住灯笼高光。
- 对焦：对在中近距离的主灯笼或街道中部灯笼上，不要只对最远处。
- 白平衡：可以锁定在偏暖的夜景色温，避免自动白平衡每张颜色变化；如果偏黄太重，后期再微调。

## 后期步骤

1. 先裁图：顶部裁掉一部分黑天空，右侧少量裁切，减少边缘半个红灯笼和右下角人脸干扰。
2. 校正透视：不要完全拉直建筑，否则会失去仰拍气氛；只做轻微垂直校正，让右侧建筑不至于太压迫。
3. 压高光：降低 Highlights 和 Whites，重点看黄色、红色灯笼是否恢复层次。
4. 控制颜色：红色和黄色饱和度各降一点，蓝色可保留，因为蓝色给画面提供冷暖对比。
5. 提局部层次：对街道下半部分轻微提 Shadows 或 Exposure，让路面和人物更可读。
6. 降噪与锐化：暗部做轻微降噪，锐化不要太重，避免建筑边缘和灯笼线条出现硬边。
7. 加轻微暗角：只要很轻，用来收住边缘视线，不要把街道压黑。
