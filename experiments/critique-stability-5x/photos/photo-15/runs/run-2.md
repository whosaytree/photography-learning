# photo-15 run-2 摄影点评

## 一句话总评

这张照片拍到了很有辨识度的清真寺建筑、蓝天和水面线条，但画面整体横倒、取景边缘被切得比较随意，使它更像一张有潜力的旅行记录，而不是已经完成的建筑照片。

## 评分前检查

- 主体：白色清真寺建筑群，重点是穹顶、宣礼塔、拱廊和水池形成的建筑秩序。
- 题材：建筑 / 旅行摄影。
- 基础问题等级：基础问题。主体清楚，曝光和清晰度基本可用，但画面方向明显不符合建筑观看习惯，且边缘裁切、垂直线控制不够稳定。
- 硬伤封顶检查：
  - 主体不可读：否，建筑主体清楚。
  - 主体存在但不清楚或偏弱：否，主体明确。
  - 主体严重虚焦：否。
  - 主体明显虚焦但仍可读：否。
  - 严重手抖或运动模糊：否。
  - 明显手抖或运动模糊削弱主体：否。
  - 重要主体严重过曝：否。白色建筑受强光影响偏亮，但仍能看到大部分纹理和形体。
  - 重要主体严重欠曝：否。

  - 主导背景干扰竞争主体：否，背景较干净。
  - 主体太小且无法裁切恢复：否。
  - 多数只是普通记录、摄影意图不清：部分成立。建筑线条有意图，但目前更偏旅行记录，故事分和总体不能太高。
  - 光线平 / 普通且故事弱：部分成立。正午强光清楚但不够有层次，故事主要停留在“到此一游式建筑记录”。
  - 多个重大缺陷叠加：否，没有虚焦、严重曝光失败和主体不可读同时出现。
- 高分资格：不具备。主体清楚，也有重复拱廊和水池引导线，但画面方向错误、边缘裁切不稳、光线偏硬，未达到 7.5 以上所需的至少两个明显强项。
- 故意处理判断：横倒构图不像有效的故意处理。它没有形成抽象秩序，也没有让线条、边缘和观看路径变得更强；更像拍摄或导出时方向没有校正。高反差来自强日照，不是有明确风格控制的高反差。

## 五项评分

- 技术：6.5/10。清晰度和曝光基本可用，天空干净，白色建筑没有完全死白；但强光下高光偏硬，建筑细节层次有限。
- 构图：5.2/10。水池、拱廊和建筑立面本来有很好的引导线，但横倒方向和边缘切塔、切穹顶的问题明显削弱了观看体验。
- 光线：5.5/10。晴天蓝天让建筑干净明亮，但光线偏正午、偏硬，白墙缺少柔和层次，阴影也没有被用来形成更强的立体感。
- 叙事：5/10。能说明“这里是一座宏大的清真寺”，但缺少人物、尺度关系、特殊瞬间或更明确的观看重点，主要是地点记录。
- 总体：5.8/10。主体和线条有潜力，基础技术也过关，但画面方向和构图控制把它限制在“有亮点的旅行记录”层级。

## 封顶规则

地平线 / 垂直线无意倾斜且可见：画面整体横倒，构图最高 6.0，总体最高 6.5。本次构图和总体均低于该封顶。

## 做得好的地方

- 主体选择好：白色建筑、穹顶、拱廊、宣礼塔、水池都很有视觉价值。
- 画面颜色干净：蓝天、白墙、金色装饰、深蓝水面形成了清楚的色彩对比。
- 有线条意识：水池边缘和拱廊重复结构能把视线带向远处，说明你注意到了建筑的秩序感。
- 清晰度基本够：不是虚焦或手抖导致失败的照片，后期和裁切还有修正空间。

## 优先修改项

### 1. 画面方向错误

- 问题：整张照片横倒，建筑的竖直结构变成横向躺着。
- 为什么：建筑摄影最依赖垂直线和稳定感；方向错误会让观众先想“是不是转错了”，而不是先看建筑本身。
- 下次怎么拍：拍完立刻回看一张，确认建筑是直立的；手机拍摄时锁定屏幕方向或等相机识别稳定后再按快门。
- 这张怎么修：先旋转 90 度，让宣礼塔和建筑墙面恢复直立，再重新裁切。

### 2. 边缘裁切太随意

- 问题：穹顶和塔楼在画面边缘被切到，右侧草地和零散设施占了不少空间。
- 为什么：建筑主体本身很强，但边缘不干净会让照片显得像匆忙扫拍。
- 下次怎么拍：先决定要拍“完整建筑”还是“重复拱廊局部”。如果拍完整建筑，给塔尖、穹顶和建筑边缘留出呼吸空间；如果拍局部，就大胆裁掉不相关区域，只保留拱廊、水池和穹顶节奏。
- 这张怎么修：旋转后，裁掉多余草地和右上角杂物，保留水池作为前景引导线，让拱廊占画面主导。

### 3. 垂直线和透视需要更稳

- 问题：建筑线条有明显倾斜和压迫感，宏伟感被削弱。
- 为什么：建筑摄影里，竖线不稳会让建筑像要倒；除非你有意拍夸张透视，否则初学阶段应先练直。
- 下次怎么拍：相机尽量端平，不要大幅仰拍；打开网格线，用建筑边缘对齐网格。必要时退远一点，再用后期裁切。
- 这张怎么修：在后期里使用“几何 / 透视校正 / 垂直校正”，让主要墙面和塔身更接近竖直。

### 4. 光线时间偏硬

- 问题：白色建筑在强日照下很亮，纹理层次不够柔和。
- 为什么：正午或接近正午的强光会让白墙高光刺眼，阴影也容易变硬，建筑的细节美感会被压缩。
- 下次怎么拍：尽量选择清晨或傍晚，侧光会让拱廊、雕花和穹顶更有体积；如果只能白天拍，优先找有阴影形状、反射水面或人群尺度的角度。
- 这张怎么修：降低高光，轻微增加纹理 / 清晰度，避免整体加曝光；白墙不要修到纯白一片。

## 建议设置

看不出真实 EXIF，以下是估计建议：

- 手机或相机拍建筑：使用默认广角或 24-28mm 等效焦段即可，但要注意边缘变形。
- ISO：白天用最低 ISO 或自动 ISO。
- 快门：白天手持通常足够快，重点不是速度，而是端平和构图。
- 光圈：如果是相机，建筑建议 f/8-f/11；如果是手机，不需要手动控制光圈。
- 对焦：点按建筑中部或拱廊区域，避免只对天空。
- 曝光补偿：白色建筑容易被拍灰或高光过亮，可以现场试 -0.3EV 到 -0.7EV，优先保住白墙纹理。
- 辅助工具：打开九宫格 / 水平仪；拍建筑时把垂直线对齐网格。

## 后期步骤

1. 先旋转画面，让建筑恢复直立。
2. 做透视校正，优先让主体墙面和宣礼塔接近竖直。
3. 重新裁切：减少草地和边缘杂物，保留水池与拱廊形成的引导线。
4. 降低高光，保住白色墙面的纹理。
5. 轻微提升阴影，让拱廊内部细节更可读。
6. 适度增加纹理 / 清晰度，但不要让天空和白墙出现脏噪点。
7. 蓝色和绿色饱和度少量控制，避免水池和草地抢过建筑主体。

## 下一次练习任务

下次拍同类建筑时，做一个“三张建筑线条练习”：

1. 正面稳定照：建筑竖直，主体完整，边缘不切塔尖和穹顶。
2. 引导线照：用水池、走廊或地面线条把视线带向主体。
3. 局部秩序照：只拍拱门、柱子、穹顶或倒影的重复图案，少放天空和杂物。

每拍一张后立刻回看三个问题：建筑是不是直的？主体边缘有没有被尴尬切掉？画面里有没有一块区域比主体还抢眼？
