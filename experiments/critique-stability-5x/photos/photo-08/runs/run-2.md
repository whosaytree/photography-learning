# photo-08 run-2 摄影点评

## 一句话总评

这是一张有云雾气氛和前中后景层次的风光照，已经不是普通记录照；主要问题是上半部亮雾和天空面积过大，导致山体主体的力量被稀释。

## 评分前检查

- 主体：云雾中的山谷、山脊，以及右下角松林作为前景锚点。
- 题材：山岳风光 / 云雾风光。
- 基础问题等级：无。画面可读，主体方向清楚，没有明显虚焦、严重抖动或曝光失败。
- 硬伤封顶检查：
  - 主体不可读：否。
  - 主体存在但不清或偏弱：否。云雾会降低清晰度，但这里符合山岳云雾题材。
  - 主体严重虚焦 / 明显虚焦：否。
  - 严重手抖或运动模糊：否。
  - 严重过曝遮挡主体细节：否。天空和雾区偏亮偏空，但没有把主要山体完全毁掉。
  - 严重欠曝遮挡主体细节：否。
  - 地平线或垂直线明显歪斜：不明显。
  - 背景干扰抢主体：否。
  - 主体太小且无法裁切恢复：否。
  - 普通记录且无摄影意图：否。前景松林、山谷层次和雾气氛围有明确意图。
  - 光线平淡且故事弱：否。光线偏平，但云雾带来了气氛。
  - 多个重大问题叠加：否。
- 高分资格：可以考虑 7.5，但不建议给到 7.5 以上。理由是主体清楚、没有严重硬伤，构图层次和云雾气氛有优势；但上方空白亮雾占比过大，视觉落点还不够集中。
- 故意处理判断：
  - 雾化、低反差：判断为题材和天气带来的有效氛围，不按失误处理。
  - 偏亮天空 / 高亮雾区：部分合理，但当前亮区面积偏大，削弱观看重点。
  - 非常规大面积留白：有一定意图，但留白没有形成足够强的极简效果，因此只算中等有效。
- 低分规则应用：没有严重基础失败，不进入 3-4.5 区间；也不是普通基础问题照，不需要封顶在 5。
- 逃逸规则：不需要启用。此图没有明确硬伤封顶。

## 做得好的地方

- 右下角松林提供了稳定前景，让画面不是单纯远山记录照。
- 中景山脊、远处蓝灰山层、近处松林形成了比较清楚的空间深度。
- 云雾包裹山体，有“山在雾中显现”的观看理由，氛围感成立。
- 色彩整体克制，绿色、灰蓝、岩石色没有互相打架，适合这种阴天山景。

## 优先修改项

### 1. 上半部亮雾和天空太多

- 问题：画面上半部接近一半是浅灰天空和亮雾，细节少，最亮区域在右上方，容易把眼睛从山体和松林上拉走。
- 为什么：风光照里的留白要么服务于气势，要么服务于极简；这张的空白区域有气氛，但占比偏多，主体山谷被压到下半部。
- 下次怎么拍：现场可以把镜头稍微下压，减少天空，保留更多山谷、岩石和松林；如果云雾变化快，等雾缝露出山脊线时再按快门。
- 这张怎么修：建议裁掉顶部约 15%-20%，保留右下松林和中间山脊，把画面重心压回山谷。也可以做 4:5 或接近 3:4 的竖幅裁切。

### 2. 山体层次偏灰，主体不够跳出来

- 问题：雾气带来氛围，但中景山体和远山的明暗差偏弱，岩石纹理没有完全立起来。
- 为什么：风光照片需要层次递进。当前前景树很清楚，但中景山脊略闷，远景又被雾吞掉，视觉路径不够有力。
- 下次怎么拍：遇到云雾山景，优先等“雾在山腰、山脊露出”的瞬间；不要只拍雾最满的时候。测光时略压亮部，让雾有细节。
- 这张怎么修：对中景山体做局部加对比和去雾，幅度要轻；前景松林稍微压暗一点，避免它比山谷更抢。

### 3. 前景松林面积较重

- 问题：右下松林颜色最饱和、细节最多，因此它的视觉重量很大，容易从“引导前景”变成“抢主体”。
- 为什么：前景是好东西，但它应该把视线带向山谷，而不是停在自己身上。
- 下次怎么拍：可以左右移动位置，让松林形成边框或斜线，而不是一整块压在右下；也可以找一块更干净的岩石、枝条或单棵松作为前景。
- 这张怎么修：降低松林区域的饱和度和清晰度一点，局部压暗约 0.2-0.4 档，让山体和雾成为主角。

### 4. 画面缺少一个更明确的视觉峰值

- 问题：有山、有雾、有松，但最吸引人的“那个点”还不够明确。
- 为什么：好风光照通常会有一个视觉峰值，比如一道光、一条特别清楚的山脊、一棵形状突出的树、云雾刚好打开的窗口。
- 下次怎么拍：同一机位多等几分钟，专门等云雾露出最清楚的山脊轮廓；也可以用长焦截取雾中山峰，减少杂乱山谷。
- 这张怎么修：用径向或画笔局部提亮中间偏右的山脊，轻微加纹理，让它成为视觉落点。

## 建议设置

看不出 EXIF，以下是估计建议：

- 模式：光圈优先或手动。
- 光圈：f/8-f/11，保证前景松林到远山都有足够景深。
- ISO：有三脚架用 ISO 100；手持可用 ISO 200-800，优先保证快门。
- 快门：手持建议不低于 1/125 秒；如果焦段更长，按 1/焦距 以上提高快门。
- 对焦：对在画面下方到中景之间，约 1/3 景深处；也可手动对焦到超焦距附近。
- 曝光：建议 -0.3 到 -0.7 EV 保护亮雾和天空；拍 RAW。
- 包围曝光：云雾和天空反差变化大时，可拍 -1/0/+1 或 -2/0/+2，后期选择或合成。

## 后期步骤

1. 先裁切：顶部裁掉约 15%-20%，让山谷和松林占据更主要位置。
2. 调白平衡：保持偏冷的阴天氛围，不要强行调成暖色；可略微加一点洋红，避免画面发脏绿。
3. 压高光：降低 highlights，让右上雾区保留层次。
4. 提中景：用局部蒙版给中间山脊增加少量对比、纹理和清晰度。
5. 控前景：右下松林稍微降饱和、降亮度，避免抢主体。
6. 去雾要轻：对山体局部少量 Dehaze 即可，不要把云雾修成脏灰块。
7. 最后锐化：只锐化山脊、岩石和树的边缘，天空和雾区不要锐化。

## 下一次练习任务

下次拍云雾山景，做一个“三张对比练习”：

1. 第一张：保留大量天空和雾，拍气势。
2. 第二张：减少天空，重点拍山谷层次。
3. 第三张：用长焦或裁切思路，只拍一段雾中山脊。

拍完后只比较一个问题：哪一张的主体最明确、视线停留最久。这个练习能快速提高风光构图里的取舍能力。
