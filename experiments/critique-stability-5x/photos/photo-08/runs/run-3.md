# photo-08 run-3 摄影点评

## 一句话总评

这张雾中山景有不错的层次和氛围，但画面上半部留白过多、主体焦点不够集中，所以更像一次有感觉的风光记录，还没有完全形成一张抓人的风光作品。

## 评分前检查

- 主体：云雾中的山体层次与右下角松树前景；真正想表达的应是“雨雾山谷的空间感和清冷气氛”。
- 题材：自然风光 / 山岳云雾。
- 基础问题等级：基础问题。照片可读，也有氛围，但主体层级不够明确，天空和雾气占比偏大，视觉落点偏散。
- 硬伤封顶检查：
  - 主体不可读：不适用，山体、云雾、松树都能辨认。
  - 主体存在但不清楚或偏弱：接近但不触发封顶；主体是“雾中山谷氛围”，能成立，只是焦点不够强。
  - 主体严重虚焦 / 明显虚焦：不适用。远山受雾影响偏软，更像天气造成的低反差，不是明显对焦失败。
  - 严重手抖或运动模糊：不适用，没有看到整体拖影。
  - 严重过曝：不触发。上方天空和雾气偏亮、细节少，但没有明显把关键山体细节完全烧掉。
  - 严重欠曝：不适用。
  - 地平线 / 垂直线明显歪斜：不适用，山景没有明显水平线可判定歪斜。
  - 主导背景干扰：不适用；问题主要是空白天空比例大，不是杂乱背景抢主体。
  - 主体太小且无法通过裁切恢复：不适用。山体和前景都占有足够面积。
  - 普通记录且缺少摄影意图：不触发。云雾、层次、前景松树说明有风光摄影意图。
  - 光线普通且故事弱：不触发封顶。光线不强，但雾气给了明确情绪。
  - 多个重大问题叠加：不适用。
- 高分资格：暂不满足 7.5 分以上。原因是氛围不错，但强项主要集中在“天气氛围”，构图控制和主体凝聚力还不够强，画面上半部的亮灰区域削弱了观看兴趣。
- 故意处理判断：
  - 雾气和低反差：可以视为题材本身的有效氛围，不按虚焦或失误处理。
  - 偏亮天空：更像现场天气和曝光控制的结果，不算明确的创作性高调处理。
  - 竖幅大留白：有一定想表现雾天开阔感的可能，但目前留白缺少细节和形状支撑，效果不够充分。

## 封顶规则

无

## 做得好的地方

- 有前景、中景、远景：右下角松树、山谷岩体、远处蓝灰山脉形成了风光摄影需要的空间层次。
- 雾气有情绪：云雾遮住部分山体，让画面有湿润、安静、清冷的气氛，不是单纯拍一座山。
- 竖幅选择基本合理：竖构图能容纳山谷纵深和高处云雾，适合表现山势的高度。
- 右下角绿色松树提供了稳定锚点：它让画面不至于完全灰掉，也给观众一个从前景进入山谷的入口。

## 优先修改项

### 1. 问题：上半部亮灰天空 / 雾区占比过大

- 为什么：画面上方接近一半是缺少细节的亮灰区域，观众视线停不住；真正有信息量的山体和松树集中在下半部，导致视觉重心下坠。
- 下次怎么拍：拍完现场先问自己“最有内容的区域在哪里”。如果天空没有云形、光线或色彩，就少给天空；可以向下压镜头，让前景松树和山谷多一些，天空少一些。
- 这张怎么修：建议从顶部裁掉约 20%-30%，保留雾压山头的感觉即可。裁成更紧的 4:5 或 3:4 竖幅，让山体和松树成为主画面。

### 2. 问题：主体落点偏散

- 为什么：雾、山、松树都好看，但没有一个最明确的“第一眼焦点”。观众会在右下角松树、中央山脊和上方雾区之间来回跳。
- 下次怎么拍：选择一个主角。如果主角是松树，就靠近或用更长焦压缩，让松树与后方山脉形成明确对比；如果主角是云雾山脊，就减少前景树的面积，把山脊放在更醒目的位置。
- 这张怎么修：用局部明暗引导视线。略压暗上方天空和右下角过重的树冠，轻微提亮中央山脊和云雾边缘，让视线落到山谷深处。

### 3. 问题：整体反差偏低，山体质感不够突出

- 为什么：雾天本来低反差，但如果全图都灰，山石纹理和层次会被抹平，照片容易显得“肉”。
- 下次怎么拍：雾景尽量等雾有分层时拍，例如雾从山腰穿过、山脊露出一部分的瞬间；同时可以欠曝约 -0.3 到 -0.7 EV，保护亮雾细节。
- 这张怎么修：不要全局猛加清晰度。只对山体和中景使用蒙版，少量增加去朦胧、纹理和对比；雾区保持柔和，否则会变脏。

### 4. 问题：前景松树略重，压住了山谷

- 为什么：右下角绿色面积很大，颜色也比远山更饱和，会把注意力拉到画面边角，而不是引向雾中山体。
- 下次怎么拍：移动机位，试着让松树只占画面底部或侧边三分之一以内；也可以找一块岩石、树枝或小路作为更简洁的前景线索。
- 这张怎么修：降低右下角绿叶的饱和度和亮度，特别是黄绿色；同时用轻微暗角把边缘压住，让松树成为入口而不是主角。

## 建议设置

看不出 EXIF，以下是按这类山地雾景估计的建议：

- 拍摄模式：光圈优先或手动模式。
- 光圈：f/8-f/11，保证前景松树、山体和远景都有足够景深。
- ISO：有三脚架时 ISO 100；手持时根据安全快门提高到 ISO 400-800。
- 快门：手持建议不低于 1/125 秒；如果焦段较长，按 1/焦距 的安全快门再提高一点。
- 对焦：对在画面约 1/3 景深处的山体或清晰岩石上；如果用三脚架，可手动对焦并放大确认。
- 曝光：雾天亮部容易没细节，建议 -0.3 到 -0.7 EV 试拍，并查看高光警告。
- 格式：尽量拍 RAW，方便后期拉回天空和雾气层次。
- 附件：有条件可用 CPL 轻微控制反光，但雾天不要过度偏振；高反差时可包围曝光。

## 后期步骤

1. 裁切：从顶部裁掉约 20%-30%，保留山头雾气，减少无信息亮灰天空。
2. 基础曝光：高光 -30 到 -50，白色色阶略降；阴影只小幅提升，避免前景变灰。
3. 局部压天空：对上半部加线性渐变，降低曝光和高光，让雾层更有重量。
4. 局部提山体：对中央山脊和中景岩体加蒙版，少量增加对比、纹理、清晰度、去朦胧。
5. 保留雾感：雾区不要强行锐化；去朦胧只用在山体边缘，避免天空出现脏块。
6. 调整绿色：降低黄绿色饱和度，略压亮度，让右下角松树不抢戏。
7. 视线引导：轻微加暗角，或手动压暗右下角和顶部边缘，提亮中央山谷。
8. 锐化输出：使用蒙版锐化，只锐化山石和树叶边缘，不锐化大面积雾和天空。

## 下一次练习任务

下次再拍山景云雾时，连续拍 3 张不同构图：

1. 少天空版本：天空只占 15%-25%，重点拍山体和雾的层次。
2. 强前景版本：找一棵树、一块岩石或一条路作为明确前景，让它引向远山。
3. 长焦压缩版本：用更长焦段只截取一段山脊和云雾，练习“少拍一点但主体更明确”。

拍完后只比较一个问题：哪一张第一眼最知道在看什么。选出最明确的一张，再进入后期。
