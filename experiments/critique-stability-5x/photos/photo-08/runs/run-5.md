# photo-08 run-5 摄影点评

## 一句话总评

这是一张有雾气氛围和山谷层次的风光照片，已经能让人感到“云雾压山”的环境感，但画面上半部空白太多、主视觉不够集中，导致它更像一次不错的风景记录，还没有形成很强的作品感。

## 评分前检查

- 主体：云雾中的山脊、山谷层次，以及右下角松林作为前景。
- 题材：山岳风光 / 雾景风光。
- 基础问题等级：基础问题。主体可读，曝光和清晰度没有严重失败，但主视觉中心偏散，天空占比过大，前景松林也有些抢注意力。
- 硬伤封顶检查：
  - 主体不可读：否。
  - 主体存在但不清楚或偏弱：接近，但未触发硬封顶；观众仍能明确看出是在拍云雾山景。
  - 主体严重虚焦 / 明显虚焦：否。远山受雾影响偏软，属于天气氛围为主，不像失焦。
  - 严重手抖或运动模糊：否。
  - 明显手抖或运动模糊削弱主体：否。
  - 重要主体严重过曝：否。天空偏亮、细节少，但山体和云雾主体没有被大面积烧掉。
  - 重要主体严重欠曝：否。前景较暗但仍可读。
  - 地平线 / 垂直线意外倾斜：不明显，未触发。
  - dominant 背景干扰：否。右下松林偏重，但仍可作为前景层次，不算纯干扰。
  - 主体太小且无法裁切恢复：否。
  - 普通记录、无明确摄影意图：否。有雾景氛围和层次意图。
  - 光线平淡且故事弱：未触发封顶。光线方向性不强，但云雾本身提供了氛围。
  - 多个重大缺陷叠加：否。
- 高分资格：暂不满足 7.5 或 8。理由是主体虽然清楚，也没有严重硬伤，但只有“氛围”比较强；构图控制、光线塑形、视觉落点还没有同时达到明显强项。
- 故意处理判断：雾气造成的低反差和远山偏软是题材效果，不按失焦处理；大面积浅灰天空有留白意图，但留得偏多，效果没有完全服务主体。

## 封顶规则

封顶规则：无。

## 做得好的地方

- 雾气是这张照片最有价值的部分。它把山体分成了前景、中景、远景，画面有空气感，不是单纯拍一座山。
- 右下角松林提供了近处参照，让山谷有纵深，不会变成一整片灰蒙蒙的远景。
- 曝光总体可用。虽然天空偏亮，但山体、松林、岩石都还能看见，不属于严重过曝或欠曝。
- 色彩克制，绿色松林和灰蓝远山的关系比较自然，适合这种阴天雾景。

## 优先修改项

### 1. 天空占比过大，画面重心被抬空

- 问题：上半部大面积浅灰天空缺少有效云形和光影变化，视觉停留时间不长。
- 为什么：风光照里的留白要么强化孤独感，要么突出尺度；这张天空没有足够形状，反而削弱了山谷和云雾主体。
- 下次怎么拍：拍雾景山谷时，先问自己“最精彩的雾在哪里”。如果精彩在山腰和山谷，就把镜头略向下压，让天空只保留 20%-30%。
- 这张怎么修：裁掉顶部约 15%-25%，保留一点灰天作为环境，但让山脊、云雾和右下松林占更主要的位置。

### 2. 主视觉不够集中

- 问题：观众能知道你在拍山雾，但不太确定应该看左侧雾、中央山脊，还是右下松林。
- 为什么：风光照片也需要“主角”。如果主体区域太散，照片会从“有氛围”退回到“这里风景不错”。
- 下次怎么拍：尝试用长焦或中焦取景，重点框住一条被雾缠绕的山脊；或者降低机位，把右下松林当作明确前景，引导到中间山峰。
- 这张怎么修：做一个偏竖向或 4:5 裁切，减少左上空白，把视觉重心放在右下松林到中部山脊的斜向关系上。

### 3. 前景松林有层次，但重量偏重

- 问题：右下角松林面积大、颜色深，容易抢走云雾山体的注意力。
- 为什么：深色前景会天然吸眼。如果它没有形成清楚的引导线，就会变成画面底部的一块重色。
- 下次怎么拍：前景可以保留，但要让它“指向”中景，比如找一棵形态更清楚的松树、岩石线条或山路作为引导。
- 这张怎么修：局部压低右下松林的饱和度和清晰度一点，同时轻微提亮中部山脊，让视线回到云雾和山体。

### 4. 雾景反差偏低，需要更精细地控制层次

- 问题：雾气很好，但中远景有些灰，山体轮廓的层次还可以更明确。
- 为什么：雾景不是简单“拉高对比”。如果全局对比拉太多，雾会脏；如果完全不处理，又会显得平。
- 下次怎么拍：尽量用 RAW 拍摄，并尝试包围曝光。雾景里亮天空和暗树林同时存在，后期余地很重要。
- 这张怎么修：不要大幅拉全局对比；用局部蒙版给中部山脊增加少量去雾、纹理和对比，天空则压高光、降低存在感。

## 建议设置

看不到 EXIF，以下是按这类雾景山岳风光的估计建议：

- 拍摄模式：光圈优先或手动模式。
- 光圈：f/8-f/11，保证前景松林到中远景山体都有足够景深。
- ISO：有三脚架时 ISO 100；手持时根据快门提高到 ISO 400-800 也可以。
- 快门：手持尽量不低于 1/焦距；如果使用长焦，快门要相应提高。三脚架则按测光结果来。
- 对焦：对在画面约 1/3 深处的山体或前景到中景之间；如果用广角，可以按超焦距思路处理。
- 曝光补偿：雾景和亮天空容易让画面发灰，建议试 -0.3EV 到 -0.7EV 保护天空，再在后期提阴影。
- 文件格式：RAW 优先。
- 包围曝光：如果天空和树林反差大，可以拍 -2/0/+2EV，后期自然合成。

## 后期步骤

1. 先裁切：顶部裁掉约 15%-25%，尝试 4:5 竖构图，让山谷和松林成为主体。
2. 校正基础曝光：高光 -20 到 -40，白色色阶略降，避免天空继续发白。
3. 提中景层次：对中央山脊和雾中岩石加局部蒙版，少量增加对比、纹理、清晰度或去雾；幅度要小，避免雾变脏。
4. 控制前景：右下松林略降饱和度，阴影可轻微提一点，但不要提到发灰。
5. 色彩统一：整体白平衡保持偏冷灰即可，绿色饱和度不要拉太高，否则会破坏雾景的安静感。
6. 最后锐化：只对山体边缘和松针做适度锐化，天空和雾区不要锐化太多。

## 下一次练习任务

下次再拍山雾，专门做一组“同一场景三种取景”的练习：

1. 广角版：保留前景、中景、远景，但天空不超过三分之一。
2. 中焦版：只拍一条被雾缠绕的山脊，练习找主角。
3. 长焦版：压缩远山层次，拍出山峰一层一层消失在雾里的效果。

拍完后只比较一个问题：哪一张最能让观众第一眼知道你想让他看哪里。
