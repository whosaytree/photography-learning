# photo-20 run-5 摄影点评

## 一句话总评

这是一张主体清楚的白鹅记录照，但背景道路太抢眼、光线和瞬间都比较普通，所以目前更像“看见了就拍下来”，还没有形成更强的照片表达。

## 评分前检查

- 主体：画面中间偏下的白鹅，头部和身体是主要观看对象。
- 题材：动物 / 公园或路边生态记录。
- 基础问题等级：基础问题。主体可读，但背景、构图和故事性控制较弱。
- 硬伤封顶检查：
  - 主体不可读：不适用，白鹅可识别。
  - 主体存在但不清楚或偏弱：不适用，主体明确。
  - 主体严重虚焦 / 明显虚焦：不适用，白鹅整体可读，头部略软但不是失败级虚焦。
  - 严重手抖或运动模糊：不适用。
  - 明显手抖或运动模糊削弱主体：不适用。
  - 严重过曝丢失主体细节：不适用；白羽有偏亮区域，但还没有到严重丢细节的程度。
  - 严重欠曝隐藏主体细节：不适用。
  - 地平线 / 垂直线明显无意倾斜：不适用。
  - 主导性背景干扰与主体竞争：适用。横向灰色道路占据画面上半部，视觉重量很大，削弱白鹅。
  - 主体太小且无法通过裁切补救：不适用，主体大小还可以裁切优化。
  - 照片主要是普通记录、缺少明确摄影意图：适用。
  - 光线平普通且故事弱：适用。
  - 多个严重维度硬伤叠加：不适用，没有严重到整体失败。
- 高分资格：不具备。主体清楚，但构图、光线、故事至少两项没有达到明显强项，背景控制也不够。
- 故意处理判断：画面里的偏暗边缘、较强明暗对比和横向道路看不出是有意设计；没有形成明确情绪、视觉路径或稳定的构图效果，按普通拍摄问题处理。
- 低分与逃逸规则：这是正常基础问题，不是严重基础失败；画面有清楚主体和白鹅本身的颜色吸引力，但补偿强度不够，整体不应超过普通记录照区间。

- 技术：5.5/10
- 构图：5/10
- 光线：5/10
- 叙事：4.5/10
- 总体：5/10

## 封顶规则

普通记录、缺少明确摄影意图使总体分封顶到 6；光线普通且故事弱使光线、叙事和总体封顶到 6；背景道路明显与主体竞争，使构图封顶到 6、总体封顶到 6.5。最终没有达到这些封顶上限，主要按记录性和构图控制不足评分。

## 做得好的地方

- 主体明确：观众一眼能知道你想拍的是白鹅。
- 白色主体和绿色植物有颜色对比，画面不是完全杂乱。
- 拍摄距离还算接近，白鹅没有小到看不清。
- 曝光基本可用，没有把白鹅拍成一团完全没有层次的白块。

## 优先修改项

### 1. 背景道路太抢眼

- 问题：灰色道路横贯画面上半部，面积大、亮度接近主体，观众视线会被它拉走。
- 为什么：动物照最怕主体背后有大块无关背景，尤其是横线，会把画面切成两段。
- 下次怎么拍：蹲低一点，让白鹅背后更多是草地、树丛或深色背景；或者向左 / 向右移动几步，避开道路横线。
- 这张怎么修：裁掉上方一大部分道路和黑暗背景，保留白鹅、左侧植物和少量环境即可；可以尝试 4:5 竖构图或更紧的横构图。

### 2. 主体位置和画面重心不够干净

- 问题：白鹅在画面中间偏下，右侧和上方留了不少无效空间，左侧植物又贴近主体尾部。
- 为什么：空间没有服务于白鹅的朝向，也没有形成“它要走向哪里”的视觉路径。
- 下次怎么拍：白鹅朝右时，给右侧留一点前进空间，但不要让右侧空地过大；让主体眼睛附近落在三分线附近。
- 这张怎么修：右边和上边都可以裁掉一些，把白鹅放到画面左下到中部之间，让它面向的右侧保留适量空间。

### 3. 拍摄机位偏高，动物存在感不够

- 问题：现在像站着俯拍，白鹅的形体没有特别突出。
- 为什么：拍动物时，机位越接近动物眼睛高度，主体越有存在感，背景也更容易虚化或简化。
- 下次怎么拍：蹲下，镜头接近白鹅胸口到头部高度，重点对准眼睛或头部。
- 这张怎么修：后期无法真正改变机位，只能通过裁切减少地面和道路，让观看距离显得更近。

### 4. 瞬间比较平

- 问题：白鹅只是站着，动作、表情、方向关系都不强。
- 为什么：动物照片除了“拍清楚”，还需要一个小瞬间，比如回头、张嘴、走路、梳羽、与环境互动。
- 下次怎么拍：不要只拍一张，连续观察 1-2 分钟，等它迈步、转头、低头觅食或和其他动物互动时再按快门。
- 这张怎么修：可以通过裁切和局部提亮增强主体，但无法补回更有趣的瞬间。

## 建议设置

看不出具体设备和 EXIF，以下是估计建议：

- 如果用相机：快门优先 1/500s 起步，动物走动时提高到 1/800s；光圈 f/4-f/5.6；ISO 自动；连续对焦 AF-C；对焦点放在头部或眼睛。
- 如果用手机：点击白鹅头部对焦，手动把曝光稍微拉低一点，避免白羽过亮；开启连拍，挑头部最清楚、姿态最好的一张。
- 白色动物容易过曝，现场可以尝试曝光补偿 -0.3EV 到 -0.7EV，后期再提暗部。

## 后期步骤

1. 先裁切：减少上方道路和底部杂乱地面，尝试 4:5 竖幅，让白鹅占画面更大比例。
2. 降高光：把白鹅羽毛的高光压一点，保住白色层次。
3. 局部提亮主体：对白鹅头部和身体做轻微提亮，但不要把背景一起提亮。
4. 压暗背景：道路和上方暗部可以略微压暗，让视线回到白鹅。
5. 调整颜色：绿色植物稍微降低饱和度，避免抢主体。
6. 适度锐化：只对主体边缘和头部做轻微锐化，不要把地面颗粒和背景噪点也锐化出来。
7. 去除干扰：右下角水印和地面上明显的小白片会分散注意力；如果这是练习图，可以裁掉或修掉。

## 下一次练习任务

拍 20 张同类动物练习照，只练一个目标：让背景变干净。每次拍之前先问自己三句话：白鹅背后是什么？有没有横线穿过主体？我能不能蹲低或移动两步让背景更简单？最后只选 3 张主体清楚、背景最干净、动作最有意思的照片。
