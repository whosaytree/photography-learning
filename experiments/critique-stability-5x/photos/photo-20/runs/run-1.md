# photo-20 run-1 摄影点评

## 一句话总评

这是一张主体清楚的白鹅记录照，但背景道路、杂乱地面和普通光线削弱了画面的摄影感，目前更像“看到一只鹅就拍下来”，还没有把鹅的姿态、环境关系或光线特点组织成一个明确画面。

## 评分前检查

1. **主体与题材**：主体是画面中偏左中部的白鹅；题材更接近动物/生活记录，也可算自然观察类小品。
2. **基础问题等级**：基础问题。主体能看清，焦点大致可用，但背景控制、光线选择和画面目的感偏弱。
3. **硬伤封顶逐项检查**：
   - 主体不可读：否，白鹅清楚可辨。
   - 主体存在但不清楚或很弱：否，主体明确。
   - 主体严重虚焦：否。
   - 主体明显虚焦但仍可读：否。
   - 严重手抖或运动模糊：否。
   - 明显手抖或运动模糊削弱主体：否。
   - 严重过曝损失主体重要细节：否；白羽有偏亮区域，但没有到严重破坏识别的程度。
   - 严重欠曝隐藏主体重要细节：否。
   - 地平线/垂直线非故意倾斜：不明显，不作为封顶。
   - 主导背景干扰与主体竞争：是。上方大面积灰色道路和暗部背景抢走注意力。
   - 主体太小且无法通过裁切挽回：否，主体大小可以通过裁切改善。
   - 普通记录照、摄影意图不清：是。画面缺少决定性动作、关系或光线设计。
   - 光线普通且故事弱：是。光线能用，但没有明显塑形或情绪。
   - 多个不同维度重大问题叠加：否，问题主要是构图与意图，不是技术崩坏。
4. **故意处理判断**：
   - 暗部/压暗：画面上方和边缘较暗，但没有形成稳定的低调氛围，也没有很好地服务主体，按偶然或后期不够克制处理。
   - 高反差：白鹅与暗背景有一定反差，但道路和地面杂乱削弱了效果，不能算明确有效的高反差表达。
   - 模糊：没有明显有意动感模糊。
   - 不寻常构图：主体偏左、右侧留白有一点“看向右边”的空间，但整体环境没有被控制到足以证明是强意图构图。
5. **低分规则应用**：没有严重基础失败，所以不进入 3-4.5；但存在普通基础问题和记录照倾向，总体不应高于 6。
6. **逃逸规则**：主体清楚、白鹅本身有一点视觉兴趣，且白色主体在环境中有分离度，因此可以略高于纯记录照 5 分；但没有强光线、强瞬间或强构图，不能超过 6。
7. **高分资格检查**：不具备 7.5 或 8 的条件。主体清楚且没有严重技术硬伤，但构图、光线、故事没有两个维度明显强，背景和边缘也不够干净。
8. **独立评分**：以下分数只根据这一张图判断，不参考其他 run 或旧评价。

## 五项评分

- **技术：6**  
  焦点和清晰度基本可用，白鹅的头部、脖子和身体都能看清。主要问题是白羽局部偏亮、暗部压得较重，整体质感不够干净。

- **构图：5**  
  主体明确，也给了白鹅朝向右侧的一些空间；但上方道路横切画面，前景地面杂乱，左侧植物和右下角水印都在分散注意力。构图更像站在原地拍到，而不是主动选择角度。

- **光线：5**  
  光线可用，白鹅从环境里能跳出来；但光线偏普通，白羽高光略硬，背景暗部沉闷，没有形成漂亮的轮廓光、侧光或环境氛围。

- **叙事：4.8**  
  画面告诉观众“这里有一只白鹅”，但鹅的动作比较静态，也没有和环境、人物、同伴或道路形成更有意思的关系。

- **总体：5.2**  
  这张照片是可看的动物记录照，主体清楚是优点；但摄影意图、背景控制和瞬间选择都还偏弱，所以整体略高于 5，但不到分享级别。

## 封顶规则

生效：**主导背景干扰与主体竞争**、**普通记录照且摄影意图不清**、**光线普通且故事弱**。因此构图、叙事和总体不应给到高分；本次总体控制在 6 以下。

## 做得好的地方

- 主体选择明确，观众第一眼能知道你在拍白鹅。
- 白鹅朝右，右侧留出一定空间，没有把鹅头直接顶到画面边缘。
- 白色主体和较暗背景形成了基本分离，至少没有被环境完全淹没。
- 拍摄距离不算太远，后期仍有裁切成更集中画面的空间。

## 优先修改项

### 1. 背景道路太抢眼

- **问题**：画面上半部是一整条灰色道路，亮度和面积都很大，和白鹅争夺注意力。
- **为什么**：动物照片里，背景越简单，主体越有力量；现在道路像一条横向色块，把画面切成上下两段。
- **下次怎么拍**：蹲低一点，让鹅后面更多是草丛或暗背景；或者绕到道路不入镜的方向拍。先看背景，再按快门。
- **这张怎么修**：裁掉上方大部分道路，把画面压成竖构图或更紧的横构图，保留白鹅、左侧一点植物和右侧少量空间。

### 2. 主体动作不够有瞬间感

- **问题**：鹅只是站着，姿态可辨但不够有记忆点。
- **为什么**：动物题材很依赖动作、眼神、互动和姿态。静止站立如果没有特别好的光线或构图，容易变成普通记录。
- **下次怎么拍**：等它抬头、迈步、回头、张嘴、梳理羽毛，或者和植物/道路产生关系时再拍。可以连拍 5-10 张，从里面挑姿态最好的一张。
- **这张怎么修**：无法补出动作，只能通过裁切和局部提亮眼睛，让注意力更集中在头颈姿态上。

### 3. 白羽高光和暗部控制不够细

- **问题**：白鹅身体有些区域偏亮，背景暗部又比较沉，画面反差有点生硬。
- **为什么**：白色动物容易过曝，一旦羽毛没有层次，质感会变弱；暗部太沉则会让环境显脏。
- **下次怎么拍**：遇到白色主体，曝光补偿可先试 **-0.3EV 到 -0.7EV**，优先保住白羽细节。尽量选择柔和光线，比如阴天、树荫边缘或早晚低角度光。
- **这张怎么修**：降低高光，轻微压白色色阶；阴影只提一点，不要把暗背景全部拉亮。给鹅头和眼睛做小范围提亮即可。

### 4. 机位偏普通

- **问题**：视角像站立高度随手拍，动物的存在感不够强。
- **为什么**：拍小动物时，机位越接近动物眼睛高度，画面越有亲近感；俯拍会让主体显得普通。
- **下次怎么拍**：蹲下或半蹲，镜头尽量接近鹅的眼睛高度；使用中长焦或手机 2x/3x，让背景更简化。
- **这张怎么修**：通过裁切减少地面空白，把鹅放在画面左侧三分线附近，保留它面向右边的空间。

## 建议设置

看不出真实 EXIF，以下是估计建议：

- **快门**：鹅在慢走或转头时，建议至少 1/250s；如果动作快，用 1/500s。
- **光圈**：相机拍摄可用 f/4-f/5.6，兼顾主体清晰和背景虚化；手机则用 2x/3x 镜头靠近构图，不要过度数码变焦。
- **ISO**：在白天尽量 ISO 100-400；如果在树荫里，为保证快门速度可以升到 ISO 800。
- **曝光补偿**：白鹅这种高亮主体，先试 -0.3EV 到 -0.7EV，避免羽毛过曝。
- **对焦**：单点或触屏对焦在鹅头/眼睛附近，不要只对到身体大白块。

## 后期步骤

1. **裁切**：优先尝试竖构图或更紧横构图，裁掉上方大部分道路和右下角水印区域；保留鹅朝向右侧的空间。
2. **校正亮度**：整体曝光可保持或略降，高光 -20 到 -40，白色色阶略降，保住白羽层次。
3. **局部调整主体**：给鹅头、眼睛、脖子轻微提亮，增加一点纹理/清晰度；不要把身体锐化过头。
4. **压背景**：对道路和杂乱地面做轻微降低亮度、降低饱和度，让它们退后。
5. **颜色**：绿色植物可以稍微降饱和，避免抢白鹅；整体白平衡保持自然，不要调得太黄或太蓝。
6. **收尾锐化**：小幅锐化主体边缘即可，避免让地面颗粒和杂草变得更乱。

## 下一次练习任务

拍 20 张同一只或同类动物，但每张按下面要求执行：

1. 先找干净背景，背景不干净就不拍。
2. 蹲到接近动物眼睛高度。
3. 等一个动作：迈步、回头、张嘴、互动、梳毛，至少满足一个。
4. 每次拍完立刻检查白色区域有没有过曝。
5. 最后只选 1 张，说明你为什么选它：是姿态好、背景干净、光线好，还是故事更明确。
