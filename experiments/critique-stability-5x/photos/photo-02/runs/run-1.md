# 摄影点评 photo-02 run-1

## 一句话总评

这张照片能清楚记录一栋城市住宅楼的形体和黄昏氛围，但目前更像“看见了就拍下来”的记录照，主体、光线和画面关系还没有被组织成一个明确的摄影表达。

## 评分前检查

- 主体：左侧偏中的高层住宅楼，附带下方裙楼和右侧天空。
- 题材：城市建筑 / 街景建筑记录。
- 基础问题等级：基础问题。主体可读，但画面意图偏弱，建筑线条、裁切和负空间没有形成足够强的视觉组织。
- 硬伤封顶检查：
  - 主体不可读：不适用，建筑主体能辨认。
  - 主体存在但不清楚或偏弱：部分适用。主体是清楚的楼，但拍摄意图偏弱，视觉重点不够集中。
  - 严重虚焦 / 明显虚焦：不适用，建筑细节基本可读。
  - 严重手抖 / 明显运动模糊：不适用，没有明显破坏观看的抖动。
  - 严重过曝：不适用，天空没有明显重要细节过曝。
  - 严重欠曝：不适用，但建筑暗部偏闷，属于轻到中等曝光问题。
  - 水平线 / 垂直线无意倾斜且可见：适用。建筑摄影里垂直线和透视需要更严格，这张楼体有明显向内收的透视感，底部建筑也有轻微不稳定感。
  - 主体太小且无法靠裁切挽回：不适用，主体占比足够。
  - 主要背景干扰：轻微适用。右下角斜向结构、底部建筑切入会分散注意力，但没有完全压过主体。
  - 普通记录、缺少明确摄影意图：适用。画面能记录场景，但没有清晰的视觉观点、瞬间或形式亮点。
  - 光线普通且故事弱：适用。蓝调天空有一点气氛，但光线没有明显塑造建筑，叙事也较弱。
  - 多个重大硬伤叠加：不适用，没有严重技术失败。
- 高分资格：不具备。主体虽然清楚，也没有严重技术硬伤，但构图、光线、叙事没有至少两项明显强；因此不考虑 7.5 或 8。
- 故意处理判断：
  - 暗：不像明确的低调表达。建筑偏暗没有强化主题，只是让墙面和窗户细节变闷。
  - 大面积天空 / 负空间：可能有想做极简城市感，但右侧空白没有和建筑形成足够有力的比例或方向关系，因此按未完全成功的构图处理。
  - 透视收缩：不像有意夸张建筑压迫感，因为画面边缘和底部结构没有同步服务这个效果。
  - 高对比：不明显。

## 五项评分

- 技术：5.5/10  
  曝光可用，焦点和清晰度基本过关；问题是建筑略暗、灰度偏闷，天空和楼体的质感都不够干净有力。
- 构图：5/10  
  主体明确，但左重右空，底部和右下角结构比较杂，建筑垂直线也没有被控制好。右侧天空像剩余空间，而不是强负空间。
- 光线：5/10  
  蓝调时段带来一点冷静气氛，但光线太平，建筑表面没有被侧光、窗光或明暗层次塑造出来。
- 叙事：4.5/10  
  能看出普通城市居住建筑的冷清感，但缺少人、灯光关系、天气、形态对比或明确情绪点，观看理由偏弱。
- 总体：5/10  
  这是一张可读的城市建筑记录照，但还没有从“记录”进入“表达”。主要提升空间在拍摄位置、线条控制、等待光线和裁切取舍。

## 封顶规则

由于照片整体偏普通记录、光线普通且故事弱，总体分封顶在 6.0；同时建筑垂直线控制不足，构图分不宜超过 6.0。最终没有触及严重技术硬伤封顶。

## 做得好的地方

- 主体没有丢失，楼体占据画面左侧，观众能马上知道你在拍建筑。
- 黄昏或蓝调时段的天空颜色比较统一，至少给画面提供了一点冷静、城市化的气氛。
- 没有严重过曝、虚焦或手抖，基础可观看性是成立的。
- 建筑外立面上窗户、空调、墙面纹理有一定重复图案，如果后续更主动取景，可以发展成“城市密度 / 居住痕迹”的主题。

## 优先修改项

### 1. 建筑线条不够稳

- 问题：楼体垂直线有明显透视收缩，底部和右侧结构也让画面显得有点斜、不稳定。
- 为什么：建筑摄影最怕“本来该直的线不直”。如果不是有意夸张压迫感，歪斜会让照片看起来像随手抬头拍。
- 下次怎么拍：后退一点、把相机尽量端平，少仰拍；打开网格线，让楼体中间的竖线尽量垂直。若必须仰拍，就更大胆地靠近并把透视夸张成明确风格。
- 这张怎么修：在后期里做“垂直透视校正 / Upright / Transform”，让楼体主要竖线更直；校正后再重新裁切，避免边缘留下空白。

### 2. 右侧天空太空，但没有形成强负空间

- 问题：画面右侧大面积天空占比很高，但天空本身没有云、鸟、月亮、光带或颜色层次，视觉信息偏少。
- 为什么：负空间不是“空就行”，它要帮助主体显得孤立、压迫、安静或渺小。现在的空白没有足够强化楼的情绪。
- 下次怎么拍：如果想拍极简感，可以让楼更靠边、更小，天空占比更极端；如果想拍建筑本身，就横向少留天空，改用竖幅或更紧的裁切。
- 这张怎么修：裁掉右侧约 25%-35% 的天空，保留楼体和少量环境；也可以试一版 4:5 竖构图，让楼成为绝对主体。

### 3. 底部和右下角杂物抢注意力

- 问题：下方裙楼、右下角斜向框架和暗部建筑切入较多，和主楼之间关系不够清楚。
- 为什么：这些元素不是强前景，也不是清楚的引导线，反而让画面重心变散。
- 下次怎么拍：拍之前先问自己：“这块底部建筑是我要的层次，还是干扰？”如果不是主题，就换角度避开，或把镜头再抬高一点，只保留主楼和天空。
- 这张怎么修：裁掉一部分底部暗建筑，尤其是左下角和右下角过杂的区域；保留一点裙楼作为城市层次即可。

### 4. 光线没有塑造建筑

- 问题：楼面整体偏灰、偏暗，窗户亮点少，墙体没有明显方向光。
- 为什么：建筑本身颜色和形态比较普通，如果光线也平，照片容易停留在记录层面。
- 下次怎么拍：等两种时机：第一，日落前侧光照到楼面，让墙面有明暗；第二，蓝调后 10-20 分钟，等更多窗户亮起，用冷天空和暖窗光形成对比。
- 这张怎么修：略微提亮建筑中间调和阴影，但不要把天空提得太亮；可以局部加一点对比和清晰度，让窗户、空调和墙面纹理更有层次。

## 建议设置

看不出准确 EXIF，以下是估计建议：

- 拍城市建筑静态场景：光圈 f/5.6-f/8，保证楼体整体清楚。
- 快门：手持建议至少 1/125s；如果焦段较长，按“1/焦距”再提高一点。
- ISO：白天或蓝调初期尽量 ISO 100-800；如果天更暗，可以提高到 ISO 1600，但要接受一点噪点。
- 对焦：单点 AF 或触屏对焦在楼体边缘 / 窗户纹理处，避免对到纯天空。
- 测光：矩阵测光即可；如果天空过亮导致楼太黑，可以加 +0.3 到 +0.7 EV，或拍 RAW 后提阴影。
- 构图辅助：打开网格线；拍建筑时优先检查垂直线，再按快门。

## 后期步骤

1. 先做镜头校正和色差校正。
2. 使用透视校正，把主楼主要竖线拉直；不要过度校正到楼体变形。
3. 重新裁切：优先尝试 4:5 竖幅或更紧的横幅，减少右侧空天空和底部杂乱区域。
4. 白平衡保持偏冷即可，但可以稍微降低蓝色饱和度，避免天空显得脏。
5. 提亮建筑阴影和中间调，大约小幅增加曝光或阴影；同时压一点高光，保持天空层次。
6. 给建筑局部加少量对比、纹理或清晰度，让窗户和墙面重复图案更明确。
7. 最后做轻微锐化和降噪；不要加太重滤镜，否则普通楼面会显得脏。

## 下一次练习任务

同一栋楼或类似建筑，连续拍三组，每组至少 10 张：

1. 线条练习：只拍“垂直线稳定”的版本。打开网格，相机端平，后退找角度。
2. 负空间练习：拍一张极简版，让天空占 70% 以上，但必须让楼的位置有明确情绪；再拍一张紧裁切版，让楼占 70% 以上，对比哪张更有力量。
3. 光线练习：日落前、蓝调刚开始、窗灯亮起后三个时间各拍一张，比较哪一张最能让建筑从记录变成有氛围的照片。
