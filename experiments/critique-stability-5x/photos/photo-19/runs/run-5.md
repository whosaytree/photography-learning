# photo-19 run-5 摄影点评

## 一句话总评

这是一张能看清菜品的餐桌记录照，颜色有食欲，但主体被水杯、酱碟、餐具和杂乱桌面分散，整体更像随手记录，还没有形成明确的食物摄影表达。

## 评分前检查

- 主体：下方白盘里的红色食材和绿色叶菜。
- 题材：餐桌食物 / 生活静物。
- 基础问题等级：基础问题。主体可读，但画面简化不够，桌面杂物抢视线，盘子边缘被裁切，画面目的偏记录。
- 硬伤封顶检查：
  - 主体不可读：不适用，菜品可以辨认。
  - 主体严重虚焦：不适用，没有严重虚焦。
  - 主体明显虚焦但可读：基本不适用；局部叶菜有轻微软和近距离景深不足，但不是主要硬伤。
  - 严重手抖 / 运动模糊：不适用。
  - 明显手抖 / 运动模糊削弱主体：不适用。
  - 严重过曝：不适用；水杯和盘边有亮部反光，但没有严重破坏菜品细节。
  - 严重欠曝：不适用。
  - 地平线 / 垂直线明显歪斜：不适用，这类餐桌近景不以水平线为主要判断。
  - 主导背景干扰与主体竞争：适用。左上大水杯、上方酱碟、右上杯碗和筷子都在抢注意力，构图和总体受限。
  - 主体太小且无法裁切恢复：不适用，主体占画面较大。
  - 普通记录照、摄影意图不清：适用。画面更像坐下吃饭前随手拍，故事和总体受限。
  - 光线普通且故事弱：适用。室内顶光可用但不塑形，叙事也弱。
  - 多个维度重大硬伤同时出现：不适用，没有严重技术失败。
- 故意处理判断：
  - 模糊：不像故意浅景深表达，只是近距离拍摄导致局部不够稳。
  - 暗部：没有明显低调处理。
  - 异常构图：盘子被切、杂物进入画面，缺少边缘控制证据，判断为非故意。
  - 高反差 / 高饱和：食材颜色鲜明有帮助，但桌面反光和亮部不是有控制的风格化处理。
- 高分资格：不具备。主体虽然清楚，但构图、光线、故事都没有达到两个明显强项，背景和边缘干扰也较重。
- 低端规则与逃逸判断：属于普通基础问题，不是严重失败；颜色和食材质感有一点补偿，所以不是 4 分段，但仍受普通记录照和背景干扰限制。

## 五项评分

- 技术：5.5/10
- 构图：4.5/10
- 光线：5/10
- 叙事：4.5/10
- 总体：5/10

## 封顶规则

主导背景干扰与主体竞争，构图最高 6、总体最高 6.5；普通记录照、摄影意图不清，故事最高 5.5、总体最高 6；光线普通且故事弱，光线最高 6、故事最高 6、总体最高 6。本图最终总体按基础问题落在 5。

## 做得好的地方

- 红色食材和绿色叶菜有天然色彩对比，第一眼能感到“有味道”。
- 拍摄距离比较近，食物占画面比例足够大，不是远远拍一整桌。
- 白色盘子提供了干净的承托，如果周围干扰减少，会更容易突出菜。
- 室内曝光基本可用，主体没有黑掉，也没有大面积糊成一片。

## 优先修改项

### 1. 主体周围太乱

- 问题：左上水杯体积很大，上方酱碟和右上餐具都在抢视线。
- 为什么：食物摄影首先要让观众知道“看哪一口”。现在眼睛会在水杯、酱碟、盘子、筷子之间来回跳。
- 下次怎么拍：拍之前先清桌面，只保留盘子和一个有用的配角，比如小酱碟；水杯、纸巾、无关餐具移出画面。
- 这张怎么修：裁掉左上大水杯和右上杯碗，保留盘子主体和少量酱碟；如果裁切后盘子太满，可以做 4:5 竖幅或 1:1 方图。

### 2. 盘子被切得不舒服

- 问题：盘子下方和右侧被切断，边缘控制比较随意。
- 为什么：切到主体承载物会让画面像没来得及构图，食物也显得拥挤。
- 下次怎么拍：要么完整拍下盘子，留一圈桌面呼吸空间；要么更大胆贴近，只拍菜的纹理和局部，不让观众意识到盘子被随便切掉。
- 这张怎么修：尝试更紧的局部裁切，让画面变成“叶菜和红色食材的质感特写”，弱化盘子边缘被切的问题。

### 3. 光线是可用的，但没有塑造食物

- 问题：室内顶光让盘子、水杯和桌面产生反光，食物表面有亮点，但层次不够干净。
- 为什么：食物好不好看，很依赖侧光带来的纹理和体积。顶光容易把油光、盘子反光和桌面花纹一起照亮。
- 下次怎么拍：尽量靠窗，用侧前方自然光；把盘子转到窗边 45 度角，另一侧用白纸或纸巾轻轻补光。
- 这张怎么修：降低高光，压一点水杯和盘边的亮部；轻微提亮菜品中暗的红色食材，让主体层次更平均。

### 4. 色彩有食欲，但白平衡偏餐厅暖杂

- 问题：桌面偏黄绿，室内灯让整体颜色有些脏，绿色叶菜略显油亮厚重。
- 为什么：食物照需要颜色干净。色温不准会让白盘不够白，菜的红绿对比也变得浑。
- 下次怎么拍：拍前点按白盘或菜品对焦测光，必要时把曝光稍微压低；如果可以手动白平衡，按餐厅灯光或白盘校正。
- 这张怎么修：用白盘边缘做白平衡参考，减少黄色；绿色饱和度略降，红色和橙色亮度略提，避免“油腻感”过强。

## 建议设置

看不出具体设备和 EXIF，以下是估计建议：

- 手机拍摄：用 1x 或 2x，不用超广角；点按最想看的食材对焦；曝光补偿约 -0.3 到 -0.7，避免盘子和桌面反光过亮；镜头保持与桌面平行或稳定的 45 度俯拍。
- 相机拍摄：等效 35-50mm；光线足时 f/4-f/5.6，想让整盘更清楚可用 f/5.6-f/8；快门不低于 1/125s；ISO 自动上限可设 1600 或 3200；单点对焦放在最前方、最有质感的一块食材上。
- 构图设置：打开网格线，先决定是完整盘子、45 度餐桌感，还是局部质感特写，不要介于两者之间。

## 后期步骤

1. 先裁切：建议裁掉左上大水杯和右上杯碗，保留盘子主体；可以尝试 4:5 竖幅或 1:1 方图。
2. 校正白平衡：以白盘为参考，把偏黄偏绿的色温拉回自然。
3. 降高光：压低水杯、盘边、油亮叶菜上的刺眼反光。
4. 提主体：对菜品局部加一点曝光和清晰度，不要全图锐化桌面纹理。
5. 调颜色：红色食材略加亮度，绿色叶菜略降饱和，保持食欲但不要过重。
6. 局部弱化干扰：给背景水杯和桌面轻微降低亮度或加暗角，让视线回到盘子。

## 下一次练习任务

下次吃饭前拍同一道菜三张：

1. 完整盘子照：移走所有无关物，只保留盘子，四周留均匀空间。
2. 45 度食欲照：靠窗侧光，酱碟只放在画面角落当配角。
3. 局部特写：靠近拍红色食材、绿色叶菜和油光纹理，让画面只讲“这一口好吃”。

拍完后只选一张最清楚、最少杂物、最有食欲的。这个练习的目标不是拍更多东西，而是学会在按快门前先减掉干扰。
