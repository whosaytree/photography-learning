# photo-18 run-3 摄影点评

## 一句话总评

这张照片有漂亮的日落色彩和窗框分割感，但主体关系还不够明确，画面被粗重窗框和技术柔化削弱了，所以更像一次有氛围的观察，而不是已经完成的城市风景作品。

## 评分前检查

- 主体：主要视觉主体是左上方的落日、室内窗框形成的黑色几何结构，以及远处城市建筑剪影；其中落日最抢眼，但“到底拍太阳、窗框，还是城市天际线”的主次还不够明确。
- 题材：城市风景 / 窗内视角的日落氛围照，带一点建筑抽象构图。
- 基础问题等级：基础问题。照片可读，有明确情绪，但主体层级、边缘控制和清晰度还没有完全站稳。
- 硬伤封顶检查：
  - 主体不可读：不适用，太阳、窗框和城市轮廓都能看懂。
  - 主体存在但不清或偏弱：接近，但未作为硬封顶处理；主体关系偏弱，作为基础问题扣分。
  - 主体严重虚焦：不适用。
  - 主体明显虚焦但仍可读：不作为硬封顶；远处城市偏软，但可能来自雾气、隔窗拍摄、数码变焦或压缩，不足以判定为单纯失焦。
  - 严重手抖或运动模糊：不适用。
  - 明显手抖或运动模糊：不明显，画面整体没有方向性拖影。
  - 严重过曝剪掉重要主体细节：太阳高光明显溢出，但在日落剪影题材里太阳呈白色光盘可以成立；未作为严重过曝硬封顶。
  - 严重欠曝隐藏重要主体细节：不适用，窗框黑成剪影是可接受的视觉处理。
  - 地平线 / 垂直线无意倾斜：不明显。
  - 强背景干扰竞争主体：部分适用但不封顶；粗窗框确实很抢眼，不过它也是构图元素。
  - 主体太小且无法通过裁切恢复：不适用。
  - 普通记录、无明确摄影意图：不适用；有利用窗框和日落氛围的意图。
  - 光线平淡且故事弱：不适用，光线是这张的主要优点。
  - 多个大硬伤同时出现：不适用。
- 高分资格：暂不具备。理由是光线明显有吸引力，但技术清晰度、主体层级、窗框占比和画面裁切都还不够稳，不能评到 7.5 或 8。
- 故意处理判断：
  - 高反差 / 黑窗框：基本可以视为有意利用剪影和窗框分割，画面里有稳定的窗框锚点，也符合日落剪影题材。
  - 太阳过亮：可以接受为日落氛围的一部分，但亮度仍然有些顶，缺少边缘层次。
  - 城市偏虚、偏灰：不完全像有意效果，更像隔窗、空气雾霾、数码变焦或后期压缩造成的画质下降。
  - 异常构图：窗框分割是有意图的，但右侧大空窗和中间粗黑竖框让视觉重心有些散。

## 做得好的地方

- 日落颜色好，橙红到粉灰的过渡给画面带来了情绪，不是普通白天记录照。
- 窗框形成了“框中框”和几何分割，让画面有设计感。
- 黑色窗框和柔和城市远景形成强烈明暗对比，能表达一种隔着窗看城市的安静感。
- 画面没有明显手抖拖影，至少基本观看是成立的。

## 优先修改项

### 1. 主体关系要更明确

- 问题：现在太阳、窗框、远处高楼、右下建筑都在争夺注意力，但没有一个被明确安排成绝对主角。
- 为什么：观众第一眼会被太阳吸住，第二眼又被中间粗黑窗框挡住，第三眼才看到城市，视觉路径不够顺。
- 下次怎么拍：拍之前先选一个主角。如果主角是太阳，就让太阳和一栋建筑形成关系，比如贴近楼顶、落在窗格交点附近，或者和远处塔楼对齐。如果主角是窗框几何，就把窗框拍得更正、更对称，让城市只做背景。
- 这张怎么修：建议裁掉右侧一部分空窗，保留左上太阳、中间窗框和下方建筑，让画面更集中。可以尝试裁成 4:5 或 3:4 竖构图，减少右侧淡粉色空白。

### 2. 窗框太重，压住了城市层次

- 问题：中间竖向黑条和横向黑条面积很大，几乎变成画面第一主体。
- 为什么：黑色大块在浅色天空前对比极强，会比远处城市更抢眼；如果它不是主角，就会显得遮挡。
- 下次怎么拍：移动机位，让窗框边缘变成更有秩序的边框，而不是横穿画面中心。可以把太阳放在一个窗格里，把城市建筑放在另一个窗格里，避免粗黑条直接卡在视觉中心。
- 这张怎么修：降低黑场的压迫感不太现实，因为窗框已经接近纯黑；更有效的是裁切。优先裁掉最左侧红黑边和右侧空窗，让窗框成为有意的分割，而不是杂乱遮挡。

### 3. 高光和清晰度需要更稳

- 问题：太阳完全白掉，周围有一圈发光边；远处建筑比较软，细节少。
- 为什么：太阳高光溢出会让画面显得像手机自动曝光没控制住；城市细节太软，会降低“城市风景”的完成度。
- 下次怎么拍：对着太阳附近天空测光后，把曝光补偿降到 -1 到 -2EV；如果用手机，点按太阳附近天空后向下拉曝光。拍 3 张不同亮度，选太阳边缘和城市轮廓都最舒服的一张。
- 这张怎么修：后期先压高光和白色色阶，略降整体曝光；不要强行大幅拉清晰度，否则天空和建筑边缘会变脏。可以对城市区域轻微加去朦胧和对比，但幅度要小。

### 4. 画面右侧信息量偏弱

- 问题：右上和右中大面积粉色天空比较空，右下建筑又太淡，支撑不住这么大的面积。
- 为什么：留白如果没有明确服务主体，就会变成空；这里的留白没有把太阳衬得更孤独，反而分散了画面。
- 下次怎么拍：要么让右侧出现一个明确的城市轮廓作为平衡，要么直接减少右侧面积，让太阳和左下建筑成为主要关系。
- 这张怎么修：从右边裁掉约 20%-30%，同时略微裁掉最左侧红色边缘；如果裁成竖幅，画面会更像“窗格里的落日城市”。

## 建议设置

看不出真实设备和参数，以下是估计建议：

- 如果用手机：点按太阳旁边的天空锁定曝光，曝光下拉约 -1 到 -2EV；使用 1x 或真实光学长焦，尽量不要用高倍数码变焦；把手机贴近窗户或靠在窗框上稳定。
- 如果用相机手持：光圈可用 f/5.6-f/8，ISO 尽量 100-400，快门至少 1/125s；如果用较长焦距，快门提高到 1/250s 以上更稳。
- 如果有三脚架：ISO 100，f/8 左右，包围曝光 -2/0/+2，后期选择一张或做轻度 HDR，但不要把剪影窗框强行拉亮。
- 对焦：如果想要城市清楚，对焦远处建筑；如果想要窗框成为几何主体，对焦窗框边缘，并接受城市作为柔和背景。

## 后期步骤

1. 裁切：先裁掉左侧红黑边缘和右侧部分空白，尝试 4:5 竖幅或更紧的横幅，让太阳、窗格和下方建筑形成更明确关系。
2. 校正：检查窗框竖线，轻微透视校正，让主要竖线更直；不要过度拉伸。
3. 全局曝光：整体曝光略降，高光降低，白色色阶降低，尽量保住太阳边缘的过渡。
4. 色彩：保留橙红日落，但降低一点红色/橙色饱和度，避免左侧区域显得脏红。
5. 局部调整：对远处城市轻微增加去朦胧、对比和清晰度；只加一点，避免噪点和边缘伪影。
6. 黑场控制：窗框保持剪影，不建议大幅提阴影；只要保证边缘干净即可。
7. 锐化：轻微锐化窗框边缘和建筑轮廓，避免对天空大面积锐化。

## 下一次练习任务

主题：同一个窗户，拍 20 张“日落窗格构图”。

要求：

- 每张只选一个主角：太阳、城市建筑、窗框几何三选一。
- 每个主角至少拍 5 张不同构图：居中、三分线、框中框、只留一个窗格、包含两层建筑。
- 每个构图拍 3 个曝光版本：正常、-1EV、-2EV。
- 回看时只选 3 张：一张光线最好，一张构图最干净，一张主体最明确。
- 复盘重点不是“颜色漂不漂亮”，而是问自己：观众第一眼会不会立刻知道我想让他看什么。
