# photo-18 run-2 摄影点评

## 一句话总评

这张照片有“窗框里的落日城市”这个清楚想法，暖色夕阳和黑色几何线条有吸引力，但太阳高光过曝、远景偏软、右侧画面信息偏空，让它更像一个有审美意识的练习片，还没有完全成为一张完成度高的城市风景照。

## 评分前检查

- 主体：窗外的夕阳，以及被窗框切分出来的城市剪影；画面真正吸引视线的是左上方的太阳。
- 题材：室内隔窗城市风景 / 日落氛围 / 几何构图。
- 基础问题等级：基础问题。主体能看懂，光线有氛围，但高光控制、清晰度、画面右侧取舍和窗框压迫感还没有完全控制住。
- 硬伤封顶检查：
  - 主体不可读：不适用，太阳和窗框关系清楚。
  - 主体存在但不清楚或偏弱：不适用，主视觉明确。
  - 主体严重虚焦或明显虚焦：不适用；远处建筑偏软，但窗框和太阳轮廓仍可读，且隔窗雾感有一定合理性。
  - 严重手抖或运动模糊：不适用。
  - 明显手抖或运动模糊削弱主体：不明显。
  - 严重过曝剪切重要主体细节：不作为封顶处理。太阳本身接近白盘是日落直拍常见结果，但边缘有明显溢光，属于技术扣分点。
  - 严重欠曝隐藏重要主体细节：不适用，窗框黑成剪影基本符合画面意图。
  - 地平线 / 垂直线无意倾斜：不触发封顶；窗框整体基本正，但仍建议后期微调垂直。
  - 背景干扰强烈竞争主体：不触发封顶；窗框很重，但它也是构图元素。
  - 主体太小且无法裁切恢复：不适用。
  - 普通记录、无明确摄影意图：不适用；有明确的框景、色彩和几何意图。
  - 光线平淡且故事弱：不适用，光线是主要优点。
  - 多个重大问题叠加：不适用。
- 高分资格：不满足 7.5 或 8。主体清楚，也有光线和几何两个方向的意图；但太阳高光溢出明显、右半边信息不足、远景细节弱，故事性也偏薄。
- 故意处理判断：
  - 高反差：基本是故意的。黑窗框剪影和橙色天空形成对比，符合日落框景的表达。
  - 黑暗窗框：基本是故意的。窗框作为稳定锚点和几何分割线成立。
  - 远景朦胧 / 偏软：部分有效，像雾霾或隔窗带来的城市氛围；但细节不足也削弱了画面质感。
  - 不规则分割构图：有意图，但控制还不够精细。左侧太阳强，右侧大块空窗偏弱，视觉重量不太平衡。

## 做得好的地方

- 你看到了“窗框 + 落日 + 城市雾感”的组合，这不是随手记录，已经有画面意识。
- 黑色窗框形成强几何结构，能把普通窗外景变成更有秩序的画面。
- 左上太阳的位置不错，没有完全放在正中，橙红色天空也提供了明确情绪。
- 下方城市剪影虽然不清晰，但有层次，能说明这是一个隔着窗看城市日落的场景。

## 优先修改项

### 1. 太阳高光太硬，白盘边缘溢出

- 问题：太阳几乎变成纯白圆盘，周围有明显发光溢出，缺少日落的层次。
- 为什么：直拍太阳时，相机或手机很容易为了整体画面提亮，导致高光被剪切；如果主体是太阳，高光控制会直接影响技术完成度。
- 下次怎么拍：对着太阳旁边的亮天空测光，曝光补偿降到约 -1EV 到 -2EV；如果是手机，长按锁定曝光后把小太阳滑块往下拉。最好连拍 3 张不同曝光，保留太阳边缘最稳的一张。
- 这张怎么修：降低高光和白色色阶，局部给太阳周围压一点曝光；不要强行拉回太阳内部细节，因为已经接近纯白，重点是让边缘溢光少一点。

### 2. 右侧画面太空，视觉重心偏左

- 问题：左上有太阳，左下有建筑，右侧大窗格主要是浅色天空和很弱的远景，信息量不够。
- 为什么：画面右半边占了很大面积，却没有提供同等重量的内容，观众看完太阳后容易不知道继续看哪里。
- 下次怎么拍：要么向左移动机位，让太阳和窗框更集中，拍成更简洁的竖向或方形构图；要么等待右侧出现更清楚的建筑轮廓、云层、飞鸟或反光，让右侧有一个视觉支点。
- 这张怎么修：裁掉一部分右侧和下方，让太阳、中央竖窗框、下方建筑形成更紧凑的三点关系。可以尝试 4:5 竖构图或接近方构图。

### 3. 窗框几何很强，但边缘控制还可以更精确

- 问题：黑色窗框占比很重，中间粗竖线和横线把画面切得很硬，左边缘还有一条深色边贴边进入。
- 为什么：几何构图最怕“差一点点整齐”。线条越强，观众越会注意它是否水平、垂直、对称或有明确节奏。
- 下次怎么拍：打开网格线，让横窗框真正水平、竖窗框尽量垂直；拍之前沿四边扫一遍，确认边缘没有半截杂物。可以稍微后退一点，给裁切和校正留空间。
- 这张怎么修：先做透视 / 垂直校正，再裁切左边贴边的深色干扰；保留窗框的黑色剪影，但让线条显得更干净。

### 4. 城市远景偏软，氛围有了但质感不足

- 问题：远处建筑轮廓比较糊，像隔着玻璃、雾气或数码放大后的结果。
- 为什么：城市风景需要一定轮廓支撑，否则只剩颜色和形状，画面会显得松。
- 下次怎么拍：尽量贴近干净玻璃拍，避开反光和脏污；不要用过多数码变焦。若用相机，优先用较低 ISO、稳住机身，必要时靠窗框或三脚架支撑。
- 这张怎么修：对建筑区域少量增加去朦胧、清晰度和纹理，但不要全图猛加锐化，否则天空会变脏、太阳边缘会更难看。

## 建议设置

看不出具体设备和 EXIF，以下是估计值，按“拍窗外日落城市”来建议：

- 如果用手机：长按锁定对焦 / 曝光在太阳旁边的天空，曝光下拉约 -1 到 -2 档；开启网格线；尽量使用原生焦段，不要大幅数码变焦；连拍几张不同曝光。
- 如果用相机手持：A/Av 光圈优先，ISO 100-400，光圈 f/5.6-f/8，曝光补偿 -1EV 起步；快门尽量不低于 1/125s；使用单点对焦对在窗框边缘或远处高反差建筑上。
- 如果有三脚架或能固定机位：ISO 100，f/8-f/11，包围曝光 -2/0/+1，后期选高光最稳的一张，或做轻度曝光融合。
- 白平衡：可以保留偏暖，不必完全校正成中性；这张的暖色是情绪来源。

## 后期步骤

1. 先校正水平和垂直，让窗框线条更稳。
2. 裁切右侧空白和左边贴边暗部，优先保留太阳、中央窗框和下方建筑的关系。
3. 全局降低高光、白色色阶，略压曝光，保护天空层次。
4. 对下方建筑和远景做局部去朦胧、清晰度、纹理增强，幅度要小。
5. 保持窗框为深色剪影，只在最黑处轻微提一点阴影，避免死黑区域显得脏。
6. 色彩上保留橙粉色天空，可略降低饱和度，避免太阳周围变得刺眼。
7. 最后做轻微锐化和降噪，重点保护天空不要出现明显颗粒和色带。

## 下一次练习任务

同一个窗边位置，连续拍 9 张日落框景：

1. 三张曝光：-2EV、-1EV、0EV，对比太阳边缘和城市细节。
2. 三张构图：太阳放左上、太阳贴近窗框交点、太阳完全不入镜只拍余晖。
3. 三张裁切方向：横构图、竖构图、方构图。

拍完只选一张最好的，判断标准是：太阳不过分刺眼、窗框线条稳定、右侧或下方至少有一个能承接视线的城市元素。
