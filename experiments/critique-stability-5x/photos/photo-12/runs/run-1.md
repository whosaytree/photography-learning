# photo-12 run-1 摄影点评

## 一句话总评

这是一张能看清“手机游戏画面”的记录照，但摄影意图偏弱，随机倾斜、边缘裁切、手部背景和屏幕反光让画面更像随手拍，而不是有控制的屏幕/生活场景照片。

## 评分前检查

- 主体：手机上的游戏画面，以及被手拿着的手机本身。
- 题材：日常记录 / 物件记录 / 屏幕内容记录。
- 基础问题等级：基础问题。主体能辨认，不是废片，但构图、光线和叙事都缺少控制。
- 硬伤封顶检查：
  - 主体不可读：否，手机和游戏画面可读。
  - 主体存在但不够清晰或表达偏弱：是。观众能看出是游戏屏幕，但不清楚你想强调“游戏内容”“手机状态”还是“玩游戏这个瞬间”，构图和叙事按此封顶。
  - 主体严重虚焦：否。
  - 主体明显虚焦但仍可读：否，画面有轻微软和反光，但不是明显跑焦。
  - 严重手抖或运动模糊：否。
  - 明显手抖或运动模糊削弱主体：否，主要问题不是抖动。
  - 严重过曝：否，屏幕有亮部和反光，但重要信息没有大面积死白。
  - 严重欠曝：否，手部和环境偏暗，但主要屏幕仍可见。
  - 水平线/垂直线非故意倾斜：部分成立。画面大幅斜置，虽然手机可以斜拍，但这里没有形成稳定的视觉设计。
  - 主导背景干扰：是。手指、手机边框、床品/杂物和反光都在抢注意力。
  - 主体太小且无法裁切恢复：否，手机占画面很大。
  - 普通记录照、缺少明确摄影意图：是。
  - 光线普通且故事弱：是。
  - 多个维度重大硬伤同时出现：不作为严格封顶触发；问题较多，但主体仍可理解。
- 高分资格：不具备。主体虽然可见，但构图、光线、背景控制和叙事没有至少两个明显强项，不能进入 7.5 或 8 的区间。
- 故意处理判断：倾斜构图、高对比屏幕和暗背景看起来更像拍摄时的自然结果，不像有意设计。缺少稳定锚点、明确视觉路径和边缘控制，所以不按“成功的故意倾斜/低调/高反差”加分。
- 低端规则与逃逸判断：这是基础问题照片，正常应在 5 分附近或以下；没有强光线、强瞬间或强构图来逃逸到 5.5-6。

## 五项评分

- 技术：5/10。主体可辨认，曝光基本能看，但屏幕反光、边缘暗部和整体轻微发软降低了清晰度。
- 构图：4.5/10。手机占画面很大，这是优点；但大幅倾斜、边缘切割随意，手和背景干扰明显，视觉重心不稳定。
- 光线：4.5/10。屏幕本身提供亮度，但环境光没有被控制，反光和暗部让画面显得杂乱。
- 叙事：4/10。能说明“正在看/玩手机游戏”，但没有更明确的瞬间、情绪、动作关系或视觉重点。
- 总体：4.5/10。它是可理解的记录照，但还没有形成清楚的摄影表达。

## 封顶规则

主体存在但表达偏弱，叙事和构图被封顶在 5.0；同时普通记录照、背景干扰、光线普通且故事弱也限制了总体分。本次总体不超过 5.0。

## 做得好的地方

- 主体距离够近，手机屏幕占据主要画面，观众不用猜“拍的是什么”。
- 屏幕色彩鲜艳，有绿色、黄色和黑色的对比，第一眼有一定吸引力。
- 斜线让画面有一点动态感，虽然还没有完全控制好，但比完全平拍的普通记录照更有尝试感。

## 优先修改项

### 1. 问题：主体意图不够明确

- 为什么：现在画面同时有手机屏幕、手机边框、手、背景杂物。观众不知道重点是游戏画面、手机设备，还是“手拿着玩游戏”的生活瞬间。
- 下次怎么拍：拍之前先定一句话主题，比如“记录游戏画面”“拍手持游戏的沉浸感”“拍手机屏幕里的角色”。如果重点是屏幕，就让屏幕占 80%-90%，尽量减少手和背景；如果重点是生活瞬间，就把手部动作、姿势和环境一起安排清楚。
- 这张怎么修：裁掉左下角多余手部和右下角杂物，保留手机屏幕和少量边框；同时把画面旋转到屏幕文字更容易阅读的角度。

### 2. 问题：倾斜和裁切显得随机

- 为什么：手机斜穿画面可以制造动感，但这张的边缘切得比较随意，上下左右都不够干净，像是来不及构图。
- 下次怎么拍：打开网格线，让手机两条长边和画面对角线形成明确关系；要么端正拍成规整的矩形，要么故意斜拍，但让四个角至少有两个完整进入画面。
- 这张怎么修：先轻微旋转，让屏幕主体更稳定；再做紧裁切，只留下屏幕主体和必要边框，减少画面外侧杂乱区域。

### 3. 问题：屏幕反光和环境干扰明显

- 为什么：屏幕是发光体，周围光线和手部反光会降低文字、角色和界面的可读性；背景杂物也会把注意力从屏幕拉走。
- 下次怎么拍：避开正对灯光或窗户的角度，把手机稍微转 10-20 度，找到反光最少的位置；背景换成干净桌面、深色布或纯色墙面。
- 这张怎么修：降低高光，压一点反光区域；用局部调整降低手部和背景亮度，让屏幕成为最亮、最清楚的区域。

### 4. 问题：叙事只停留在“拍到了”

- 为什么：记录照能说明事情，但好照片还需要一个让人停留的理由，比如紧张瞬间、胜负结果、手指动作、人物表情或特殊光线。
- 下次怎么拍：等游戏里出现更关键的瞬间再拍，比如战斗动作、胜利画面、失败提示、手指正按按钮的动作；也可以把玩家的手势纳入构图，形成“人在操作游戏”的关系。
- 这张怎么修：如果原图像素允许，可以裁到游戏角色和对战界面，减少无关环境，让故事更集中。

## 建议设置

看不出具体 EXIF，以下是估计建议：

- 如果用手机拍屏幕：使用 1x 或 2x 镜头，不要用过度数码变焦。
- 对焦：点按屏幕上的游戏角色或文字区域，让手机对屏幕内容对焦。
- 曝光：点按屏幕后，把曝光稍微下拉一点，避免屏幕过亮和反光泛白。
- 快门：手机自动即可；如果有专业模式，尽量保持 1/100 秒以上，减少手持轻微晃动。
- ISO：尽量低，优先找稳定光线，不要在很暗环境里硬拍。
- 拍摄角度：镜头尽量和手机屏幕平面平行，或只保留一个明确的斜角，不要边拍边歪。

## 后期步骤

1. 旋转校正：先决定是端正屏幕，还是保留明确对角线；不要停在半歪不歪的状态。
2. 裁切：裁掉手部过多区域、右下角杂物和多余黑边，保留屏幕主体。
3. 高光：降低屏幕反光区域的高光，保护文字和角色细节。
4. 阴影：略微压暗背景和手部，让它们退后。
5. 清晰度：对屏幕区域轻加清晰度或锐化，不要全图过度锐化。
6. 色彩：略降绿色饱和度，避免屏幕颜色过于刺眼；保持游戏画面的鲜艳感即可。
