# photo-11 run-3 摄影点评

## 一句话总评

这张照片有一点“地铁线路图形和斜线”的视觉线索，但主体不够明确、画面倾斜且上半部空墙占比过大，目前更像随手记录而不是完成的城市图形照片。

## 评分前检查

- 主体：下方地铁线路图，以及上方红色斜带和灯带形成的几何线条；但画面没有一个明确的视觉落点，比如某个站名、箭头、线路交汇或人物关系。
- 题材：城市空间细节 / 交通标识 / 图形构成练习。
- 基础问题等级：基础问题。照片可读，不是废片；但主体偏弱、构图取舍不清、倾斜感明显。
- 硬伤封顶检查：
  - 主体不可读：不触发，能看出是地铁线路图和墙面线条。
  - 主体存在但不清晰或偏弱：触发。总体、构图、叙事按规则不应高于 5。
  - 主体严重虚焦：不触发。
  - 主体明显虚焦但仍可读：不触发。文字不是特别锐，但主要问题不是虚焦。
  - 严重手抖或运动模糊导致主体难读：不触发。
  - 明显手抖或运动模糊削弱主体：不明显触发，画面有轻微软感，但不构成主要硬伤。
  - 重要主体严重过曝：不触发。上方灯带偏亮，但没有压倒主体细节。
  - 重要主体严重欠曝：不触发。下方线路图偏暗，但仍能读。
  - 水平线 / 垂直线无意倾斜且可见：触发。地铁图边缘和墙面线条整体斜，若不是明确抽象表达，会削弱稳定感。
  - 主导背景干扰主体：接近触发。上半部大面积空墙和红带比线路图更抢眼，但它也可能是构成元素，所以按“主体弱”处理，不单独再加重。
  - 主体太小且无法通过裁切补救：不触发。裁掉上方空墙后仍可形成较清楚的线路图画面。
  - 普通记录、缺少明确摄影意图：触发。当前更像看到地铁图后顺手拍下。
  - 光线普通且叙事弱：触发。室内灯光可用，但没有明显方向、质感或情绪。
  - 多个维度重大硬伤同时出现：不触发到 4.5 封顶，因为技术可读，问题主要集中在主体和构图意图。
- 高分资格：不具备。主体不是立即明确的摄影主体；构图、光线、叙事没有两个维度明显强。
- 故意处理判断：倾斜和上方留白可能想做几何抽象，但证据不足。画面没有稳定锚点，边缘控制也不够干净，所以按无意倾斜和取景未完成来评分。
- 低分规则应用：属于普通基础问题，不是严重基础失败；总体按主体弱和普通记录感封顶在 5 附近。
- 逃逸规则：有一点斜线和色块的图形感，可以避免落到 4 以下；但补偿强度不够，不能超过 5。

## 五项评分

- 技术：5.5/10。曝光基本可读，白平衡和室内光没有大问题；但下方偏暗、整体有轻微软感，画面不够干净。
- 构图：4.5/10。斜线有潜力，但上半部空墙太重，下方线路图被切得零散，视觉中心不明确。
- 光线：5/10。地铁室内光均匀可用，上方灯带提供了一点亮度层次；但光线本身普通，没有强化主体。
- 叙事：4/10。能说明“这是地铁线路图”，但缺少事件、人物、空间关系或明确观点。
- 总体：4.8/10。照片能看懂，也有一点图形意识，但目前主体弱和普通记录感比较明显。

## 封顶规则

主体存在但不清晰或偏弱，叙事和总体按规则封顶在 5；同时普通记录感、光线普通且叙事弱也限制了总体上限。

## 做得好的地方

- 你注意到了墙面红色斜带、灯带和线路图之间的线条关系，这说明你开始在看“形状”，不只是看内容。
- 画面里有中英文站名、彩色换乘标识、箭头和线路，这些元素本身有城市交通的识别度。
- 曝光没有严重崩坏，重要信息还能读出来，后期仍有裁切和校正空间。

## 优先修改项

### 1. 主体不够明确

- 问题：观众不知道该看上方红色斜带、下方线路图、某个站名，还是整个地铁空间。
- 为什么：摄影里“有信息”和“有主体”不是一回事。信息很多但没有主次，照片就会变成记录。
- 下次怎么拍：拍之前先说一句“我这张要拍什么”：例如“我要拍三元桥这个站名和换乘箭头”或“我要拍红色斜线压过线路图的抽象构成”。然后让这个目标占画面最大视觉权重。
- 这张怎么修：建议裁掉上方约 35%-45% 的空墙，让线路图和红色斜带更接近画面中心；如果想保留抽象感，可以只保留红带、灯带边缘和一排站名，形成更简洁的三层结构。

### 2. 倾斜感没有转化成有效动势

- 问题：画面整体明显斜，但不像是经过控制的动态构图，更像手机举歪了。
- 为什么：地铁线路图、墙面接缝、灯带都是强线条元素，观众会自然期待它们要么水平稳定，要么斜得非常有意图。
- 下次怎么拍：打开网格线，让线路图底边或上方灯带至少有一条线保持水平；如果想拍斜线，就让斜线更大胆，比如旋转到 20-30 度，并确保边缘裁切干净。
- 这张怎么修：先做透视 / 旋转校正，让线路图的黑色边缘接近水平；如果校正后损失太多，就反过来裁成更抽象的斜构图，减少“本该水平却歪了”的感觉。

### 3. 上半部空墙压过了下方信息

- 问题：上方浅色墙面占了太多面积，但纹理、光影和内容都不够强。
- 为什么：大面积留白只有在能服务主体、情绪或极简构成时才成立；这张的留白目前没有提供足够的视觉价值。
- 下次怎么拍：靠近线路图，减少无效墙面；或者退后一点，把完整的地铁导视环境、乘客、方向箭头一起纳入，让空间关系成立。
- 这张怎么修：裁成更宽的横幅，重点保留下方“站名 + 换乘标识 + 红带”的组合；同时用局部提亮让线路图文字更清楚。

### 4. 叙事停留在“我看到了一块线路图”

- 问题：照片没有人的动作、等待的情绪、方向选择、城市通勤感，也没有足够强的抽象图形美。
- 为什么：交通标识本身很常见，除非你把它拍成清晰信息、强图形、或人与空间的关系，否则观看理由会弱。
- 下次怎么拍：可以等一个人经过、手指指向某个站、或把换乘箭头和乘客移动方向放在一起；也可以只拍局部色块和线条，彻底走抽象路线。
- 这张怎么修：增强对比和清晰度后，裁出“光熙门、三元桥、箭头、换乘17号线”这一带，让照片至少有一个可读中心。

## 建议设置

看不出原始 EXIF，以下是估计建议：

- 如果用手机：开启网格线，点按线路图文字区域对焦并锁定曝光；室内导视牌容易偏暗，可略微上调曝光 0.3-0.7 档，但不要让灯带过曝。
- 如果用相机：光圈可用 f/5.6-f/8，保证导视牌文字和墙面线条都清楚；快门尽量不低于 1/125 秒，ISO 自动即可。
- 构图设置：优先用 1x 或 2x 的正常视角，不要太广导致边缘变形；拍导视牌时先对齐一条主要水平线。

## 后期步骤

1. 旋转校正：先让线路图上方黑色边线接近水平。
2. 裁切：裁掉上方多余空墙，保留红色斜带和下方站名区域；尝试 16:9 或 2:1 横幅。
3. 提亮下方：对线路图区域加一点曝光或阴影，让文字更可读。
4. 压低高光：降低灯带和浅墙高光，避免上半部继续抢注意力。
5. 增加中等对比：轻微提升对比和清晰度，让线条边缘更利落。
6. 颜色整理：红色斜带可以稍微增加饱和度，但不要把整张调得过重。

## 下一次练习任务

做一次“地铁导视三选一”练习：同一个地铁站里各拍 10 张，只选一种目标拍法。

- 信息型：把一个站名、箭头或换乘标识拍清楚，要求水平线端正、主体占画面 50% 以上。
- 图形型：只拍线条、色块、圆点、箭头，不追求完整文字，但要求边缘干净、画面有主线。
- 叙事型：等待一个人、手、影子或行李进入画面，让导视牌和人的动作产生关系。

拍完后只选 3 张，每张问自己一句：观众第一眼会看哪里？如果答案不一致，就说明主体还需要再简化。
