Guide

使用说明

单张模式

  1. 切换到“单张模式”。
  2. 点击左下角“开始评分”。
  3. 左侧按日期选择照片。
  4. 查看右侧五个评分：技术、构图、光线、叙事、总体。
  5. 如果你认为某个分数偏低，点“↑”；如果认为偏高，点“↓”。
  6. 可以在“评分反馈”输入框写下对这张照片评分或点评的整体看法。
  7. 可以只评价部分照片、部分维度，不需要每一项都点。
  8. 完成后点击左下角“结束评分”，浏览器会导出本轮 JSON 文件。

对比模式

  1. 切换到“对比模式”。
  2. 点击左下角“开始评分”，页面会随机抽取两张归档照片。
  3. 这个模式不会显示原来的模型分数。
  4. 在五个维度里选择“左图更高”“右图更高”或“难说”。
  5. 可以只选择你有判断的维度，不需要五项都选。
  6. 点击“换一组”会随机抽取下一组照片。
  7. 完成后点击左下角“结束评分”，浏览器会导出本轮 JSON 文件。

导出文件

导出的 JSON 会记录你的点击轨迹、对应照片 ID、评分维度、选择时间，以及单张模式下填写的文字反馈。

把这个 JSON 文件发给我，就可以分析你认为当前评分系统在哪些维度偏高、偏低，或者和你的照片判断习惯有什么差异。
