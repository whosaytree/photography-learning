# 摄影点评

## 一句话总评

这张小屋逆光照有很明确的气氛和构图意识，阳光、草坡和木屋形成了海岸边的孤独感；主要问题是高光太冲、暗部压得过深，主体细节被牺牲得有点多。

## 评分前检查

- 主体：左侧海岸小屋和前方木栏。
- 题材：海岸风景 / 建筑环境照。
- 基础问题等级：无。主体清楚，构图和逆光处理都有明确意图。
- 硬伤封顶检查：
  - 主体不可读：否。小屋轮廓、窗户、栏杆都能辨认。
  - 主体存在但不清楚或偏弱：否，主体位置和形状明确。
  - 主体严重虚焦或明显误焦：否。
  - 手震或运动模糊影响主体：否。
  - 严重过曝剪掉重要主体细节：不触发。太阳附近高光明显溢出，但太阳和天空亮斑不是主体细节；不过技术分会因此降低。
  - 严重欠曝隐藏重要主体细节：不触发硬封顶。小屋左侧和草地暗部压黑明显，但整体仍有轮廓和气氛，属于有意低调逆光的一部分。
  - 地平线 / 垂直线明显歪斜：否。
  - 背景干扰强烈竞争主体：否。
  - 主体太小且无法裁切补救：否。
  - 普通记录照、无明确摄影意图：否。
  - 光线平淡且叙事弱：否。光线是这张的主要表达。
- 故意处理判断：逆光、高反差和暗部压黑基本属于有意处理。至少满足三点：画面有清楚主体小屋；太阳和暗草坡支持孤独、风大、傍晚的氛围；构图边缘和视觉路径基本受控。
- 低端规则：无严重基础失败，不进入 3-4.5。
- 逃逸规则：不需要使用逃逸规则，因为没有硬性基础问题。
- 高分资格：考虑过 7.5。主体清楚，构图和光线有意图；但太阳附近高光面积过大，暗部细节损失多，天空留白也略重，所以总体停在 7。
- 独立评分：只基于这张图，不按任何分布修正。

## 做得好的地方

- 逆光制造了很强的现场感，像海边风大的傍晚。
- 小屋放在左侧，右侧留给天空和草坡，画面有空间感。
- 木栏杆形成几何线条，能把视线从小屋带向右侧环境。
- 暗草坡、亮天空、黑木屋之间有明显明暗对比，气氛比普通记录照强。
- 画面没有杂乱元素，主体和环境关系清楚。

## 优先修改项

### 1. 太阳高光太冲

- 问题：太阳位置接近屋顶边缘，亮斑面积很大，周围天空细节被冲掉。
- 为什么：逆光可以强，但高光过大时会把观众视线从小屋吸走，也会显得技术控制不够稳。
- 下次怎么拍：让太阳被屋顶边缘遮住更多，只露一小点光；或者等太阳再低一点，让亮度下降。
- 这张怎么修：高光 -40 到 -70，白色色阶 -15 到 -30；太阳周围用局部蒙版稍微压暗，但不要压成灰块。

### 2. 暗部细节损失偏多

- 问题：左侧屋体和底部草坡压得很暗，部分草的纹理读不出来。
- 为什么：低调不是全黑，重要区域至少要保留一些边缘和纹理，画面才有层次。
- 下次怎么拍：逆光时可以包围曝光，或用 -1 EV 保护天空后再在 RAW 里拉阴影；如果想保留屋体细节，可稍微偏侧一点拍，不要完全对着太阳。
- 这张怎么修：阴影 +20 到 +35，黑色色阶 +5 到 +15；只拉小屋和草坡，不要全图拉平。

### 3. 天空面积略大

- 问题：上半部分天空很多，云层有质感但还不够强到撑起这么大的比例。
- 为什么：天空占比大时，云形、颜色或光线必须很有看点；否则主体会被稀释。
- 下次怎么拍：如果云层不够戏剧化，可以稍微压低取景，让草坡和小屋占更多画面；如果想留天空，等云边被夕阳照亮。
- 这张怎么修：顶部裁掉约 10%-15%，保持太阳和小屋关系，同时减少空白天空。

### 4. 小屋边缘略贴左

- 问题：小屋左侧被画面边缘切得比较紧，窗户靠边，视觉上有一点局促。
- 为什么：建筑主体贴边容易让画面显得没留够空间，尤其是左侧还有窗户细节。
- 下次怎么拍：向左退半步或稍微向右转镜头，让小屋左侧留出一点边界。
- 这张怎么修：如果原片有余量，可以从左侧多留一点；如果没有，就从右侧和顶部轻裁，强化“半边小屋 + 大环境”的意图。

## 建议设置

看不出真实 EXIF，以下是按画面效果估计：

- 模式：手动或光圈优先加曝光补偿。
- 光圈：风景建筑建议 f/8-f/11，保证小屋、草坡和远处环境都有清晰度。
- 快门：手持至少 1/250s；风大草动时可到 1/500s。
- ISO：ISO 100-400。
- 测光：逆光场景建议看直方图，优先保护高光；可用 -1/3 到 -1 EV 曝光补偿。
- 对焦：单点对焦在小屋墙面或栏杆上。
- 拍法：最好拍 RAW，并做 2-3 张包围曝光，方便后期保留天空和暗部。

## 后期步骤

1. 先裁切：顶部裁 10%-15%，必要时右侧轻裁，让小屋更稳。
2. 开启镜头校正和色差校正。
3. 高光 -40 到 -70，白色色阶 -15 到 -30，压住太阳附近亮部。
4. 小屋和草坡局部阴影 +20 到 +35，黑色色阶 +5 到 +15，恢复一点纹理。
5. 天空局部增加去朦胧 +5 到 +10，云层对比 +5，不要过度 HDR。
6. 木栏杆局部加一点清晰度，让线条更能引导视线。
7. 草地饱和度只微调，避免绿色发脏或过艳。
8. 最后加轻微暗角，把视线收回小屋和栏杆。

## 下一次练习任务

拍 5 张逆光建筑练习：

1. 太阳完全露出一张。
2. 太阳被屋顶挡住一半一张。
3. 太阳完全藏在屋顶后，只留轮廓光一张。
4. 对天空曝光一张，保住高光。
5. 对小屋曝光一张，保住暗部。

回看时比较：哪一张既有逆光气氛，又还能看清主体细节。这个练习会直接提升你处理高反差场景的能力。
